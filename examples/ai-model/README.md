# Title Ideas

- **Suggest Titles** (Plugins menu): your writing model reads the document
  in front and offers three titles. Textus asks you the first time, and
  counts what the plugin uses each month.
- **Word completion**: pick "Words in this document" in Settings › Textus
  AI › Writing assist, and a word you are typing is finished in grey from
  the words already written. Tab takes it.

Shows `textus.ai.complete`, `textus.ai.available` and
`textus.ai.registerInlineCompletion` (API 1.8).
