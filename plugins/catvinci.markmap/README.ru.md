# Интеллект-карта

Рисует план на Markdown (заголовки и списки) в виде интеллект-карты.

- Напишите блок кода на `markmap`: под ним появится рисунок, а исходник снова видно, если щёлкнуть в блок.
- `height=400` после имени языка задаёт высоту рисунка.
- При экспорте в HTML, PDF или Word рисунок попадает картинкой.

## Пример

```markmap
# Project
## Goals
- Ship 1.3
- Write the guide
## People
- Writers
- Reviewers
```
