# Gráfica de funciones

Gráficas de funciones, una por línea: sin(x), x^2 - 1.

- Escribe un bloque de código en `function-plot`: se dibuja debajo, y su código vuelve a verse al hacer clic en él.
- `height=400` tras el lenguaje fija la altura del dibujo.
- Al exportar a HTML, PDF o Word, el dibujo va como imagen.
- `xmin=-5 xmax=5` (y `ymin`, `ymax`) tras el lenguaje fijan el rango; entiende + - * / ^, x, pi, e y sin, cos, tan, exp, ln, log, sqrt, abs.

## Ejemplo

```function-plot
sin(x)
x^2 / 4 - 1
```
