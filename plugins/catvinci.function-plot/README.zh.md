# 函数图像

画函数图像，每行一个：sin(x)、x^2 - 1。

- 写一个 `function-plot` 代码块，下方就会画出来；点进代码块可以再看到并修改源码。
- 在语言后面写 `height=400` 可以设置图的高度。
- 导出 HTML、PDF、Word 时，图会作为图片放进去。
- 在语言后写 `xmin=-5 xmax=5`（以及 `ymin`、`ymax`）设置范围；支持 + - * / ^、x、pi、e，以及 sin、cos、tan、exp、ln、log、sqrt、abs。

## 示例

```function-plot
sin(x)
x^2 / 4 - 1
```
