# 関数グラフ

x の関数のグラフを 1 行に 1 つずつ描きます。たとえば sin(x) や x^2 - 1。

## グラフを描く

- `function-plot` のコードブロックに、1 行に 1 つ関数を書きます。グラフはその下に描かれ、ブロックをクリックするとソースが表示され、編集できます。
- 行頭に `y =` を付けてもかまいません。`2x` や `3sin(x)` は掛け算になります。
- + - * / ^、括弧、x、pi、e と sin、cos、tan、asin、acos、atan、sinh、cosh、tanh、exp、ln、log（底 10）、sqrt、abs、floor、ceil が使えます。
- x の範囲は -10 から 10 です。言語名の後に `xmin=-5 xmax=5` と書くと変えられます。`ymin`・`ymax` で y の範囲を固定でき、書かなければ曲線に合わせます。
- 言語名の後に `height=400` と書くと高さを指定できます。
- 読めない行があると、ブロックの下に何が問題かを表示します。
- 曲線にはテーマの色が使われ、テーマを変えると描き直します。
- HTML・PDF・Word に書き出すと、グラフは画像として入ります。

## 例

```function-plot xmin=-5 xmax=5
sin(x)
x^2 / 4 - 1
```

## 権限

求めるのは **Textus AI のツール** だけで、Textus AI がブロックを書く前に確認できるようにするためです。ファイルは読まず、すべて端末の中で描きます。デスクトップと iOS で使えます。
