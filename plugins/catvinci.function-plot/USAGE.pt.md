# Gráfico de funções

Gráficos de funções, uma por linha: sin(x), x^2 - 1.

- Escreva um bloco de código em `function-plot`: ele é desenhado abaixo, e o código volta a aparecer ao clicar nele.
- `height=400` depois da linguagem define a altura do desenho.
- Ao exportar para HTML, PDF ou Word, o desenho vai como imagem.
- `xmin=-5 xmax=5` (e `ymin`, `ymax`) depois da linguagem definem o intervalo; entende + - * / ^, x, pi, e e sin, cos, tan, exp, ln, log, sqrt, abs.

## Exemplo

```function-plot
sin(x)
x^2 / 4 - 1
```
