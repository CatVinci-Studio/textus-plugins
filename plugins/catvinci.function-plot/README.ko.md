# 함수 그래프

x의 함수 그래프를 한 줄에 하나씩 그립니다. 예를 들어 sin(x)나 x^2 - 1.

## 그래프 그리기

- `function-plot` 코드 블록에 한 줄에 하나씩 함수를 씁니다. 그래프는 블록 아래에 그려지고, 블록을 클릭하면 소스가 다시 보여 고칠 수 있습니다.
- 줄 앞에 `y =`를 붙여도 됩니다. `2x`, `3sin(x)`는 곱셈입니다.
- + - * / ^, 괄호, x, pi, e와 sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, exp, ln, log(밑 10), sqrt, abs, floor, ceil을 씁니다.
- x는 -10부터 10까지입니다. 언어 이름 뒤에 `xmin=-5 xmax=5`를 쓰면 바뀝니다. `ymin`, `ymax`로 y 범위를 고정하고, 쓰지 않으면 곡선에 맞춥니다.
- 언어 이름 뒤에 `height=400`을 쓰면 높이를 정할 수 있습니다.
- 읽을 수 없는 줄이 있으면 블록 아래에 무엇이 문제인지 알려 줍니다.
- 곡선마다 테마의 색을 쓰고, 테마를 바꾸면 다시 그립니다.
- HTML, PDF, Word로 내보내면 그래프가 이미지로 들어갑니다.

## 예시

```function-plot xmin=-5 xmax=5
sin(x)
x^2 / 4 - 1
```
