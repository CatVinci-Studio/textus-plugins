# Графики функций

Графики функций, по одной в строке: sin(x), x^2 - 1.

- Напишите блок кода на `function-plot`: под ним появится рисунок, а исходник снова видно, если щёлкнуть в блок.
- `height=400` после имени языка задаёт высоту рисунка.
- При экспорте в HTML, PDF или Word рисунок попадает картинкой.
- `xmin=-5 xmax=5` (и `ymin`, `ymax`) после имени языка задают диапазон; понимает + - * / ^, x, pi, e и sin, cos, tan, exp, ln, log, sqrt, abs.

## Пример

```function-plot
sin(x)
x^2 / 4 - 1
```
