# 画像ビューア

画像と SVG ファイルをタブで開きます。

- サイドバーから画像を開くか、ウインドウにドラッグします。
- ボタンか **Ctrl+スクロール**（Mac では **⌘+スクロール**）で拡大・縮小できます。**ウインドウに合わせる** で全体表示に戻ります。
- 拡大中は画像をドラッグして見回せます。ダブルクリックで、ウインドウに合わせた表示と実際のサイズを切り替えます。
- **⟳** で 90 度ずつ回転します。変わるのは表示だけで、ファイルはそのままです。
- キー：**+** と **-** で拡大・縮小、**0** で実際のサイズ、**F** でウインドウに合わせる、**R** で回転。
- SVG はソースを表示して、読んだりコピーしたりできます。
