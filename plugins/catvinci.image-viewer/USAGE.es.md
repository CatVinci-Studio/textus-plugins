# Visor de imágenes

Las imágenes y los archivos SVG se abren en una pestaña.

- Abre una imagen desde la barra lateral o arrástrala a la ventana.
- Amplía con los botones o con **Ctrl+rueda** (**⌘+rueda** en Mac); **Ajustar** vuelve a mostrarla entera.
- Un SVG puede mostrar su código, para leerlo o copiarlo.
