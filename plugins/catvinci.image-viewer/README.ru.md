# Просмотр изображений

Изображения и файлы SVG открываются во вкладке.

- Откройте изображение на боковой панели или перетащите его в окно.
- Масштабируйте кнопками или **Ctrl+прокрутка** (**⌘+прокрутка** на Mac); щёлкните по проценту, чтобы снова увидеть изображение целиком.
- В увеличенном виде изображение можно перетаскивать, чтобы его осмотреть; двойной щелчок переключает между вписанным видом и исходным размером.
- **⟳** поворачивает его на четверть оборота за раз. Меняется только вид, сам файл остаётся прежним.
- Клавиши: **+** и **-** меняют масштаб, **0** — исходный размер, **F** — вписать, **R** — повернуть.
- SVG может показать исходный код, чтобы его прочитать или скопировать.
