# Visionneuse d’images

Les images et les fichiers SVG s’ouvrent dans un onglet.

- Ouvrez une image depuis la barre latérale, ou faites-la glisser dans la fenêtre.
- Zoomez avec les boutons ou **Ctrl+molette** (**⌘+molette** sur Mac) ; **Ajuster** la réaffiche en entier.
- Un SVG peut afficher sa source, à lire ou à copier.
