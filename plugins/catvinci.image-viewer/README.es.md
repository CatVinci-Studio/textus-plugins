# Visor de imágenes

Las imágenes y los archivos SVG se abren en una pestaña.

- Abre una imagen desde la barra lateral o arrástrala a la ventana.
- Amplía con los botones o con **Ctrl+rueda** (**⌘+rueda** en Mac); haz clic en el porcentaje para volver a verla entera.
- Con la imagen ampliada, arrástrala para recorrerla; haz doble clic para pasar de ajustada a su tamaño real y al revés.
- **⟳** la gira un cuarto de vuelta cada vez. Solo cambia la vista; el archivo no se toca.
- Teclas: **+** y **-** hacen zoom, **0** muestra el tamaño real, **F** la ajusta y **R** la gira.
- Un SVG puede mostrar su código, para leerlo o copiarlo.
