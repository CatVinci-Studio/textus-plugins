# 이미지 뷰어

그림과 SVG 파일을 탭에서 엽니다.

- 사이드바에서 그림을 열거나, 창으로 끌어다 놓습니다.
- 버튼이나 **Ctrl+스크롤**(Mac에서는 **⌘+스크롤**)로 확대·축소하고, **창에 맞추기**를 누르면 전체가 다시 보입니다.
- 확대한 상태에서는 그림을 끌어 여기저기 볼 수 있고, 두 번 클릭하면 창에 맞추기와 실제 크기 사이를 오갑니다.
- **⟳**는 한 번에 90도씩 돌립니다. 보기만 바뀌고 파일은 그대로입니다.
- 키: **+**와 **-**는 확대·축소, **0**은 실제 크기, **F**는 창에 맞추기, **R**은 회전입니다.
- SVG는 소스를 표시해 읽거나 복사할 수 있습니다.
