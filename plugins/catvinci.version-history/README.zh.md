# 版本历史

文档每次保存都留一个版本。

- 每次保存，文档内容都会存成一个版本。
- 侧边栏的 **历史** 标签按时间倒序列出当前文档的版本。
- 选一个版本可以看它之后改了什么；**恢复这个版本** 把它找回来，或 **作为新文档打开** 单独打开。
- 间隔很近的多次保存（比如自动保存每隔几秒一次）只算一个版本，最多每 15 分钟留一版；每篇文档保留最近 50 版。
- 版本按天分组：今天、昨天，再往前显示日期。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `list_versions`：列出一篇文档（默认当前文档）保存过的各个版本，最新的在前，从 1 开始编号，每个版本带保存时间和大小。
- `diff_versions`：逐行显示一篇文档两个版本之间、或某个版本与当前内容之间的改动：+ 表示新增，- 表示删除，并附少量上下文。
