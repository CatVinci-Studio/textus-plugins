# История версий

Каждое сохранение документа остаётся в истории.

- Каждый раз при сохранении текст документа сохраняется как версия.
- Вкладка **История** на боковой панели показывает версии текущего документа, сначала новые.
- Выберите версию, чтобы увидеть, что изменилось с тех пор; **Вернуть эту версию** восстанавливает её, а **Открыть как новый документ** открывает рядом.
- Сохранения подряд (автосохранение каждые несколько секунд) считаются одной версией, новая — не чаще раза в 15 минут; хранятся последние 50.
- Версии сгруппированы по дням: Сегодня, Вчера, затем дата.
