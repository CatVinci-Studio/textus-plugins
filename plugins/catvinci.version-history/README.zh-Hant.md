# 版本紀錄

文件每次儲存都會留下一個版本。

- 每次儲存時，文件內容都會存成一個版本。
- 側邊欄的 **紀錄** 分頁會依時間由新到舊列出目前文件的版本。
- 選一個版本可以看它之後改了什麼；**還原這個版本** 會把它找回來，或用 **以新文件開啟** 在旁邊開啟。
- 間隔很近的多次儲存（例如自動儲存每隔幾秒一次）只算一個版本，最多每 15 分鐘留一版；每篇文件保留最近 50 版。
- 版本依日期分組：今天、昨天，再往前則顯示日期。

## Textus AI 工具

裝上這個外掛後，Textus AI 在對話中可以使用：

- `list_versions`：列出一份文件（預設目前文件）儲存過的各個版本，最新的在前，從 1 開始編號，每個版本附儲存時間和大小。
- `diff_versions`：逐行顯示一份文件兩個版本之間、或某個版本與目前內容之間的改動：+ 表示新增，- 表示刪除，並附少量上下文。
