# 버전 기록

문서를 저장할 때마다 그 버전이 남습니다.

- 저장할 때마다 문서의 내용이 하나의 버전으로 남습니다.
- 사이드바의 **기록** 탭에 지금 보고 있는 문서의 버전이 최신순으로 나옵니다.
- 하나를 고르면 그 뒤에 무엇이 바뀌었는지 볼 수 있습니다. **이 버전으로 되돌리기**로 되살리거나, **새 문서로 열기**로 옆에 엽니다.
- 짧은 간격으로 이어진 저장(몇 초마다 하는 자동 저장 등)은 하나의 버전이 되고, 새 버전은 최소 15분마다 생깁니다. 문서마다 최근 50개를 남깁니다.
- 버전은 날짜별로 묶여 오늘, 어제, 그 이전은 날짜로 표시됩니다.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `list_versions`: 어떤 문서(경로가 없으면 앞에 열린 문서)의 저장된 버전을 최신순으로 1부터 번호를 매겨, 저장 시각과 크기와 함께 나열합니다.
- `diff_versions`: 문서의 두 버전 사이, 또는 어떤 버전과 지금 문서 사이에 바뀐 것을 줄 단위로 보여 줍니다. +는 추가, -는 삭제이며 앞뒤 줄을 조금 덧붙입니다.
