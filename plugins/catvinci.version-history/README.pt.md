# Histórico de versões

Cada salvamento de um documento, guardado.

- Cada vez que você salva, o texto do documento é guardado como uma versão.
- A aba **Histórico** da barra lateral lista as versões do documento em primeiro plano, da mais recente para a mais antiga.
- Escolha uma para ver o que mudou desde então; **Restaurar esta versão** a traz de volta, ou **Abrir como novo documento** a abre ao lado.
- Quantas versões são guardadas por documento está nos ajustes do plugin.
- Salvamentos muito próximos (o salvamento automático a cada poucos segundos) são guardados como uma só versão; o intervalo entre versões é **Guardar uma versão** nos ajustes do plugin (a cada 15 minutos, no início).
- As versões são agrupadas por dia: Hoje, Ontem e depois a data.
