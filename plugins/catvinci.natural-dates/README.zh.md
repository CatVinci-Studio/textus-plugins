# 自然语言日期

输入 `@` 加上一个日子，选中后就写入它对应的日期：

- 中文：`@今天`、`@明天`、`@后天`、`@周五`、`@下周五`、`@星期三`、`@3天后`、`@下周`
- English: `@today`、`@tomorrow`、`@friday`、`@next friday`、`@in 3 days`、`@next week`
- 日本語：`@今日`、`@明日`、`@金曜日`、`@来週金曜日`、`@3日後`

默认写成 `2026-11-06` 这样的日期；把设置里的**插入为**改成链接，就会写成 `[[2026-11-06]]`，如果你的每日笔记用这个名字，它就会链到那天的笔记。

只有在空格后、行首或括号后输入 `@` 才会弹出，`me@example.com` 这样的邮箱、`[@key]` 这样的引用不会。在 `(` 后面会保留 `@`，所以 `(@明天` 会写成提醒的格式 `(@2026-11-06`。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `parse_date`：把用文字说的日子（英文、中文或日文，与插件的 @ 补全认得的一样：tomorrow、next wednesday、in 3 days、下周五、明後日）换算成日期 YYYY-MM-DD，从今天算起。每周从周一开始；只说星期几指下一个。
