# Leitor de Word

Documentos do Word, como aparecem no Word, numa aba.

- Abra um .docx pela barra lateral ou arraste um para a janela.
- Ele aparece somente para leitura, com layout, tabelas e imagens; a barra mostra em que página você está.
- **Ctrl+F** (**⌘F** no Mac), ou **⌕**, localiza palavras: **Enter** vai para a próxima, **Shift+Enter** para a anterior e **Esc** fecha.
- **+** e **−** dão zoom; **Ctrl+0** (**⌘0**) volta a 100%.
- **Editar como Markdown** o abre como um documento no qual você pode escrever.
