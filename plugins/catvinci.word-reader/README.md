# Word Reader

Read Word documents (.docx) in a tab, laid out as they are in Word.

- Open a .docx from the sidebar, or drag one into the window.
- It shows read-only, with its layout, tables and pictures; the bar says which page you are on.
- **Ctrl+F** (**⌘F** on a Mac), or the search button, finds words and counts the matches: **Enter** goes to the next, **Shift+Enter** the one before, **Esc** closes.
- The zoom buttons, or **Ctrl+plus** and **Ctrl+minus** (**⌘** on a Mac), zoom from 50% to 200%. **Ctrl+0** (**⌘0**), or a click on the percentage, goes back to 100%.
- **Edit as Markdown** hands the file to Textus, which turns it into a Markdown document you can write in.
- A file that can't be read says so in the tab.

The plugin asks for no permissions: it only reads the file you open in it. It works on the desktop and on iPhone and iPad.
