# Word 阅读器

在标签页里阅读 Word 文档（.docx），排版和在 Word 里看到的一样。

- 从侧边栏打开 .docx，或把它拖进窗口。
- 只读显示，保留排版、表格和图片；工具栏会显示你在第几页。
- **Ctrl+F**（Mac 上 **⌘F**）或搜索按钮用来查找文字，并显示匹配数：**Enter** 跳到下一个，**Shift+Enter** 跳到上一个，**Esc** 关闭。
- 缩放按钮，或 **Ctrl+加号**、**Ctrl+减号**（Mac 上用 **⌘**），在 50% 到 200% 之间缩放。**Ctrl+0**（**⌘0**）或点百分比，回到 100%。
- **作为 Markdown 编辑** 把文件交给 Textus，转成可以编辑的 Markdown 文档。
- 文件读不出来时，标签页里会说明。

插件不申请任何权限，只读取你用它打开的文件。电脑、iPhone 和 iPad 上都能用。
