# Word リーダー

Word 文書を Word と同じ見た目で、タブに表示します。

- サイドバーから .docx を開くか、ウインドウにドラッグします。
- 読み取り専用で、レイアウト、表、画像もそのまま表示されます。バーには今いるページが出ます。
- **Ctrl+F**（Mac では **⌘F**）か **⌕** で文字を検索します。**Enter** で次へ、**Shift+Enter** で前へ、**Esc** で閉じます。
- **+** と **−** で拡大・縮小、**Ctrl+0**（**⌘0**）で 100% に戻ります。
- **Markdown として編集** を選ぶと、書き込める文書として開きます。
