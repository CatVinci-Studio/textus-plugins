# Word-Leser

Lesen Sie Word-Dokumente (.docx) in einem Tab, so gesetzt wie in Word.

- Öffnen Sie eine .docx-Datei aus der Seitenleiste oder ziehen Sie sie ins Fenster.
- Sie wird schreibgeschützt angezeigt, mit Layout, Tabellen und Bildern; die Leiste zeigt, auf welcher Seite Sie sind.
- **Strg+F** (**⌘F** auf dem Mac) oder die Suchtaste findet Wörter und zählt die Treffer: **Eingabe** springt zum nächsten, **Umschalt+Eingabe** zum vorherigen, **Esc** schließt.
- Die Zoomtasten oder **Strg+Plus** und **Strg+Minus** (**⌘** auf dem Mac) zoomen zwischen 50 % und 200 %. **Strg+0** (**⌘0**) oder ein Klick auf die Prozentzahl führt zurück zu 100 %.
- **Als Markdown bearbeiten** übergibt die Datei an Textus, das daraus ein Markdown-Dokument macht, in dem Sie schreiben können.
- Kann eine Datei nicht gelesen werden, sagt der Tab das.

Das Plugin fragt nach keinen Berechtigungen: Es liest nur die Datei, die Sie damit öffnen. Es läuft auf dem Desktop sowie auf iPhone und iPad.
