# Word-Leser

Word-Dokumente, wie sie in Word aussehen, in einem Tab.

- Öffne eine .docx über die Seitenleiste oder ziehe eine ins Fenster.
- Sie wird schreibgeschützt angezeigt, mit Layout, Tabellen und Bildern; die Leiste zeigt, auf welcher Seite du bist.
- **Ctrl+F** (**⌘F** auf dem Mac) oder **⌕** sucht nach Wörtern: **Enter** springt zum nächsten Treffer, **Shift+Enter** zum vorherigen, **Esc** schließt.
- **+** und **−** zoomen, **Ctrl+0** (**⌘0**) setzt auf 100 % zurück.
- **Als Markdown bearbeiten** öffnet sie als Dokument, in dem du schreiben kannst.
