# 템플릿

내가 만든 템플릿으로 새 문서를 만들고 조각을 넣습니다. 날짜, 시간, 제목은 자동으로 채워집니다.

템플릿은 연 폴더의 **Templates** 폴더에 있는 Markdown 파일입니다(Obsidian 보관함에서는 템플릿 설정에 지정된 폴더). 그래서 노트와 함께 어디든 갑니다. 아직 하나도 없으면 먼저 **회의록** 템플릿을 만듭니다.

- **플러그인 › 템플릿으로 새로 만들기…**는 템플릿으로 연 폴더 맨 위에 문서를 만듭니다. 이름을 묻고, 같은 이름의 문서가 이미 있으면 만들지 않습니다.
- **플러그인 › 템플릿 넣기…**나 슬래시 메뉴의 **템플릿 넣기…**는 커서 위치에 템플릿을 넣습니다.
- **플러그인 › 템플릿으로 저장…**은 앞에 있는 문서를 템플릿으로 저장합니다. 이미 있는 이름에는 번호를 붙이고, 아무것도 덮어쓰지 않습니다.

## 채워지는 것

- 템플릿을 쓸 때 `{{date}}`, `{{time}}`, `{{title}}`이 채워집니다. `{{date:YYYY-MM-DD}}`와 `{{time:HH:mm}}`처럼 형식을 지정할 수 있습니다(Obsidian과 같음).
- Obsidian 보관함에서는 `{{date}}`와 `{{time}}`이 보관함 템플릿 설정의 날짜·시간 형식을 따릅니다.
- Templater의 자주 쓰는 태그도 채워집니다: `<% tp.date.now("YYYY-MM-DD") %>`(`-1` 같은 일수나 `"P1W"`로 옮길 수 있음), `tp.date.today`, `tomorrow`, `yesterday`, `<% tp.file.title %>`, `tp.file.creation_date()`, `tp.file.folder()`. `<% tp.file.cursor() %>` 자리에 커서를 둡니다.
- 스크립트와 다른 태그는 실행하지 않습니다. 쓴 그대로 두고 알림으로 이름을 알려 줍니다.

데스크톱과 iPhone에서 쓸 수 있고 Textus 1.3.10 이상이 필요합니다. 템플릿과 새 문서를 위해 연 폴더의 파일 읽기와 쓰기를, 템플릿을 넣거나 저장하기 위해 앞에 있는 문서의 읽기와 편집을 요청합니다. 또 Textus AI에 아래 두 도구를 줍니다.

## 변경 내역

- **0.5.1** - 파일이나 폴더의 오른쪽 클릭 메뉴에서 **템플릿으로 새로 만들기…**를 고르면 그 폴더에 만들어짐.
- **0.5.0** - 템플릿을 Textus가 직접 채웁니다. 데일리 노트와 같은 방식입니다. Textus 1.3.10 필요.
- **0.4.1** - 템플릿을 자연스러운 순서(2가 10보다 앞)로 나열합니다.
- **0.4.0** - Templater의 자주 쓰는 `tp.date`와 `tp.file` 태그, Obsidian 보관함 템플릿 설정의 날짜·시간 형식. 실행하지 않은 태그는 알림으로 알려 줍니다.
- **0.3.0** - 템플릿이 Templates 폴더(Obsidian에서는 보관함의 템플릿 폴더)의 Markdown 파일이 됩니다. 예전 버전이 저장한 것은 한 번 옮깁니다. `{{date:형식}}`과 `{{time:형식}}`.
- **0.2.0** - Textus AI가 템플릿 목록을 보고 템플릿으로 문서를 만들 수 있습니다.
- **0.1.3** - 실행되는 곳을 밝힘: 데스크톱과 iPhone.
- **0.1.2** - 템플릿으로 새로 만들기가 이미 있는 이름을 거절합니다.
- **0.1.0-0.1.1** - 첫 버전: 새 문서, 조각 넣기, 템플릿으로 저장, `{{date}}`, `{{time}}`, `{{title}}`. 스토어 페이지와 아이콘.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `list_templates`: 사용자의 문서 템플릿을 이름과 Markdown과 함께 나열합니다. 쓸 때 {{date}}, {{time}}, {{title}}과 Templater의 tp.date, tp.file 태그가 채워집니다.
- `create_from_template`: 사용자의 템플릿으로 열린 폴더에 새 문서를 만들고 {{date}}, {{time}}, {{title}}과 Templater의 tp.date, tp.file 태그를 채웁니다. 경로와, 그대로 둔 태그(notRun)를 돌려줍니다.
