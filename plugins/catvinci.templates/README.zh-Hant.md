# 範本

用自己的範本新增文件或插入片段，自動填好日期、時間和標題。

- **從範本新增…** 在打開的資料夾裡用範本新增文件；**插入範本…**（或在內文輸入 `/`）把範本插到游標處。
- **存為範本…** 把目前的文件存成範本。
- 範本裡的 `{{date}}`、`{{time}}`、`{{title}}` 使用時會自動填好。一開始內建一個「會議記錄」範本。

## Textus AI 工具

裝上這個外掛後，Textus AI 在對話中可以使用：

- `list_templates`：列出使用者的文件範本，每個附名稱和 Markdown 內容；使用時其中的 {{date}}、{{time}} 和 {{title}} 會被填入。
- `create_from_template`：用使用者的某個範本在開啟的資料夾中新建一份文件，並填入 {{date}}、{{time}} 和 {{title}}。回傳它的路徑。
