# 模板

用自己的模板新建文档或插入片段，自动填好日期、时间和标题。

- **从模板新建…** 在打开的文件夹里用模板新建文档；**插入模板…**（或在正文输入 `/`）把模板插到光标处。
- **存为模板…** 把当前文档存成模板。
- 模板里的 `{{date}}`、`{{time}}`、`{{title}}` 使用时会自动填好。一开始自带一个「会议记录」模板。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `list_templates`：列出用户的文档模板，每个带名称和 Markdown 内容；使用时其中的 {{date}}、{{time}} 和 {{title}} 会被填入。
- `create_from_template`：用用户的某个模板在打开的文件夹中新建一篇文档，并填入 {{date}}、{{time}} 和 {{title}}。返回它的路径。
