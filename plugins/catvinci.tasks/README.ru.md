# Задачи

Все задачи вашей папки в одном списке.

- Напишите задачу где угодно в виде `- [ ] что-то сделать`.
- Вкладка **Задачи** на боковой панели показывает задачи из всех документов открытой папки.
- Отметьте задачу там же или нажмите на неё, чтобы перейти к ней в документе.
- Показывать ли выполненные задачи, настраивается в параметрах плагина.
- Укажите у задачи дату (`📅 2026-11-01` или `due:2026-11-01`), и она появится в виде значка; просроченные задачи и те, срок которых наступает в течение недели, показываются первыми, в разделе **Скоро срок**.
- Поле вверху фильтрует список по словам, по названию документа или по его заголовку.
- Карточки канбан-доски (`имя.kanban.md`) остаются на доске и в список не попадают.

## Инструменты для Textus AI

Когда плагин установлен, Textus AI может пользоваться ими в разговоре:

- `list_tasks`: Перечисляет задачи Markdown (- [ ] ...) в документах открытой папки - по умолчанию только незавершённые - с текстом, сроком, путём к документу и номером строки. Фильтрует по состоянию, документу, тегу, сроку и словам.
- `add_task`: Добавляет задачу (- [ ] ...) в документ открытой папки: в конец или в конец раздела под заголовком, со сроком, если он задан. Создаёт документ, если его нет. Возвращает, куда она попала.
- `complete_task`: Отмечает задачу выполненной (- [x]) - или, при done false, снова открывает её - по пути документа и строке, как их даёт list_tasks.
