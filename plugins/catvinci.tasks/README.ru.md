# Задачи

Все задачи вашей папки в одном списке.

- Напишите задачу где угодно в виде `- [ ] что-то сделать`.
- Вкладка **Задачи** на боковой панели показывает задачи из всех документов открытой папки.
- Отметьте задачу там же или нажмите на неё, чтобы перейти к ней в документе.
- Показывать ли выполненные задачи, настраивается в параметрах плагина.
- Укажите у задачи дату (`📅 2026-11-01` или `due:2026-11-01`), и она появится в виде значка; просроченные задачи и те, срок которых наступает в течение недели, показываются первыми, в разделе **Скоро срок**.
- Поле вверху фильтрует список по словам, по названию документа или по его заголовку.
