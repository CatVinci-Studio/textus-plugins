# 任务

把文件夹里所有任务集中到一个列表。

- 在任何文档里写 `- [ ] 要做的事` 就是一条任务。
- 侧边栏的 **任务** 标签列出当前文件夹所有文档里的任务。
- 在那里直接勾选完成，或点一下跳到它所在的文档。
- 要不要显示已完成的任务，在插件设置里改。
- 给任务写上日期（`📅 2026-11-01` 或 `due:2026-11-01`），旁边会显示日期标签；已过期和 7 天内到期的任务会集中列在最上面的 **即将到期** 里。
- 顶部的输入框按文字、文档名或所在标题筛选任务。
- 看板（`名称.kanban.md`）上的卡片交给看板，不列在这里。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `list_tasks`：列出打开的文件夹中各文档里的 Markdown 任务（- [ ] ...），默认只列未完成的；每项带文字、截止日期、文档路径和行号。可按状态、文档、标签、截止日期和关键词筛选。
- `add_task`：在打开的文件夹中的某个文档里添加一条任务（- [ ] ...）：加在文末，或某个标题下那一节的末尾；可带截止日期。文档不存在时会新建。返回任务所在位置。
- `complete_task`：按 list_tasks 给出的文档路径和行号，把一条任务勾为完成（- [x]）；done 为 false 时则改回未完成。
