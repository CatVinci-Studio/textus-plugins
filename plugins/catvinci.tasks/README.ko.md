# 할 일

폴더 안의 모든 할 일을 한 목록에 모읍니다.

- 어디서든 `- [ ] 할 일`이라고 쓰면 할 일이 됩니다.
- 사이드바의 **할 일** 탭에 연 폴더 안 모든 문서의 할 일이 나옵니다.
- 거기서 바로 체크해 끝내거나, 클릭해서 그 문서의 해당 위치로 이동합니다.
- 끝난 할 일을 보일지는 플러그인 설정에서 바꿀 수 있습니다.
- 할 일에 날짜(`📅 2026-11-01` 또는 `due:2026-11-01`)를 적으면 배지로 표시되고, 기한이 지났거나 일주일 안에 다가온 할 일은 맨 위의 **곧 마감**에 먼저 나옵니다.
- 맨 위의 입력란으로 단어, 문서 이름, 제목에 따라 목록을 걸러 낼 수 있습니다.
- 칸반 보드(`이름.kanban.md`)의 카드는 보드에 맡기고 목록에 넣지 않습니다.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `list_tasks`: 열린 폴더의 문서에 있는 Markdown 작업(- [ ] ...)을 나열합니다. 기본으로 미완료 작업만 보여 주며, 각각 내용·마감일·문서 경로·줄 번호가 붙습니다. 상태·문서·태그·마감일·단어로 거를 수 있습니다.
- `add_task`: 열린 폴더의 문서에 작업(- [ ] ...)을 추가합니다. 문서 끝이나 제목 아래 구역의 끝에 넣고, 마감일이 있으면 붙입니다. 문서가 없으면 만듭니다. 추가된 위치를 돌려줍니다.
- `complete_task`: list_tasks가 알려 준 문서 경로와 줄 번호로 작업을 완료(- [x])로 표시합니다. done을 false로 하면 다시 미완료로 돌립니다.
