# Notion 导入

把 Notion 导出的内容搬进 Textus，变成普通的 Markdown 文件：页面和子页面、图片和附件、页面之间的链接，以及数据库。

1. 在 Notion 里选「设置 › 导出所有工作区内容」，格式选「Markdown 和 CSV」，包含子页面。把得到的 .zip（或解压后的文件夹）放进 Textus 打开的文件夹。
2. 选「插件 › 从 Notion 导入…」（或在侧边栏右键这个 .zip），选中导出文件。大工作区导出时 zip 里套着 Part-1.zip、Part-2.zip…，会当成一份打开。超过 256 MB 的 .zip 太大，没法一次读取：请把它连同里面的 Part zip 一起解压到打开的文件夹里的同一个文件夹，再选那个文件夹。
3. 给导入的文件夹起个名字（不填就叫「Notion」），已有的文件一个都不改。完成后打开一页导入报告。

转换结果：

- **页面**：`计划 1a2b….md` 和同名文件夹变成 `计划.md` 和 `计划/`，正好是「页面树」插件显示成树的结构，Notion 新旧两种导出格式都支持。数据库每一行的文档用完整标题命名（Notion 导出的文件名会截短）。两个页面同名时，标题不同就用各自的标题，否则后一个加「 2」。
- **图片和附件**：放进用到它的页面旁边的 `assets` 文件夹（新版导出把它们都放在一个 `attachments` 文件夹里）；没有页面用到的留在 `attachments`。Notion 把粘贴的图片都叫 image，这些图片改用所在页面的名字（「周会.png」「周会 2.png」），其他文件保留原名。即使设置了图床，导入的图片也留在本地。
- **链接**：页面之间、指向图片和附件的链接都跟着新名字改好。指向没有导出的页面的链接保持原样，列在报告里。
- **属性**：数据库每一行的页面标题下的属性行写进文档开头的属性（front matter）；其他页面里这样的行保持为正文。
- **数据库**：每一行变成文件夹里的一篇文档，属性写在开头：日期统一成 2026-01-04（英文、中文、日文、韩文、德文、法文、西班牙文、葡萄牙文和 ISO 格式都认），复选框成 true/false，数字成数字，多选成列表，关系成指向对应行文档的链接。旁边生成一页数据库视图：表格，有状态列时加看板，有日期列时加日历，放在数据库原页面的文字后面。别的页面里嵌着的数据库，在那里也直接显示，按导出时的排序。
- **标注（Callout）**变成提示块（`> [!NOTE]`），保留 emoji。折叠块保持 `<details>`。

带不过来的：Notion 的导出里没有页面图标、封面、评论和数据库视图的筛选条件（只有属性名），所以这些不会导入；视图的排序会带过来。公式和汇总属性保留导出时的值，分栏内容依次排开，内联数据库变成指向它那一页的链接，提及的人和日期成为普通文字。

报告里有导入的数量、没找到的链接、转换过的块，还会按导入的内容推荐有用的插件：子页面推荐「页面树」，数据库推荐「数据库视图」，互相链接的页面推荐「双向链接」和「快速预览」，等等。「插件 › Notion 导入后推荐的插件…」可以选一个安装，Textus 会先问你，不会自动安装。

全部在你的电脑上完成：插件只读写打开的文件夹里的文件，不联网。
