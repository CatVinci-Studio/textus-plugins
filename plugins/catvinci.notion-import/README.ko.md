# Notion 가져오기

Notion에서 내보낸 내용을 일반 Markdown 파일로 Textus에 가져옵니다. 페이지와 하위 페이지, 그림과 첨부 파일, 페이지 사이의 링크, 데이터베이스까지.

1. Notion에서 **설정 › 모든 워크스페이스 콘텐츠 내보내기**를 고르고 **Markdown 및 CSV**, 하위 페이지 포함으로 내보냅니다. 받은 .zip(또는 압축을 푼 폴더)을 Textus에서 연 폴더에 넣습니다.
2. **플러그인 › Notion에서 가져오기…**를 고르고(사이드바에서 .zip을 오른쪽 클릭해도 됩니다) 내보내기를 선택합니다. 큰 워크스페이스라 zip 안에 Part-1.zip, Part-2.zip…이 들어 있어도 하나로 엽니다. 256 MB가 넘는 .zip은 한 번에 읽을 수 없으니, 안에 있는 Part zip까지 열린 폴더 안의 한 폴더에 압축을 풀고 그 폴더를 고르세요.
3. 모든 내용은 새 폴더 **Notion 가져오기**와 날짜에 들어가며, 이미 있는 파일은 바꾸지 않습니다. 끝나면 보고서 페이지가 열립니다.

바뀌는 모습:

- **페이지**: `계획 1a2b….md`와 그 폴더는 `계획.md`와 `계획/`이 되어, 페이지 플러그인이 트리로 보여 주는 구조가 됩니다. 이름이 같은 페이지에는 " 2"가 붙습니다.
- **링크**: 페이지 사이, 그림과 첨부 파일로 가는 링크는 새 이름을 따라갑니다. 내보내지 않은 페이지로 가는 링크는 그대로 두고 보고서에 적습니다.
- **속성**: 데이터베이스 행 페이지의 제목 아래 속성 줄은 프론트매터로 들어갑니다. 다른 페이지의 그런 줄은 본문으로 남습니다.
- **데이터베이스**: 각 행은 폴더 안의 문서가 되고 속성은 프론트매터에 들어갑니다. 날짜는 2026-01-04로(영어, 중국어, 일본어, 한국어, 독일어, 프랑스어, 스페인어, 포르투갈어, ISO 형식 인식), 체크박스는 true/false, 숫자는 숫자, 다중 선택은 목록, 관계는 행 문서로 가는 링크가 됩니다. 옆에 데이터베이스를 표로 보여 주는 페이지를 만들고, 상태가 있으면 보드를, 날짜가 있으면 달력을 더합니다.
- **콜아웃**은 알림 블록(`> [!NOTE]`)이 되고 이모지는 남습니다. 토글은 `<details>` 그대로입니다.

가져오지 못하는 것: Notion 내보내기에는 페이지 아이콘, 커버, 댓글, 저장된 데이터베이스 보기(필터, 정렬)가 없어서 이것들은 넘어오지 않습니다. 수식과 롤업 속성은 내보낼 때의 값으로 남고, 열 레이아웃은 차례로 이어지며, 인라인 데이터베이스는 그 페이지로 가는 링크가 되고, 사람과 날짜 멘션은 일반 텍스트가 됩니다.

보고서에는 가져온 개수, 찾지 못한 링크, 바꾼 블록이 나오고, 가져온 내용에 도움이 되는 플러그인을 추천합니다. 하위 페이지에는 페이지, 데이터베이스에는 데이터베이스 보기, 서로 링크한 페이지에는 양방향 링크와 빠른 미리보기 등입니다. **플러그인 › Notion 가져오기 후 추천 플러그인…**에서 하나를 골라 설치할 수 있습니다. Textus가 먼저 묻고, 저절로 설치되는 것은 없습니다.

모든 작업은 내 컴퓨터에서 이루어집니다. 플러그인은 열린 폴더의 파일만 읽고 쓰며 네트워크를 쓰지 않습니다.
