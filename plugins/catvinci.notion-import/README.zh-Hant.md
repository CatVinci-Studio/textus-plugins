# Notion 匯入

把 Notion 匯出的內容搬進 Textus，變成普通的 Markdown 檔案：頁面和子頁面、圖片和附件、頁面之間的連結，以及資料庫。

1. 在 Notion 裡選「設定 › 匯出所有工作區內容」，格式選「Markdown 和 CSV」，包含子頁面。把得到的 .zip（或解壓後的資料夾）放進 Textus 開啟的資料夾。
2. 選「外掛程式 › 從 Notion 匯入…」（或在側邊欄右鍵這個 .zip），選取匯出檔案。大工作區匯出時 zip 裡套著 Part-1.zip、Part-2.zip…，會當成一份開啟。超過 256 MB 的 .zip 太大，沒辦法一次讀取：請把它連同裡面的 Part zip 一起解壓到開啟的資料夾裡的同一個資料夾，再選那個資料夾。
3. 所有內容放進一個新資料夾「Notion 匯入」加日期，已有的檔案一個都不改。完成後開啟一頁匯入報告。

轉換結果：

- **頁面**：`計畫 1a2b….md` 和同名資料夾變成 `計畫.md` 和 `計畫/`，正好是「頁面樹」外掛顯示成樹的結構。兩個頁面同名時後一個加「 2」。
- **連結**：頁面之間、指向圖片和附件的連結都跟著新名字改好。指向沒有匯出的頁面的連結保持原樣，列在報告裡。
- **屬性**：資料庫每一列的頁面標題下的屬性行寫進文件開頭的屬性（front matter）；其他頁面裡這樣的行保持為內文。
- **資料庫**：每一列變成資料夾裡的一篇文件，屬性寫在開頭：日期統一成 2026-01-04（英文、中文、日文、韓文、德文、法文、西班牙文、葡萄牙文和 ISO 格式都認），核取方塊成 true/false，數字成數字，多選成清單，關聯成指向對應列文件的連結。旁邊產生一頁資料庫檢視：表格，有狀態欄時加看板，有日期欄時加日曆。
- **標註（Callout）**變成提示區塊（`> [!NOTE]`），保留 emoji。摺疊區塊保持 `<details>`。

帶不過來的：Notion 的匯出裡沒有頁面圖示、封面、留言和儲存的資料庫檢視（篩選、排序），所以這些不會匯入。公式和彙總屬性保留匯出時的值，分欄內容依序排開，內嵌資料庫變成指向它那一頁的連結，提及的人和日期成為普通文字。

報告裡有匯入的數量、沒找到的連結、轉換過的區塊，還會依匯入的內容推薦有用的外掛：子頁面推薦「頁面樹」，資料庫推薦「資料庫檢視」，互相連結的頁面推薦「雙向連結」和「快速預覽」，等等。「外掛程式 › Notion 匯入後推薦的外掛…」可以選一個安裝，Textus 會先問你，不會自動安裝。

全部在你的電腦上完成：外掛只讀寫開啟的資料夾裡的檔案，不連網。
