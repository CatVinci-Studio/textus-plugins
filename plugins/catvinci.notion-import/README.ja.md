# Notion インポート

Notion のエクスポートを、ふつうの Markdown ファイルとして Textus に取り込みます。ページとサブページ、画像と添付ファイル、ページ間のリンク、データベースが対象です。

1. Notion で「設定 › ワークスペースのコンテンツをすべてエクスポート」を選び、「Markdown と CSV」でサブページも含めます。できた .zip（または展開したフォルダー）を Textus で開いているフォルダーに置きます。
2. 「プラグイン › Notion からインポート…」を選び（サイドバーで .zip を右クリックしても可）、エクスポートを選びます。大きなワークスペースで zip の中に Part-1.zip、Part-2.zip… がある場合も、ひとつとして開きます。256 MB を超える .zip は一度に読み込めないため、中の Part zip も含めて開いているフォルダー内の一つのフォルダーに展開し、そのフォルダーを選んでください。
3. すべて新しいフォルダー「Notion インポート」＋日付に入り、既存のファイルは変更しません。最後にレポートのページが開きます。

変換の内容：

- **ページ**：`計画 1a2b….md` とそのフォルダーは `計画.md` と `計画/` になり、「ページ」プラグインがツリーで表示する構成になります。同じ名前のページには「 2」が付きます。
- **リンク**：ページ間、画像や添付ファイルへのリンクは新しい名前に合わせて直します。エクスポートされなかったページへのリンクはそのまま残し、レポートに載せます。
- **プロパティ**：データベースの行のページで、タイトルの下にあるプロパティ行はフロントマターに入ります。ほかのページのそうした行は本文のままです。
- **データベース**：各行がフォルダー内の文書になり、プロパティはフロントマターに入ります。日付は 2026-01-04 に（英語、中国語、日本語、韓国語、ドイツ語、フランス語、スペイン語、ポルトガル語、ISO の形式に対応）、チェックボックスは true/false、数値は数値、マルチセレクトはリスト、リレーションは行の文書へのリンクになります。隣にデータベースを表で表示するページを作り、ステータスがあればボード、日付があればカレンダーも付けます。
- **コールアウト**は注記（`> [!NOTE]`）になり、絵文字は残ります。トグルは `<details>` のままです。

持ち込めないもの：Notion のエクスポートにはページのアイコン、カバー、コメント、保存したデータベースのビュー（フィルター、並べ替え）が含まれないため、これらは取り込まれません。数式とロールアップのプロパティはエクスポート時の値のまま、列レイアウトは順に並び、インラインデータベースはそのページへのリンクになり、人や日付のメンションはふつうのテキストになります。

レポートには、取り込んだ数、見つからなかったリンク、変換したブロックが載り、取り込んだ内容に役立つプラグインを提案します。サブページには「ページ」、データベースには「データベースビュー」、リンクし合うページには「双方向リンク」と「クイックプレビュー」などです。「プラグイン › Notion インポート後のおすすめプラグイン…」からひとつ選んでインストールできます。Textus が先に確認し、勝手にはインストールしません。

すべてお使いのコンピューターの中で行います。プラグインは開いているフォルダーのファイルだけを読み書きし、ネットワークは使いません。
