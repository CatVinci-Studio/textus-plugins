# Gemini CLI

Разговаривайте с Gemini CLI в Textus AI, с моделями Gemini от Google. Он читает открытую папку, пишет и правит ваши заметки и спрашивает перед каждым изменением: Textus показывает, что он хочет сделать, а вы разрешаете или нет. Всё, что он изменил, отмечено в документе и отменяется одним действием. Его режим (сначала спрашивать, принимать правки, принимать всё, план) и модель находятся в меню рядом с меню моделей Textus AI.

1. Установите [Node.js](https://nodejs.org), если его нет на этом компьютере.
2. Нажмите кнопку Gemini CLI в правом верхнем углу окна, рядом с кнопкой Textus AI. В первый раз откроется браузер для входа в аккаунт Google. Для ключа Gemini API или Vertex AI один раз выполните в терминале `npx @google/gemini-cli` и выберите нужное через `/auth` (Textus, открытый из Dock, не видит переменные, заданные в терминале).

Textus запускает [Gemini CLI](https://github.com/google-gemini/gemini-cli) командой `gemini --acp` — это его сервер Agent Client Protocol — с помощью `npx`. Аккаунт и расход относятся к Google; Textus не хранит для него ключ.

Режимы «принимать правки» и «принимать всё» работают только в папках, которым вы доверились в самом Gemini CLI; в остальных он остаётся в режиме «сначала спрашивать».

Нужен Textus 1.4.3 или новее. Плагин просит одно разрешение — запускать этого агента на этом компьютере.
