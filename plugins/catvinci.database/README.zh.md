# 知识库

页面里套页面，再把笔记做成表格、看板、日历、画廊和列表形式的数据库。数据库使用 **Obsidian 的 Bases 格式**，在 Obsidian 里也能打开同一个数据库；所有内容都是普通的 Markdown 文件。

## 页面

- **有子页面的页面是一个文件夹**：`Plans/Plans.md` 是页面本身，子页面放在同一个 `Plans/` 文件夹里，和 Obsidian 的“文件夹笔记”一样。输入 `/page`（或选「新建子页面…」）新建：第一个子页面会自动把 `Plans.md` 移进它的文件夹，指向它的链接跟着更新。
- **侧边栏的「页面」标签**把文件夹显示成页面树。右键一个页面可以新建子页面、重命名、设图标或移到废纸篓；把页面拖到另一个页面上，它就成了那个页面的子页面。移动后链接都会跟着更新。
- **页面树还是文件树？** 「页面」按页面和它下面的内容显示，和 Notion 一样；「文件」按磁盘上的文件和文件夹原样显示。两边是同一批文件，用哪个都行。
- **当前位置**：在子页面里，状态栏会显示上级页面，例如 `Life › 2026 Calendar › Week 1`。
- **在「文件」里改页面文件夹的名字**，里面的页面会跟着改名，仍然是一个带子页面的页面。
- **旧的结构**：`Plans.md` 旁边放一个 `Plans/` 文件夹装子页面，也照样能读。「整理为文件夹单元…」会先列出清单，再一次把它们都移进各自的文件夹。

## 数据库

数据库就是页面里的一个 `base` 代码块（或一个 `.base` 文件）：它的筛选条件选出笔记，每篇笔记是一行，笔记开头的属性就是各列。输入 `/database` 或选「新建数据库…」：会为数据库建一个文件夹，里面放一个装着这个代码块的页面。

````markdown
```base
filters:
  and:
    - file.inFolder(this.file.folder)
    - file.path != this.file.path
views:
  - type: kanban
    name: Board
    groupBy:
      property: status
    groupOrder: [To read, Reading, Read]
  - type: table
    name: Table
    limit: 25
```
````

- **视图**是代码块顶部的标签：表格、看板、日历、画廊和列表。点当前的那个标签打开它的菜单（换布局、重命名、删除）；点 **+** 添加视图。日历是 Textus 自己的，Obsidian 会把它当成不认识的视图。
- **每一行都是一篇笔记。** 点单元格修改，属性写进那篇笔记的开头；「新建」在数据库的文件夹里建一篇笔记；打开一行，会在数据库旁边打开它。
- **看板**：把卡片拖到另一列就改了它的值；拖动列头可以按你想要的顺序排列各列（`groupOrder`）。
- **筛选**、**排序**和每一列的菜单，都按 Bases 的写法存在视图里，例如 `status == "Read"`、`tags.contains("ml")`、`due.isEmpty()`。Textus 暂时读不懂的筛选会原样保留，并在工具栏下方说明。
- **很长的数据库**先显示前 25 行（或视图里设的 `limit`），下面的「再显示」按钮显示其余的。工具栏左边的箭头可以把数据库折叠成一行，只记在这台电脑上。
- **属性类型**在 Obsidian 库里使用 Obsidian 自己的 `.obsidian/types.json`。
- **在嵌入的笔记里**（`![[页面]]`），数据库只占一行，点一下才画出来。

Notion 的导出包请用「Notion 导入」插件导入，它写出的页面和数据库就由这个插件显示。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `create_database`：以 Obsidian 的 Bases 格式建一个数据库：一个文件夹，里面每篇笔记的开头属性就是它的各项属性；文件夹里再放一个页面，用 ```base 块把它们显示成表格、看板、日历、画廊或列表。返回这个页面的链接，放在用户想要的位置。
- `query_rows`：读取一个数据库的行：它的 base 选中的笔记（默认是它文件夹里的笔记），每行带名字、路径和属性，可筛选和排序。
- `add_row`：在数据库中添加一行：在其文件夹里新建一篇以该行命名的文档，各项属性写在开头属性中。展示该文件夹的每个块都会显示它。 只用于数据库文件夹（create_database、query_rows）；普通待办用 add_task。
- `create_page`：新建一个页面：在打开的文件夹顶层新建以该标题命名的文档，或在父页面旁的同名文件夹中新建子页面；可设图标。返回它的路径，以及要放进父页面的 [[链接]]。
