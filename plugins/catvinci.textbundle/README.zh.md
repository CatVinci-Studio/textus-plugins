# TextBundle

把 .textbundle 文件夹（Bear、Ulysses、iA Writer 存成的那种）当作一篇文档打开，图片就在旁边。

## 它做什么

- `.textbundle` 文件夹在侧边栏里显示为一篇文档。点开它，正文（`text.md`）在以文件夹名命名的标签里打开。
- 文件夹里 `assets/` 中的图片直接显示。
- 在侧边栏里移动、重命名或删除它，整个文件夹一起处理。

## 权限

不需要任何权限。它只告诉 Textus 哪些文件夹是文档，自己不读取任何东西。
