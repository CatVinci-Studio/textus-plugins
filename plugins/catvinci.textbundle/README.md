# TextBundle

Opens a .textbundle folder - as Bear, Ulysses and iA Writer save them - as one document, its pictures beside it.

## What it does

- A `.textbundle` folder shows in the sidebar as one document. Click it, and its text (`text.md`) opens in a tab named after the bundle.
- Pictures in the bundle's `assets/` show in place.
- Moving, renaming or deleting the bundle in the sidebar takes the whole folder along.

## Permissions

None. It only tells Textus which folders are documents; it reads nothing itself.
