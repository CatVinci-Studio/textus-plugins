# TextBundle

Bear、Ulysses、iA Writer が保存する .textbundle フォルダを、画像を隣に置いたまま 1 つの文書として開きます。

## できること

- `.textbundle` フォルダは、サイドバーに 1 つの文書として表示されます。クリックすると、本文（`text.md`）がバンドルの名前のタブで開きます。
- バンドルの `assets/` にある画像は、その場に表示されます。
- サイドバーでバンドルを移動、名前変更、削除すると、フォルダごとまとめて扱われます。

## 権限

ありません。どのフォルダが文書かを Textus に伝えるだけで、自分では何も読みません。
