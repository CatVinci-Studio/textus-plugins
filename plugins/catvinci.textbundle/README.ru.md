# TextBundle

Открывает папку .textbundle — в таком виде их сохраняют Bear, Ulysses и iA Writer — как один документ, с картинками рядом.

## Что он делает

- Папка `.textbundle` показывается на боковой панели как один документ. Щёлкните по ней, и её текст (`text.md`) откроется во вкладке с именем пакета.
- Картинки из `assets/` пакета показываются на своих местах.
- Если переместить, переименовать или удалить пакет на боковой панели, вся папка переместится, переименуется или удалится вместе с ним.

## Разрешения

Не нужны. Плагин только сообщает Textus, какие папки являются документами; сам он ничего не читает.
