# 日曆與每日筆記

每天一篇筆記，用日曆隨時回到任何一天。

- 按 **Ctrl+Alt+J**（Mac 上為 **⌘⌥J**），或選擇 **外掛程式 › 開啟今天的筆記**，就會開啟今天的筆記；第一次會自動建立。
- 側邊欄的 **日曆** 分頁會顯示當月，有筆記的日子會標示出來。點選哪一天就開啟哪一天。
- 筆記存放在開啟的資料夾裡的一個子資料夾中。資料夾名稱和新一天筆記的開頭內容可以在外掛程式的設定中修改；每週從哪天開始依系統地區而定。
- **外掛程式 › 開啟前一天的筆記** 和 **開啟後一天的筆記**，可以從某天的筆記跳到前後一天。
- 範本裡除了 {{date}}，還能用 {{weekday}}、{{yesterday}}、{{tomorrow}} 和 {{time}}；例如寫 `[[{{yesterday}}]]`，每天的筆記就會連結到前一天。
- 開頭文字也可以寫 Templates 資料夾（範本外掛用的那個）裡某個範本的名字，例如 `Daily`。在 Obsidian 庫裡，依庫自己的日記設定：資料夾、`YYYY/MM/YYYY-MM-DD` 這樣的命名格式和範本；Textus 不會改這些設定。

## Textus AI 工具

裝上這個外掛後，Textus AI 在對話中可以使用：

- `read_daily_note`：讀取某一天的日記（預設今天）：從日記資料夾中給出它的路徑、是否存在以及全文。
- `append_to_daily_note`：在某一天的日記（預設今天）末尾附加 Markdown 內容；如果還沒有這篇日記，先依範本新建。
