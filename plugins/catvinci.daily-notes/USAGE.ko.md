# 달력과 데일리 노트

하루에 한 편씩 노트를 쓰고, 달력으로 어느 날이든 찾아갑니다.

- **Ctrl+Alt+D**(Mac에서는 **⌘⌥D**)를 누르거나 **플러그인 › 오늘의 노트 열기**를 선택하면 오늘의 노트가 열립니다. 처음 열 때 자동으로 만들어집니다.
- 사이드바의 **달력** 탭에 이번 달이 표시되고, 노트가 있는 날에는 표시가 붙습니다. 날짜를 클릭하면 그날의 노트가 열립니다.
- 노트는 연 폴더 안의 하위 폴더에 보관됩니다. 폴더 이름, 새 날의 시작 내용, 한 주의 시작 요일은 플러그인 설정에서 바꿀 수 있습니다.
