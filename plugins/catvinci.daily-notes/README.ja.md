# カレンダーとデイリーノート

一日にひとつのノートと、どの日にも行けるカレンダー。

- **Ctrl+Alt+J**（Mac では **⌘⌥J**）か **プラグイン › 今日のノートを開く** で、今日のノートが開きます。初回は自動で作られます。
- サイドバーの **カレンダー** タブに月が表示され、ノートのある日には印が付きます。日をクリックするとそのノートが開きます。
- ノートは、開いているフォルダの中のフォルダに保存されます。フォルダ名と新しい日の書き出しはプラグインの設定で変えられます。週の始まりはお使いの地域に合わせます。
- **プラグイン › 前の日のノートを開く** と **次の日のノートを開く** で、その日のノートから前後の日へ移れます。
- テンプレートには {{date}} のほか、{{weekday}}、{{yesterday}}、{{tomorrow}}、{{time}} も使えます。たとえば `[[{{yesterday}}]]` と書くと、各日のノートが前の日にリンクします。
- 書き始めの文字には、Templates フォルダ（テンプレートプラグインのもの）にあるテンプレートの名前（`Daily` など）も使えます。Obsidian の保管庫では、保管庫のデイリーノート設定（フォルダ、`YYYY/MM/YYYY-MM-DD` のような名前の書式、テンプレート）に従います。Textus がそれを変えることはありません。設定がない保管庫では、Obsidian と同じくノートを保管庫の一番上に置きます。`{{date}}`・`{{yesterday}}`・`{{tomorrow}}` はノートの名前の書式で書かれ、`MMMM Do, YYYY` などの Moment の書式も使えます。

## Textus AI のツール

このプラグインを入れると、Textus AI が会話の中で使えます：

- `read_daily_note`：ある日のデイリーノート（日付がなければ今日）をデイリーノートのフォルダから読みます。パス、あるかどうか、本文を返します。
- `append_to_daily_note`：ある日のデイリーノート（日付がなければ今日）の末尾に Markdown を書き足します。ノートがなければ先にテンプレートから作ります。 あとで使うためサイドバーに置くメモは add_note、日付付きの ToDo は add_task です。
