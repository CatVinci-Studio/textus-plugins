# カレンダーとデイリーノート

一日にひとつのノートと、どの日にも行けるカレンダー。

- **Ctrl+Alt+D**（Mac では **⌘⌥D**）か **プラグイン › 今日のノートを開く** で、今日のノートが開きます。初回は自動で作られます。
- サイドバーの **カレンダー** タブに月が表示され、ノートのある日には印が付きます。日をクリックするとそのノートが開きます。
- ノートは、開いているフォルダの中のフォルダに保存されます。フォルダ名、新しい日の書き出し、週の始まりはプラグインの設定で変えられます。
- **プラグイン › 前の日のノートを開く** と **次の日のノートを開く** で、その日のノートから前後の日へ移れます。
- テンプレートには {{date}} のほか、{{weekday}}、{{yesterday}}、{{tomorrow}}、{{time}} も使えます。たとえば `[[{{yesterday}}]]` と書くと、各日のノートが前の日にリンクします。
