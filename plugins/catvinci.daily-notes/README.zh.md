# 日历与每日笔记

每天一篇笔记，用日历随时回到任何一天。

- 按 **Ctrl+Alt+D**（Mac 上 **⌘⌥D**），或 **插件 › 打开今天的笔记**，打开今天的笔记；第一次会自动新建。
- 侧边栏的 **日历** 标签显示当月，有笔记的日子会标出来。点哪天就打开哪天。
- 笔记放在当前文件夹下的一个子文件夹里。文件夹名和新一天的开头内容在插件设置里改；一周从哪天开始跟随系统地区。
- **插件 › 打开前一天的笔记** 和 **打开后一天的笔记**，可以从某天的笔记跳到前后一天。
- 模板里除了 {{date}}，还能用 {{weekday}}、{{yesterday}}、{{tomorrow}} 和 {{time}}；比如写 `[[{{yesterday}}]]`，每天的笔记就会链接到前一天。
