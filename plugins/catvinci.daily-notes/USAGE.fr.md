# Calendrier et notes du jour

Une note par jour, et un calendrier pour accéder à chacune.

- **Ctrl+Alt+D** (**⌘⌥D** sur Mac), ou **Extensions › Ouvrir la note du jour**, ouvre la note d’aujourd’hui ; elle est créée la première fois.
- L’onglet **Calendrier** de la barre latérale affiche le mois ; les jours qui ont une note sont marqués. Cliquez sur un jour pour l’ouvrir.
- Les notes sont rangées dans un dossier du dossier ouvert. Son nom, le texte de départ d’un nouveau jour et le premier jour de la semaine se règlent dans les réglages de l’extension.
