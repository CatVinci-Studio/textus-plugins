# Espacement CJK

Met une espace entre le texte chinois ou japonais et les lettres latines ou les chiffres.

- **Ajouter des espaces entre CJK et latin** (clic droit ou le menu Plugins) : 用Textus写作 devient 用 Textus 写作, en une étape d’annulation.
- Activez **Aussi à l’enregistrement** dans ses réglages pour le faire à chaque enregistrement.
- Le code, les formules, les liens, les #tags, les rappels (@…), les commentaires %% et le HTML restent tels quels, à l’enregistrement aussi.
- Ce qu’écrit Obsidian aussi : identifiants de bloc (^1a2b3c), champs Dataview (key:: value), ==surlignages== et champs d’Obsidian Tasks (📅 2026-11-07).

## Outils pour Textus AI

Une fois le plugin installé, Textus AI peut s’en servir dans une conversation :

- `fix_cjk_spacing`: Met une espace entre les caractères chinois ou japonais et les lettres latines ou les chiffres d'un Markdown, sans toucher au code ni aux liens, comme la commande de l'extension. Renvoie le texte espacé ; n'écrit rien.
