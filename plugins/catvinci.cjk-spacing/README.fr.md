# Espacement CJK

Met une espace entre le texte chinois ou japonais et les lettres latines ou les chiffres.

- **Ajouter des espaces entre CJK et latin** (clic droit ou le menu Plugins) : 用Textus写作 devient 用 Textus 写作, en une étape d’annulation.
- Activez **Aussi à l’enregistrement** dans ses réglages pour le faire à chaque enregistrement.
- Le code, les formules, les adresses de liens et le HTML restent tels quels.
