# Espaçamento CJK

Coloca um espaço entre texto chinês ou japonês e letras latinas ou números.

- **Adicionar espaços entre CJK e latim** (clique direito ou o menu Plugins): 用Textus写作 vira 用 Textus 写作, num passo de desfazer.
- Ative **Também ao salvar** nos ajustes para fazer isso a cada salvamento.
- Código, fórmulas, links, #tags, lembretes (@…), comentários %% e HTML ficam como estão, também ao salvar.

## Ferramentas para o Textus AI

Com o plugin instalado, o Textus AI pode usá-las numa conversa:

- `fix_cjk_spacing`: Põe um espaço entre caracteres chineses, japoneses ou coreanos e letras latinas ou algarismos num Markdown, sem mexer no código nem nos links, como o comando do plugin. Devolve o texto espaçado; não escreve nada.
