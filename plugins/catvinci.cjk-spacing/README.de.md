# CJK-Abstände

Setzt ein Leerzeichen zwischen chinesischen oder japanischen Text und lateinische Buchstaben oder Ziffern.

- **Leerzeichen zwischen CJK und Latein einfügen** (Rechtsklick oder das Plugins-Menü): Aus 用Textus写作 wird 用 Textus 写作 – mit einem Schritt rückgängig.
- Schalten Sie in den Einstellungen **Auch beim Speichern** ein, damit jedes Dokument beim Speichern angepasst wird.
- Code, Formeln, Linkadressen und HTML bleiben, wie sie sind.

## Werkzeuge für Textus AI

Ist das Plugin installiert, kann Textus AI sie im Gespräch nutzen:

- `fix_cjk_spacing`: Setzt in Markdown ein Leerzeichen zwischen chinesische, japanische oder koreanische Zeichen und lateinische Buchstaben oder Ziffern, Code und Links ausgenommen, wie der Befehl des Plugins. Gibt den Text zurück; schreibt nichts.
