# CJK Spacing

Puts a space between Chinese or Japanese text and Latin letters or numbers.

- **Add Spaces Between CJK and Latin** (right-click, or the Plugins menu): 用Textus写作 becomes 用 Textus 写作, as one undo step.
- Turn on **Also when saving** in its settings to space every document as it is saved.
- Code, formulas, links, #tags, reminders (@…), %% comments and HTML are left as they are - on save too.

<!-- ai-tools -->
## Tools for Textus AI

Once it is installed, Textus AI can use these in a conversation:

- `fix_cjk_spacing`: Puts a space between Chinese, Japanese or Korean characters and Latin letters or digits in some Markdown, leaving code and links alone, as the plugin's command does. Returns the spaced text; writes nothing.
