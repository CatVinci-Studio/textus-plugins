# 和欧文スペース

中国語・日本語の文字と英字や数字の間にスペースを入れます。

- **和文と欧文の間にスペースを入れる**（右クリックまたは「プラグイン」メニュー）：「Textusで書く」が「Textus で書く」になります。1 回で取り消せます。
- 設定で **保存時にも入れる** をオンにすると、保存のたびに整えます。
- コード、数式、リンク、#タグ、リマインダー (@…)、%% コメント、HTML はそのままです。保存時も同じです。

## Textus AI のツール

このプラグインを入れると、Textus AI が会話の中で使えます：

- `fix_cjk_spacing`：Markdown の中で、中国語・日本語・韓国語の文字と英字・数字の間に空白を入れます。コードとリンクはそのままで、プラグインのコマンドと同じです。空白を入れた文章を返し、何も書き込みません。
