# 中英文间距

在中文、日文与英文字母或数字之间加上空格。

- **在中英文之间加空格**（右键菜单或「插件」菜单）：「用Textus写作」变成「用 Textus 写作」，可以一步撤销。
- 在它的设置里打开 **保存时也自动加**，每次保存都会自动调整。
- 代码、公式、链接、#标签、提醒 (@…)、%% 批注和 HTML 保持原样，保存时也一样。
- Obsidian 的写法也保持原样：块 id（^1a2b3c）、Dataview 字段（key:: value）、==高亮== 和 Obsidian Tasks 的字段（📅 2026-11-07）。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `fix_cjk_spacing`：在一段 Markdown 中给中日韩文字与英文字母、数字之间加上空格，代码和链接保持不变，和插件命令的做法一样。返回处理后的文本，不写入任何文件。
