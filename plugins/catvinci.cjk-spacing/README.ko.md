# CJK·영문 간격

중국어·일본어 글자와 영문자나 숫자 사이에 공백을 넣습니다.

## 문서에 공백 넣기

- **플러그인 › CJK와 영문 사이에 공백 넣기**를 고르거나, 오른쪽 클릭 메뉴에서 같은 항목을 고릅니다. 「用Textus写作」가 「用 Textus 写作」가 됩니다. 문서 전체의 변경을 한 번에 되돌릴 수 있고, 고친 곳의 수를 알려 줍니다.
- 플러그인 설정에서 **저장할 때도 넣기**를 켜면 저장할 때마다 맞춥니다. 문단·제목·목록 같은 본문만 바뀝니다.
- 한글은 건드리지 않습니다. 한국어는 원래 단어 사이를 띄어 씁니다.

## 그대로 두는 것

- 코드, 수식, 링크와 위키 링크, 각주, #태그, 알림 (@…), %% 주석, HTML, front matter. 저장할 때도 마찬가지입니다.
- Obsidian의 문법: 블록 ID(^1a2b3c), Dataview 필드(key:: value), ==하이라이트==, Obsidian Tasks의 필드(📅 2026-11-07).

## 권한

- **문서 읽기와 편집**: 지금 문서에 공백을 넣기 위해.
- **파일 쓰기**: **저장할 때도 넣기**가 켜져 있을 때 저장하면서 문서를 맞추기 위해.
- **Textus AI 도구**: Textus AI가 글에 공백을 넣어 줄 수 있도록.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `fix_cjk_spacing`: Markdown에서 중국어·일본어 문자와 라틴 문자·숫자 사이에 공백을 넣습니다. 코드와 링크는 그대로 두며 플러그인 명령과 같습니다. 공백을 넣은 글을 돌려주고 아무것도 쓰지 않습니다.
