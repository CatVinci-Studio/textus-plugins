# CJK·영문 간격

중국어·일본어 글자와 영문자나 숫자 사이에 공백을 넣습니다.

- **CJK와 영문 사이에 공백 넣기**(오른쪽 클릭 또는 플러그인 메뉴): 「用Textus写作」가 「用 Textus 写作」가 됩니다. 한 번에 되돌릴 수 있습니다.
- 설정에서 **저장할 때도 넣기**를 켜면 저장할 때마다 맞춥니다.
- 코드, 수식, 링크, #태그, 알림 (@…), %% 주석, HTML은 그대로 둡니다. 저장할 때도 마찬가지입니다. 한글은 건드리지 않습니다.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `fix_cjk_spacing`: Markdown에서 한중일 문자와 라틴 문자·숫자 사이에 공백을 넣습니다. 코드와 링크는 그대로 두며 플러그인 명령과 같습니다. 공백을 넣은 글을 돌려주고 아무것도 쓰지 않습니다.
