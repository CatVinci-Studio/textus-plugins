# 中英文間距

在中文、日文與英文字母或數字之間加上空格。

- **在中英文之間加空格**（右鍵選單或「外掛」選單）：「用Textus寫作」變成「用 Textus 寫作」，可以一步復原。
- 在它的設定裡開啟 **儲存時也自動加**，每次儲存都會自動調整。
- 程式碼、公式、連結、#標籤、提醒 (@…)、%% 註解和 HTML 保持原樣，儲存時也一樣。

## Textus AI 工具

裝上這個外掛後，Textus AI 在對話中可以使用：

- `fix_cjk_spacing`：在一段 Markdown 中為中日韓文字與英文字母、數字之間加上空格，程式碼和連結保持不變，和外掛命令的做法一樣。回傳處理後的文字，不寫入任何檔案。
