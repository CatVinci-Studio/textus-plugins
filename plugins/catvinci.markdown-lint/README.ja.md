# Markdown チェック

よくあるスタイル規則に合わない Markdown に波線を引き、直せるものは一度に直します。

- 規則に合わない箇所に波線が引かれます。ポインタを置くと、どの規則か、理由が表示されます。
- **Markdown を修正**（右クリックまたは「プラグイン」メニュー）で直せるものを一度に直します。1 回で取り消せます。
- #タグ、参照定義（[d]: url）、見出しへのリンク、%% コメントは指摘も変更もしません。

## Textus AI のツール

このプラグインを入れると、Textus AI が会話の中で使えます：

- `lint_markdown`：Markdown（渡された文章か前面の文書）を、エディタが下線で示すのと同じ markdownlint の規則で検査します。各問題の行・規則・説明・自動修正できるかを返し、fix を指定すると修正後の文章も返します。それ自体は何も変更しません。
