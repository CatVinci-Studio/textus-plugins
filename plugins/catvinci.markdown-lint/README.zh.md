# Markdown 检查

给不合常见规范的 Markdown 画上波浪线，能修的一键修好。

- 不合规范的地方会画波浪线；把指针停在上面，可以看到是哪条规则、为什么。
- **修正 Markdown**（右键菜单或「插件」菜单）把能修的一次修好，可以一步撤销。
- #标签、引用链接定义（[d]: url）、指向标题的链接和 %% 批注，不会标出，也不会改动。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `lint_markdown`：用 markdownlint 的规则检查 Markdown（给定的文本或当前文档），与编辑器中划线提示的一致：每个问题的行号、规则、说明以及能否自动修复；设 fix 时还返回修复后的文本。本身不改动任何内容。
