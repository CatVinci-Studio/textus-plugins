# 整理

给不合常见规范的 Markdown 画波浪线并一键修正，还能整理空行、空格、标点和换行。

用法类似 Obsidian 的 Linter，每次改动都可以一步撤销。

## Markdown

- 不合常见规范的地方会画波浪线；把指针停在上面，可以看到是哪条规则、为什么。
- **修正 Markdown**（右键菜单或「插件」菜单）把能修的一次修好。
- 每个块单独检查，所以针对整篇文档的规则（标题层级、第一行、块之间的空行）不检查。

## 文字

每个命令都作用于选中的文字；没有选中时，先问一句，再整理整篇文档。在「插件」菜单或命令面板里找到它们。

- **删除空行**：删掉空段落；在选中的文字里，所有空行都删掉。
- **删除行尾空格**：删掉行尾的空格和制表符；用来换行的两个空格保留。
- **中文里改用中文标点**：「你好,世界?」变成「你好，世界？」。1.3.8 这样的小数和英文句子不变。
- **英文里改用英文标点**：「Hello，world！」变成「Hello, world!」；挨着中文的标点不变。
- **全角字母数字转半角**：「ＡＢＣ１２３」变成「ABC123」。
- **合并选中的行**（右键菜单里也有）：选中的几行合成一行，中文之间不加空格，英文单词之间加一个空格。

## 设置

- **给不合规范的 Markdown 画波浪线**：关掉后不再画线，「修正 Markdown」照常可用。
- **不检查的规则**：markdownlint 的规则，一行一条（MD009 或 no-trailing-spaces），既不画线也不修正。

## 保持原样的内容

代码、公式、文档开头的属性、链接、#标签、提醒 (@…)、%% 批注、HTML 和引用链接定义（[d]: url）都不会标出，也不会改动；Obsidian 的写法也一样：块 id（^1a2b3c）、Dataview 字段（key:: value、[key:: value]）、==高亮== 和 Obsidian Tasks 的字段（📅 2026-11-07、🔁 every week、🆔 abc123）。合并行时，字段单独占一行。括号成对替换：价格(USD) 变成 价格（USD）。

「中英文间距」插件（在中文和英文之间加空格）也不改动这些内容。

## 权限

- 读取和修改文档：检查文档并做出修正。
- Textus AI 工具：让 Textus AI 能用同样的规则检查 Markdown。

## 更新日志

- **0.4.1** - 删除空行和切换列表不再改动被更长围栏包住的代码块（```` 里含 ```）。
- **0.4.0** - 选中的行可一键转为无序、有序或待办列表（有序列表每层从 1 编号，待办保留勾选状态）。
- **0.3.2** - 说明和空状态文字更简短。
- **0.3.1** - 介绍页重写：一句话说明它做什么，再讲它能做的事，并列出每个版本的更新。
- **0.3.0** - 改名为整理（原名 Markdown 检查）：并入「文本整理」的六个命令；可以关掉波浪线或单独关掉某条规则；Obsidian 自己的写法保持原样。
- **0.2.1** - 标签、链接、提醒和引用链接定义不再被标出，和「中英文间距」不改动的内容是同一份清单。
- **0.2.0** - Textus AI 可以检查 Markdown（`lint_markdown`）。
- **0.1.0-0.1.2** - 最初的版本：波浪线提示违反了哪条规则，以及「修正 Markdown」；商店页面和图标；支持桌面和 iOS。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `lint_markdown`：用 markdownlint 的规则检查 Markdown（给定的文本或当前文档），与编辑器中划线提示的一致：每个问题的行号、规则、说明以及能否自动修复；设 fix 时还返回修复后的文本。本身不改动任何内容。
