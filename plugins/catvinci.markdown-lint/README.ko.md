# 정리

흔한 규칙에 어긋나는 Markdown에 물결선을 긋고 고치며, 빈 줄·공백·문장 부호·줄바꿈도 정리합니다.

Obsidian의 Linter처럼 쓰며, 모든 변경은 한 번에 되돌릴 수 있습니다.

## Markdown

- 흔한 Markdown 규칙에 어긋나는 곳에 물결선이 그어집니다. 포인터를 올리면 어떤 규칙인지, 왜인지 보입니다.
- **Markdown 고치기**(오른쪽 클릭 또는 플러그인 메뉴)로 고칠 수 있는 것을 한 번에 고칩니다.
- 블록마다 따로 검사하므로 문서 전체에 관한 규칙(제목 단계, 첫 줄, 블록 사이 빈 줄)은 검사하지 않습니다.

## 텍스트

모든 명령은 선택한 텍스트에 적용되고, 선택이 없으면 먼저 물은 뒤 문서 전체에 적용됩니다. ‘플러그인’ 메뉴나 명령 팔레트에서 찾을 수 있습니다.

- **빈 줄 삭제**: 빈 단락을 지웁니다. 선택한 텍스트에서는 빈 줄을 모두 지웁니다.
- **줄 끝 공백 삭제**: 줄 끝의 공백과 탭을 지웁니다. 줄바꿈용 공백 두 칸은 남깁니다.
- **중국어 문장에 전각 문장 부호**: 「你好,世界?」가 「你好，世界？」가 됩니다. 1.3.8 같은 숫자와 영어 문장은 그대로입니다.
- **영어 문장에 반각 문장 부호**: 「Hello，world！」가 「Hello, world!」가 됩니다. 중국어에 붙은 부호는 그대로입니다.
- **전각 영문·숫자를 반각으로**: 「ＡＢＣ１２３」이 「ABC123」이 됩니다.
- **선택한 줄 합치기**(오른쪽 클릭 메뉴에도 있음): 선택한 줄을 한 줄로 합칩니다. 중국어 사이에는 공백을 넣지 않고 영어 단어 사이에는 한 칸 넣습니다.

## 설정

- **규칙에 어긋나는 Markdown에 물결선 긋기**: 끄면 물결선이 보이지 않습니다. ‘Markdown 고치기’는 그대로 쓸 수 있습니다.
- **검사하지 않을 규칙**: markdownlint 규칙을 한 줄에 하나씩(MD009 또는 no-trailing-spaces). 밑줄도 수정도 하지 않습니다.

## 그대로 두는 것

코드, 수식, 프런트 매터, 링크, #태그, 알림 (@…), %% 주석, HTML, 참조 정의([d]: url)는 표시하지도 바꾸지도 않습니다. Obsidian의 문법도 마찬가지입니다: 블록 ID(^1a2b3c), Dataview 필드(key:: value, [key:: value]), ==하이라이트==, Obsidian Tasks의 필드(📅 2026-11-07, 🔁 every week, 🆔 abc123). 줄을 합쳐도 필드는 한 줄로 남습니다. 괄호는 짝으로 바뀝니다: 价格(USD)는 价格（USD）가 됩니다.

중국어와 영문 사이에 공백을 넣는 ‘CJK·영문 간격’ 플러그인도 같은 것들을 건드리지 않습니다.

## 권한

- 문서 읽기와 편집: 문서를 검사하고 고치기 위해.
- Textus AI 도구: Textus AI가 같은 규칙으로 Markdown을 검사할 수 있도록.

## 변경 내역

- **0.4.1** - 빈 줄 제거와 목록 전환은 더 긴 펜스(```` 안의 ```)로 감싼 코드 블록을 그대로 둡니다.
- **0.4.0** - 선택한 줄을 글머리 기호·번호·할 일 목록으로 전환(번호는 단계마다 1부터, 할 일의 체크는 유지).
- **0.3.2** - 설명과 빈 상태 문구를 짧게 줄였습니다.
- **0.3.1** - 소개 페이지를 새로 썼습니다. 무엇을 하는지 한 문장으로, 할 수 있는 일과 버전별 변경 내역을 담았습니다.
- **0.3.0** - 이름을 정리로 바꿨습니다(이전 Markdown 검사). ‘텍스트 정리’의 텍스트 명령 여섯 개를 합쳤고, 물결선이나 개별 규칙을 끄는 설정이 생겼으며, Obsidian 고유 문법은 그대로 둡니다.
- **0.2.1** - 태그, 링크, 알림, 참조 정의에는 표시하지 않습니다. ‘CJK·영문 간격’이 건드리지 않는 것과 같은 목록입니다.
- **0.2.0** - Textus AI가 Markdown을 검사할 수 있습니다(`lint_markdown`).
- **0.1.0-0.1.2** - 첫 버전들: 규칙을 설명하는 물결선과 Markdown 고치기, 스토어 페이지와 아이콘, 데스크톱과 iOS 지원.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `lint_markdown`: Markdown(주어진 글이나 앞에 열린 문서)을 편집기가 밑줄로 보여 주는 것과 같은 markdownlint 규칙으로 검사합니다. 각 문제의 줄·규칙·설명·자동 수정 가능 여부를 돌려주고, fix를 주면 고친 글도 돌려줍니다. 스스로는 아무것도 바꾸지 않습니다.
