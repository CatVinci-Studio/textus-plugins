# Markdown 검사

흔한 스타일 규칙에 어긋나는 Markdown에 물결선을 긋고, 고칠 수 있는 것은 한 번에 고칩니다.

- 규칙에 어긋나는 곳에 물결선이 그어집니다. 포인터를 올리면 어떤 규칙인지, 왜인지 보입니다.
- **Markdown 고치기**(오른쪽 클릭 또는 플러그인 메뉴)로 고칠 수 있는 것을 한 번에 고칩니다. 한 번에 되돌릴 수 있습니다.
- #태그, 참조 정의([d]: url), 제목으로 가는 링크, %% 주석은 표시하지도 바꾸지도 않습니다.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `lint_markdown`: Markdown(주어진 글이나 앞에 열린 문서)을 편집기가 밑줄로 보여 주는 것과 같은 markdownlint 규칙으로 검사합니다. 각 문제의 줄·규칙·설명·자동 수정 가능 여부를 돌려주고, fix를 주면 고친 글도 돌려줍니다. 스스로는 아무것도 바꾸지 않습니다.
