# Revisión de Markdown

Subraya el Markdown que rompe reglas de estilo comunes y corrige de una vez lo que puede.

- Lo que rompe una regla se subraya; deja el puntero encima para ver qué regla y por qué.
- **Corregir Markdown** (clic derecho o el menú Plugins) corrige lo que se puede, en un solo paso para deshacer.
