# Vérification Markdown

Souligne le Markdown qui enfreint les règles de style courantes et corrige d’un coup ce qu’il peut.

- Ce qui enfreint une règle est souligné ; laissez le pointeur dessus pour voir quelle règle et pourquoi.
- **Corriger le Markdown** (clic droit ou le menu Plugins) corrige ce qui peut l’être, en une seule étape d’annulation.
- Les #tags, les définitions de référence ([d]: url), les liens vers des titres et les commentaires %% ne sont ni signalés ni modifiés.

## Outils pour Textus AI

Une fois le plugin installé, Textus AI peut s’en servir dans une conversation :

- `lint_markdown`: Vérifie du Markdown - fourni, ou le document au premier plan - avec les règles de markdownlint, comme l'éditeur les souligne : ligne, règle, description de chaque problème et s'il se corrige ; avec fix, aussi le texte corrigé. Ne modifie rien lui-même.
