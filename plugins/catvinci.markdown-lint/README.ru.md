# Проверка Markdown

Подчёркивает Markdown, нарушающий общие правила оформления, и исправляет всё, что может, за раз.

- Нарушения правил подчёркнуты; задержите указатель, чтобы увидеть правило и причину.
- **Исправить Markdown** (правый щелчок или меню «Плагины») исправляет всё, что можно, одним шагом отмены.
- #теги, определения ссылок ([d]: url), ссылки на заголовки и комментарии %% не отмечаются и не меняются.

## Инструменты для Textus AI

Когда плагин установлен, Textus AI может пользоваться ими в разговоре:

- `lint_markdown`: Проверяет Markdown - переданный или документ на переднем плане - по правилам markdownlint, как их подчёркивает редактор: строка, правило, описание каждой проблемы и можно ли её исправить; с fix - ещё и исправленный текст. Сам ничего не меняет.
