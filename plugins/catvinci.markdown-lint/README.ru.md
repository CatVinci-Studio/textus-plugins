# Проверка Markdown

Подчёркивает Markdown, нарушающий общие правила оформления, и исправляет всё, что может, за раз.

- Нарушения правил подчёркнуты; задержите указатель, чтобы увидеть правило и причину.
- **Исправить Markdown** (правый щелчок или меню «Плагины») исправляет всё, что можно, одним шагом отмены.
