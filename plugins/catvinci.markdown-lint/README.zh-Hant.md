# 整理

在一個地方整理文字和 Markdown，相當於 Obsidian 的 Linter。每次改動都可以一步復原。

## Markdown

- 不合常見規範的地方會畫波浪線；把指標停在上面，可以看到是哪條規則、為什麼。
- **修正 Markdown**（右鍵選單或「外掛」選單）把能修的一次修好。

## 文字

每個指令都作用於選取的文字；沒有選取時，先問一句，再整理整份文件。在「外掛」選單或指令面板裡找到它們。

- **刪除空行**：刪掉空段落；在選取的文字裡，所有空行都刪掉。
- **刪除行尾空格**：刪掉行尾的空格和定位字元；用來換行的兩個空格保留。
- **中文裡改用中文標點**：「你好,世界?」變成「你好，世界？」。1.3.8 這樣的小數和英文句子不變。
- **英文裡改用英文標點**：「Hello，world！」變成「Hello, world!」；挨著中文的標點不變。
- **全形字母數字轉半形**：「ＡＢＣ１２３」變成「ABC123」。
- **合併選取的行**（右鍵選單裡也有）：選取的幾行合成一行，中文之間不加空格，英文單字之間加一個空格。

## 設定

- **為不合規範的 Markdown 畫波浪線**：關掉後不再畫線，「修正 Markdown」照常可用。
- **不檢查的規則**：markdownlint 的規則，一行一條（MD009 或 no-trailing-spaces），既不畫線也不修正。

## 保持原樣的內容

程式碼、公式、文件開頭的屬性、連結、#標籤、提醒 (@…)、%% 註解、HTML 和參考連結定義（[d]: url）都不會標出，也不會改動；Obsidian 的寫法也一樣：區塊 id（^1a2b3c）、Dataview 欄位（key:: value、[key:: value]）、==醒目標示== 和 Obsidian Tasks 的欄位（📅 2026-11-07、🔁 every week、🆔 abc123）。合併行時，欄位單獨佔一行。括號成對替換：价格(USD) 變成 价格（USD）。

「中英文間距」外掛（在中文和英文之間加空格）也不改動這些內容。

## Textus AI 工具

裝上這個外掛後，Textus AI 在對話中可以使用：

- `lint_markdown`：用 markdownlint 的規則檢查 Markdown（給定的文字或目前文件），與編輯器中劃線提示的一致：每個問題的行號、規則、說明以及能否自動修正；設 fix 時還回傳修正後的文字。本身不改動任何內容。
