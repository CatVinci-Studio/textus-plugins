# Markdown 檢查

為不合常見規範的 Markdown 畫上波浪線，能修的一鍵修好。

- 不合規範的地方會畫波浪線；把指標停在上面，可以看到是哪條規則、為什麼。
- **修正 Markdown**（右鍵選單或「外掛」選單）把能修的一次修好，可以一步復原。
- #標籤、參考連結定義（[d]: url）、指向標題的連結和 %% 註解，不會標出，也不會改動。

## Textus AI 工具

裝上這個外掛後，Textus AI 在對話中可以使用：

- `lint_markdown`：用 markdownlint 的規則檢查 Markdown（給定的文字或目前文件），與編輯器中劃線提示的一致：每個問題的行號、規則、說明以及能否自動修正；設 fix 時還回傳修正後的文字。本身不改動任何內容。
