# Verificação de Markdown

Sublinha o Markdown que quebra regras de estilo comuns e corrige de uma vez o que puder.

- O que quebra uma regra fica sublinhado; pare o ponteiro em cima para ver qual regra e por quê.
- **Corrigir Markdown** (clique direito ou o menu Plugins) corrige o que for possível, num único passo de desfazer.
- #tags, definições de referência ([d]: url), links para títulos e comentários %% não são marcados nem alterados.

## Ferramentas para o Textus AI

Com o plugin instalado, o Textus AI pode usá-las numa conversa:

- `lint_markdown`: Verifica Markdown - dado, ou o documento em primeiro plano - com as regras do markdownlint, como o editor as sublinha: a linha, a regra, a descrição de cada problema e se se corrige; com fix, também o texto corrigido. Não altera nada por si.
