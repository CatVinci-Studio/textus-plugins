# Revisión de Markdown

Subraya el Markdown que rompe reglas de estilo comunes y corrige de una vez lo que puede.

- Lo que rompe una regla se subraya; deja el puntero encima para ver qué regla y por qué.
- **Corregir Markdown** (clic derecho o el menú Plugins) corrige lo que se puede, en un solo paso para deshacer.
- Las #etiquetas, las definiciones de referencia ([d]: url), los enlaces a encabezados y los comentarios %% no se marcan ni se cambian.

## Herramientas para Textus AI

Con el plugin instalado, Textus AI puede usarlas en una conversación:

- `lint_markdown`: Revisa Markdown - dado, o el documento al frente - con las reglas de markdownlint, como las subraya el editor: la línea, la regla, la descripción de cada problema y si se puede corregir; con fix, también el texto corregido. No cambia nada por sí mismo.
