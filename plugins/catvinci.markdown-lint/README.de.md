# Markdown-Prüfung

Unterstreicht Markdown, das gängige Stilregeln verletzt, und behebt, was es kann, in einem Schritt.

- Was gegen eine Regel verstößt, wird unterstrichen; lassen Sie den Zeiger darauf ruhen, um Regel und Grund zu sehen.
- **Markdown korrigieren** (Rechtsklick oder das Plugins-Menü) behebt, was sich beheben lässt – mit einem Schritt rückgängig.
