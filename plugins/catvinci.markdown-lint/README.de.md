# Markdown-Prüfung

Unterstreicht Markdown, das gängige Stilregeln verletzt, und behebt, was es kann, in einem Schritt.

- Was gegen eine Regel verstößt, wird unterstrichen; lassen Sie den Zeiger darauf ruhen, um Regel und Grund zu sehen.
- **Markdown korrigieren** (Rechtsklick oder das Plugins-Menü) behebt, was sich beheben lässt – mit einem Schritt rückgängig.
- #Tags, Referenzdefinitionen ([d]: url), Links auf Überschriften und %%-Kommentare werden weder markiert noch geändert.

## Werkzeuge für Textus AI

Ist das Plugin installiert, kann Textus AI sie im Gespräch nutzen:

- `lint_markdown`: Prüft Markdown - übergeben oder das vordere Dokument - mit den Regeln von markdownlint, wie der Editor sie unterstreicht: Zeile, Regel, Beschreibung und Behebbarkeit jedes Problems; mit fix auch den korrigierten Text. Ändert selbst nichts.
