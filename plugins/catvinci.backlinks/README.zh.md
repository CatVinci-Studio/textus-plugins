# 反向链接

> `[[笔记]]` 这样的双链（双向链接）是 Textus 自带的，不装插件也能写、能点开。这个插件补上另一半：看谁链接到了当前文档。

在侧边栏的 **反向链接** 标签里，看哪些笔记链接到当前文档，以及它链接到了哪里。

- **已链接提及**：其他笔记里用 [[维基链接]] 或文件链接指向这里的那几行。点一下就跳过去。
- **未链接提及**：提到这篇笔记（按文件名、第一个标题，或 front matter 里的 `aliases`）却没有加链接的地方。右键选 **添加链接**，就变成 [[链接]]。
- **出链**：这篇笔记链接到的笔记，包括还没创建的。
- 顶部的输入框可以筛选列表。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `list_backlinks`：针对一篇文档（默认当前文档）：列出链接到它的笔记（路径、行号、那一行的文字）、提到它却没加链接的行，以及它链接到的笔记。
