# Обратные ссылки

Что ссылается на открытый документ и куда ссылается он сам — во вкладке **Обратные ссылки** на боковой панели.

- **Упоминания со ссылкой**: строки других заметок, которые ведут сюда через [[вики-ссылки]] или ссылки на этот файл. Щёлкните, чтобы перейти.
- **Упоминания без ссылки**: строки, где эта заметка названа — по имени файла, первому заголовку или `aliases` во front matter — без ссылки. Щёлкните правой кнопкой и выберите **Сделать ссылкой**, чтобы получилась [[ссылка]].
- **Исходящие ссылки**: заметки, на которые ссылается эта, включая ещё не созданные.
- Поле вверху фильтрует список.

## Инструменты для Textus AI

Когда плагин установлен, Textus AI может пользоваться ими в разговоре:

- `list_backlinks`: Для документа - переднего, если путь не указан, - перечисляет заметки со ссылками на него (путь, строка, текст строки), строки, где он назван без ссылки, и заметки, на которые он ссылается.
