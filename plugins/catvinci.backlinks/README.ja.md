# 双方向リンク

> `[[ノート]]` のようなリンクは Textus に標準で入っていて、プラグインなしで書いて開けます。このプラグインはリンクを書く手助けをし、リンク先をその場に表示し、今の文書にどこからリンクされているかを一覧にします。

## 書きながらリンクする

- `[[` と入力し、開いたパネルからノートを選びます。ファイル名、最初の見出し、front matter の `aliases` のどれでも探せます。別名を選ぶと `[[ノート|別名]]` と書かれます。
- `#` の後はそのノートの見出し：`[[ノート#見出し]]`。`[[#` で今の文書自身の見出しが出ます。
- `#^` の後はそのブロック：段落、リストの項目、表、引用。id のないブロックを選ぶと、そのノートのブロック末尾に id（`^1a2b3c` など）を Obsidian と同じ形で付けます。
- 言葉を選択してから `[[` と入力すると、リンクになります。
- リンクはフォルダの書き方で書かれます。Obsidian の保管庫では、保管庫のリンク形式に従います。

## 埋め込み

- `![[ノート]]` はノート全体を、`![[ノート#見出し]]` はその節を、`![[ノート#^id]]` はそのブロックをその場に表示します。読み取り専用で、元のノートが変わると追従します。
- その行にカーソルを置くと、リンクそのものを編集できます。

## サイドバーのバックリンク

サイドバーの **双方向リンク** タブで、開いている文書にリンクしているノートと、この文書のリンク先を確認できます。

- **リンクされた言及**：[[ウィキリンク]] やファイルへのリンクでここを指している、他のノートの行。クリックでその場所へ移動します。
- **リンクされていない言及**：このノートの名前（ファイル名、最初の見出し、front matter の `aliases`）をリンクなしで書いている行。右クリックして **リンクにする** を選ぶと [[リンク]] になります。
- **発リンク**：このノートのリンク先。まだ作成されていないノートも含みます。
- 上の入力欄で一覧を絞り込めます。

## Textus AI のツール

このプラグインを入れると、Textus AI が会話の中で使えます：

- `list_backlinks`：ある文書（パスがなければ前面の文書）について、そこへリンクしているノート（パス・行番号・その行の本文）、リンクせずに名前を挙げている行、その文書からのリンク先を一覧にします。
