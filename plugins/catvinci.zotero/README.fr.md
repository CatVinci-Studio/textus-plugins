# Zotero

Citez depuis votre bibliothèque Zotero pendant que vous écrivez.

- Nécessite Zotero 7 ou plus récent (Zotero 10 compris) en cours d’exécution, avec **Settings › Advanced › Allow other applications on this computer to communicate with Zotero** activé.
- **Ctrl+Alt+C** (**⌘⌥C** sur Mac), clic droit › **Insérer une citation depuis Zotero…**, ou le menu Extensions : les ouvrages cités récemment viennent d’abord, puis une recherche dans votre bibliothèque.
- Si des mots sont sélectionnés, ce sont eux qui sont recherchés.
- Choisissez un élément et la citation s’insère au curseur.
- **Extensions › Insérer la liste des références** ajoute à la fin du document la liste de tous les ouvrages qu’il cite.
- La façon d’écrire une citation se règle dans les réglages de l’extension.

## Outils pour Textus AI

Une fois le plugin installé, Textus AI peut s’en servir dans une conversation :

- `search_library`: Cherche dans la bibliothèque Zotero de l'utilisateur sur cet ordinateur (Zotero 7 ou plus récent doit être ouvert) : la clé, le titre, les auteurs, l'année, le type, la source et la clé de citation de chaque élément, et la citation à insérer dans le style choisi. Échoue en disant quoi faire quand Zotero est injoignable.
