# Zotero

글을 쓰면서 Zotero 라이브러리에서 인용합니다.

## 준비

같은 컴퓨터에서 Zotero 7 이상(Zotero 10 포함)을 켜 두고, Zotero의 **설정 › 고급**에서 '이 컴퓨터의 다른 응용 프로그램이 Zotero와 통신하도록 허용'을 켜야 합니다. 플러그인은 이 컴퓨터의 Zotero와만 통신하며, 데이터는 컴퓨터 밖으로 나가지 않습니다. 데스크톱에서 동작합니다.

## 인용하기

- **Ctrl+Alt+R**(Mac에서는 **⌘⌥R**)을 누르거나, 오른쪽 클릭 메뉴의 **Zotero에서 인용 넣기…**, 또는 **플러그인 › Zotero에서 인용 넣기…**를 고릅니다. 최근에 인용한 문헌이 먼저 나오고, 그다음 라이브러리 전체를 검색할 수 있습니다.
- 글자를 선택해 두면 그 글자로 검색합니다.
- 항목을 고르면 커서 위치에 인용이 들어갑니다.
- 인용이나 Zotero 항목으로 가는 링크에 포인터를 올리면 저자, 연도, 실린 곳, 초록 앞부분이 보입니다.
- **플러그인 › 참고문헌 목록 넣기**는 문서가 인용한 모든 문헌을 제1저자와 연도 순으로 정리한 **참고문헌** 절을 끝에 넣습니다. 다시 실행하면 두 번 넣지 않고 목록을 바꿉니다.

## 인용 표기 방식

플러그인 설정의 **인용 표기 방식**에서 고릅니다:

- **Pandoc 키: [@key]**(기본값). **설정 › 편집기 및 모양 › 내보내기**에서 참고 문헌 파일(.bib)을 고르면, Pandoc으로 내보낼 때 형식을 갖춘 참고 문헌이 됩니다.
- **저자와 연도: (저자, 2024)**.
- **Obsidian 노트 링크: [[@key]]**. 그 항목의 문헌 노트로 가는 링크입니다. 노트가 아직 없으면 만들지 물어봅니다.
- **Zotero를 여는 링크**.

인용 키는 항목의 Citation Key 필드(또는 Better BibTeX가 쓰는 Extra의 `Citation Key:` 줄)에서 가져옵니다.

## 문헌 노트

- **플러그인 › Zotero에서 문헌 노트 만들기…**는 `@citekey.md`를 만듭니다(이미 있으면 엽니다). 항목의 제목, 저자, 연도, 초록, DOI나 URL, Zotero의 하이라이트와 메모가 들어갑니다.
- 노트는 열린 폴더의 **References**에 만들어지며, **문헌 노트 폴더**에서 바꿀 수 있습니다.
- **문헌 노트 템플릿**에는 폴더 안의 Markdown 파일(예: `Templates/Literature.md`)을 지정할 수 있습니다. `{{title}}`, `{{authors}}`, `{{year}}`, `{{abstract}}`, `{{citekey}}`, `{{DOI}}`, `{{URL}}`, `{{highlights}}`, `{{notes}}`, `{{date:YYYY-MM-DD}}`를 씁니다. 비워 두면 front matter가 있는 간단한 노트를 만듭니다.
- Obsidian 보관소에서는 Zotero Integration이나 Citations 플러그인에 설정한 폴더와 템플릿을 따릅니다. 다른 템플릿 언어로 쓴 템플릿은 간단한 노트로 대신합니다.

## 권한

- **네트워크(localhost:23119만)**: 이 컴퓨터에 있는 Zotero의 로컬 API에 연결하기 위해.
- **문서 읽기와 편집**: 인용과 참고문헌 목록을 넣고, 선택한 글자로 검색하기 위해.
- **열린 폴더의 파일 읽기와 쓰기**: 템플릿과 보관소의 Zotero 설정을 읽고, 문헌 노트를 만들기 위해.
- **Textus AI 도구**: Textus AI가 라이브러리를 검색할 수 있도록.

## 변경 내역

- **0.4.2** - 설명과 빈 상태 문구를 짧게 줄였습니다.
- **0.4.1** - 코드를 역할별로 작은 파일로 나눴습니다. 사용법은 바뀌지 않습니다.
- **0.4.0** - 문헌 노트 템플릿을 Textus 내장 템플릿 엔진으로 채움, Textus 1.3.10 필요
- **0.3.0** - Zotero에서 문헌 노트 만들기(템플릿과 Obsidian 보관소 설정 지원), `[[@citekey]]` 형식의 인용
- **0.2.1** - 단축키를 Ctrl+Alt+C에서 Ctrl+Alt+R로 변경
- **0.2.0** - Textus AI 도구 `search_library` 추가
- **0.1.3** - 데스크톱 전용으로 제공
- **0.1.2** - Zotero 10의 로컬 API 지원, 참고문헌 목록을 다시 만들면 교체, 코드 안의 내용은 인용으로 읽지 않음
- **0.1.0-0.1.1** - 첫 버전: 인용 넣기(최근 문헌 먼저), 인용 호버 카드, 참고문헌 목록, 네 가지 인용 방식

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `search_library`: 이 컴퓨터에 있는 사용자의 Zotero 라이브러리를 검색합니다(Zotero 7 이상이 실행 중이어야 합니다). 각 항목의 키·제목·저자·연도·유형·게재처·인용 키와, 사용자가 고른 형식으로 넣을 인용을 돌려줍니다. Zotero에 연결할 수 없으면 해야 할 일을 알려 주며 실패합니다.
