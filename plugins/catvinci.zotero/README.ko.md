# Zotero

글을 쓰면서 Zotero 라이브러리에서 바로 인용합니다.

- Zotero 7 이상(Zotero 10 포함)이 실행 중이어야 하며, **Settings › Advanced › Allow other applications on this computer to communicate with Zotero**가 켜져 있어야 합니다.
- **Ctrl+Alt+C**(Mac에서는 **⌘⌥C**), 오른쪽 클릭 › **Zotero에서 인용 넣기…**, 또는 플러그인 메뉴를 쓰세요. 최근에 인용한 문헌이 먼저 나오고, 그다음에 라이브러리 검색이 이어집니다.
- 단어를 선택해 두면 그 단어로 검색합니다.
- 항목을 고르면 커서 위치에 인용이 들어갑니다.
- **플러그인 › 참고문헌 목록 넣기**는 문서가 인용한 모든 문헌의 목록을 문서 끝에 붙입니다.
- 인용 표기 방식은 플러그인 설정에서 바꿀 수 있습니다.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `search_library`: 이 컴퓨터에 있는 사용자의 Zotero 라이브러리를 검색합니다(Zotero 7 이상이 실행 중이어야 합니다). 각 항목의 키·제목·저자·연도·유형·게재처·인용 키와, 사용자가 고른 형식으로 넣을 인용을 돌려줍니다. Zotero에 연결할 수 없으면 해야 할 일을 알려 주며 실패합니다.
