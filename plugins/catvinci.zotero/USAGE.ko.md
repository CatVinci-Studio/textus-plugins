# Zotero

글을 쓰면서 Zotero 라이브러리에서 바로 인용합니다.

- Zotero 7이 실행 중이어야 하며, **Settings › Advanced › Allow other applications on this computer to communicate with Zotero**가 켜져 있어야 합니다.
- **Ctrl+Alt+C**(Mac에서는 **⌘⌥C**), 오른쪽 클릭 › **Zotero에서 인용 넣기…**, 또는 플러그인 메뉴로 라이브러리 검색을 엽니다.
- 항목을 고르면 커서 위치에 인용이 들어갑니다.
- 인용 표기 방식은 플러그인 설정에서 바꿀 수 있습니다.
