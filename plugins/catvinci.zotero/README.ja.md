# Zotero

書きながら Zotero ライブラリから引用できます。

- Zotero 7 以降（Zotero 10 も含む）が起動していて、**Settings › Advanced › Allow other applications on this computer to communicate with Zotero** がオンである必要があります。
- **Ctrl+Alt+R**（Mac では **⌘⌥R**）、右クリック › **Zotero から引用を挿入…**、またはプラグインメニューを使います。最近引用した文献が先に並び、その後にライブラリの検索が続きます。
- 文字を選択していると、その文字で検索します。
- 項目を選ぶと、カーソルの位置に引用が入ります。
- **プラグイン › 参考文献リストを挿入** で、文書が引用しているすべての文献の一覧を末尾に加えます。
- **プラグイン › Zotero から文献ノートを作成…** で、References に `@citekey.md` を作ります（あれば開きます）。タイトル・著者・年・要旨・DOI または URL と、Zotero のハイライトとメモが入ります。テンプレートファイルも指定でき、Obsidian の保管庫では Zotero Integration や Citations のフォルダとテンプレートに従います。
- 引用は Obsidian 式の `[[@citekey]]` でも書けます。その文献ノートへのリンクで、引用したときにノートの作成を提案します。
- 引用の書き方は、プラグインの設定で変えられます。

## Textus AI のツール

このプラグインを入れると、Textus AI が会話の中で使えます：

- `search_library`：このコンピュータにあるユーザーの Zotero ライブラリを検索します（Zotero 7 以降が起動している必要があります）。各アイテムのキー・タイトル・著者・年・種類・掲載先・引用キーと、ユーザーが選んだ形式で挿入する引用を返します。Zotero に接続できないときは、どうすればよいかを添えて失敗します。
