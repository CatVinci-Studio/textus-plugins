# Zotero

Cita desde tu biblioteca de Zotero mientras escribes.

- Necesita Zotero 7 o posterior (también Zotero 10) en ejecución, con **Settings › Advanced › Allow other applications on this computer to communicate with Zotero** activado.
- **Ctrl+Alt+R** (**⌘⌥R** en Mac), clic derecho › **Insertar una cita de Zotero…**, o el menú Complementos: primero salen las obras que citaste hace poco y después una búsqueda en tu biblioteca.
- Si hay palabras seleccionadas, se busca por ellas.
- Elige un elemento y la cita se inserta donde está el cursor.
- **Complementos › Insertar lista de referencias** añade al final del documento una lista de todas las obras que cita.
- **Complementos › Nueva nota de lectura desde Zotero…** crea `@citekey.md` en References (o la abre si ya existe) con el título, los autores, el año, el resumen, el DOI o la URL, y los subrayados y notas de Zotero. Se puede elegir un archivo de plantilla; en una bóveda de Obsidian se siguen la carpeta y la plantilla de Zotero Integration o Citations.
- Las citas también pueden escribirse a la manera de Obsidian, `[[@citekey]]`: un enlace a esa nota de lectura, que se ofrece al citar.
- Cómo se escribe una cita se cambia en los ajustes del complemento.

## Herramientas para Textus AI

Con el plugin instalado, Textus AI puede usarlas en una conversación:

- `search_library`: Busca en la biblioteca de Zotero del usuario en este ordenador (Zotero 7 o posterior debe estar abierto): la clave, el título, los autores, el año, el tipo, dónde se publicó y la clave de cita de cada elemento, y la cita para insertar en el estilo elegido.
