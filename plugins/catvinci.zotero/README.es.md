# Zotero

Cita desde tu biblioteca de Zotero mientras escribes.

- Necesita Zotero 7 o posterior (también Zotero 10) en ejecución, con **Settings › Advanced › Allow other applications on this computer to communicate with Zotero** activado.
- **Ctrl+Alt+C** (**⌘⌥C** en Mac), clic derecho › **Insertar una cita de Zotero…**, o el menú Complementos: primero salen las obras que citaste hace poco y después una búsqueda en tu biblioteca.
- Si hay palabras seleccionadas, se busca por ellas.
- Elige un elemento y la cita se inserta donde está el cursor.
- **Complementos › Insertar lista de referencias** añade al final del documento una lista de todas las obras que cita.
- Cómo se escribe una cita se cambia en los ajustes del complemento.
