# Zotero

写作时直接引用 Zotero 文库里的文献。

- 需要 Zotero 7 或更新版本（包括 Zotero 10）正在运行，并在 Zotero 的 **设置 › 高级** 里打开 **允许此计算机上的其他应用程序与 Zotero 通信**。
- 按 **Ctrl+Alt+R**（Mac 上 **⌘⌥R**），或右键 › **从 Zotero 插入引用…**，或从插件菜单：最近引用过的文献排在最前，后面是文库搜索。
- 如果选中了文字，就用选中的文字去搜索。
- 选中一条文献，引用就插在光标处。
- **插件 › 插入参考文献列表** 会在文档末尾加上本文引用的全部文献。
- **插件 › 从 Zotero 新建文献笔记…** 在 References 里新建 `@citekey.md`（已有就直接打开），填好标题、作者、年份、摘要、DOI 或网址，以及 Zotero 里的标注和笔记。可以指定模板文件；在 Obsidian 库里，按 Zotero Integration 或 Citations 插件的文件夹和模板来。
- 引用也可以写成 Obsidian 的 `[[@citekey]]`：链接到那篇文献笔记，插入引用后会问要不要新建。
- 引用的写法在插件设置里改。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `search_library`：搜索这台电脑上用户的 Zotero 文献库（需要 Zotero 7 或更新版本正在运行）：给出每个条目的 key、标题、作者、年份、类型、出处、引用键，以及按用户所选格式要插入的引文。连不上 Zotero 时会失败并说明该怎么做。
