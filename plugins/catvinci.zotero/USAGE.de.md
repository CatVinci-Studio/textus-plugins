# Zotero

Zitiere beim Schreiben aus deiner Zotero-Bibliothek.

- Benötigt Zotero 7, das läuft, mit eingeschaltetem **Settings › Advanced › Allow other applications on this computer to communicate with Zotero**.
- **Ctrl+Alt+C** (**⌘⌥C** auf dem Mac), Rechtsklick › **Zitat aus Zotero einfügen…** oder das Plugins-Menü öffnet eine Suche in deiner Bibliothek.
- Wähle einen Eintrag, und das Zitat wird an der Einfügemarke eingefügt.
- Wie ein Zitat geschrieben wird, steht in den Einstellungen des Plugins.
