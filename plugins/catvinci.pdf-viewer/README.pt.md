# Visualizador de PDF

Abre PDFs numa aba ao lado das suas notas, para ler, procurar e copiar texto.

- Abra um PDF pela barra lateral ou arraste-o para a janela. Um link para uma página de um PDF o abre nessa página.
- Role pelas páginas ou use os botões de seta para a página anterior e a seguinte.
- Dê zoom com os botões, **Ctrl+roda** (**⌘+roda** no Mac) ou o gesto de pinça. As páginas se esticam na hora em volta do ponteiro e ficam nítidas quando você para.
- Um PDF abre na largura da janela e a acompanha quando a janela muda de tamanho. Clique na porcentagem para alternar entre isso e o tamanho real.
- Selecione texto para copiá-lo para as suas notas.
- **Ctrl+F** (**⌘F** no Mac), ou a lupa, procura palavras no PDF e as destaca: **Enter** vai para a próxima página com elas, **Shift+Enter** volta, **Esc** fecha.
- Um PDF abre de novo na página e no zoom em que você o deixou. Os últimos 200 PDFs são lembrados.
- PDFs em chinês, japonês e coreano sem fontes incorporadas mostram o texto mesmo assim, e páginas digitalizadas mostram suas imagens. Um arquivo que não abre diz por quê.

Não pede permissões: o Textus entrega a ele o PDF que você abre.
