# PDF 뷰어

노트 옆 탭에서 PDF를 열어 읽고, 찾고, 글을 복사합니다.

- 사이드바에서 PDF를 열거나 창으로 끌어다 놓습니다. PDF의 특정 페이지로 가는 링크는 그 페이지에서 엽니다.
- 스크롤로 페이지를 넘기거나, 화살표 버튼으로 이전·다음 페이지로 갑니다.
- 버튼, **Ctrl+스크롤**(Mac에서는 **⌘+스크롤**), 핀치로 확대·축소합니다. 페이지가 포인터를 중심으로 바로 커지거나 작아지고, 멈추면 선명하게 다시 그려집니다.
- PDF는 창 너비에 맞춰 열리고, 창 크기를 바꿔도 계속 맞춥니다. 퍼센트 표시를 누르면 너비 맞춤과 실제 크기를 오갑니다.
- 글을 선택해 노트로 복사할 수 있습니다.
- **Ctrl+F**(Mac에서는 **⌘F**)나 돋보기로 PDF 안의 단어를 찾아 표시합니다. **Enter**는 그 단어가 있는 다음 페이지로, **Shift+Enter**는 이전으로, **Esc**는 닫기입니다.
- PDF를 다시 열면 마지막으로 본 페이지와 배율로 돌아갑니다. 최근 PDF 200개를 기억합니다.
- 글꼴이 포함되지 않은 중국어·일본어·한국어 PDF도 글자를 보여 주고, 스캔한 페이지는 이미지를 보여 줍니다. 열 수 없는 파일은 이유를 알려 줍니다.

권한이 필요 없습니다. 연 PDF는 Textus가 이 플러그인에 넘겨줍니다.

## 변경 내역

- **0.2.0** - Textus 자체 컨트롤을 씁니다. Textus 1.3.2가 필요합니다.
- **0.1.3** - Textus 1.3의 모습으로 바뀌고, 인터페이스 언어를 바꾸면 버튼 글자도 바뀝니다.
- **0.1.2** - 스캔한 페이지의 이미지 표시, 페이지 링크, 보이지 않는 페이지의 메모리 해제, 열 수 없는 파일 안내. 창 너비로 열고, 확대·축소는 포인터를 중심으로 늘였다가 멈추면 선명하게 그립니다.
- **0.1.0-0.1.1** - 첫 버전들: 페이지 넘기기, 확대·축소, 글 선택과 복사, 찾기, 마지막 위치에서 다시 열기, 글꼴이 포함되지 않은 중국어·일본어·한국어 표시.
