# PDF ビューア

PDF をノートの横のタブで開きます。

- サイドバーから PDF を開くか、ウインドウにドラッグします。
- スクロールでページをめくり、ボタンか **Ctrl+スクロール**（Mac では **⌘+スクロール**）で拡大・縮小します。
- テキストを選択して、ノートにコピーできます。
- PDF を開いたときの大きさは、プラグインの設定で変えられます。
- **Ctrl+F**（Mac では **⌘F**）か虫眼鏡で、PDF 内の語句を検索できます。**Enter** でその語句がある次のページへ、**Shift+Enter** で前のページへ移ります。
- PDF は、前回閉じたときのページと拡大率で開きます。
