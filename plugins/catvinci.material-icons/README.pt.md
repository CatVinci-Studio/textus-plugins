# Material Icon Theme

Ícones de arquivos e pastas do Material Icon Theme do VS Code na barra lateral, na busca e na abertura rápida: um ícone colorido para cada tipo de arquivo - Markdown, PDF, imagens, Word, Excel, código - e para pastas como images, docs e src. Escolha-o em Ajustes › Aparência › Ícones de arquivo.

## O que faz

- Dá a cada arquivo um ícone colorido pela extensão ou pelo nome: Markdown, texto simples, PDF, imagens, Word, Excel e CSV, PowerPoint, JSON, YAML, LaTeX e BibTeX, EPUB, Excalidraw, áudio, vídeo, arquivos compactados, fontes e as linguagens de programação mais comuns. `README.md`, `LICENSE`, `CHANGELOG.md`, `package.json` e `.gitignore` têm ícones próprios.
- As pastas comuns têm ícone próprio, abertas e fechadas: images, assets, docs, src, test, public, dist, scripts, attachments e outras.
- Aparece nos arquivos da barra lateral, nos resultados da busca e na abertura rápida depois de escolher **Material** em **Ajustes › Aparência › Ícones de arquivo**. **Padrão** traz de volta os ícones do Textus.

Traz os ícones do tema para escrita e para o código do dia a dia; qualquer outro arquivo ou pasta recebe o ícone simples de arquivo ou de pasta.

## Permissões

Nenhuma. Só dá ao Textus um conjunto de ícones; não lê nada por conta própria.

## Créditos
