# Material Icon Theme

File and folder icons from VS Code's Material Icon Theme in the sidebar, search and quick open: a colour icon for each kind of file - Markdown, PDF, pictures, Word, Excel, code - and for folders such as images, docs and src. Pick it in Settings › Appearance › File icons.

## What it does

- Gives files a colour icon by their extension or name: Markdown, plain text, PDF, pictures, Word, Excel and CSV, PowerPoint, JSON, YAML, LaTeX and BibTeX, EPUB, Excalidraw, audio, video, archives, fonts, and the common programming languages. `README.md`, `LICENSE`, `CHANGELOG.md`, `package.json` and `.gitignore` have icons of their own.
- Gives common folders their own icon, open and closed: images, assets, docs, src, test, public, dist, scripts, attachments and more.
- Shows in the sidebar's files, search results and quick open once you pick **Material** in **Settings › Appearance › File icons**. **Default** brings back Textus's own icons.

It carries 125 of the theme's 1,256 icons, the ones for writing and everyday code; everything else keeps the plain file and folder icons.

## Permissions

None. It only gives Textus a set of icons; it reads nothing itself.
