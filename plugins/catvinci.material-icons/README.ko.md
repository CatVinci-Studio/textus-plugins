# Material Icon Theme

사이드바, 검색, 빠른 열기의 파일과 폴더 아이콘을 VS Code의 Material Icon Theme 아이콘으로 바꿉니다. Markdown, PDF, 그림, Word, Excel, 코드 등 파일 종류마다 색 아이콘이 있고, images, docs, src 같은 폴더에도 아이콘이 있습니다. 설정 › 모양 › 파일 아이콘에서 고르세요.

## 하는 일

- 확장자나 파일 이름에 따라 파일에 색 아이콘을 붙입니다: Markdown, 일반 텍스트, PDF, 그림, Word, Excel과 CSV, PowerPoint, JSON, YAML, LaTeX와 BibTeX, EPUB, Excalidraw, 오디오, 동영상, 압축 파일, 글꼴, 그리고 흔히 쓰는 프로그래밍 언어. `README.md`, `LICENSE`, `CHANGELOG.md`, `package.json`, `.gitignore`에는 전용 아이콘이 있습니다.
- 자주 쓰는 폴더에는 열렸을 때와 닫혔을 때의 전용 아이콘이 있습니다: images, assets, docs, src, test, public, dist, scripts, attachments 등.
- **설정 › 모양 › 파일 아이콘**에서 **Material**을 고르면 사이드바의 파일, 검색 결과, 빠른 열기에 나타납니다. **기본**을 고르면 Textus의 아이콘으로 돌아갑니다.

이 테마에서 글쓰기와 평소 코드에 쓰는 아이콘을 담았습니다. 그 밖의 파일과 폴더에는 일반 파일, 폴더 아이콘이 붙습니다.

## 권한

필요 없습니다. Textus에 아이콘 한 벌을 줄 뿐, 스스로는 아무것도 읽지 않습니다.

## 출처

아이콘은 [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme)에서 왔으며 MIT 라이선스입니다. `THIRD-PARTY-NOTICES.md`를 보세요.
