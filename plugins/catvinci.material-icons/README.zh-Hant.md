# Material 圖示主題

側邊欄、搜尋和快速開啟裡的檔案與資料夾圖示，來自 VS Code 的 Material Icon Theme：每種檔案各有一個彩色圖示——Markdown、PDF、圖片、Word、Excel、程式碼——images、docs、src 等資料夾也有專屬圖示。在 設定 › 外觀 › 檔案圖示 中選用。

## 它做什麼

- 依副檔名或檔名給檔案一個彩色圖示：Markdown、純文字、PDF、圖片、Word、Excel 和 CSV、PowerPoint、JSON、YAML、LaTeX 和 BibTeX、EPUB、Excalidraw、音訊、影片、壓縮檔、字型，以及常見的程式語言。`README.md`、`LICENSE`、`CHANGELOG.md`、`package.json` 和 `.gitignore` 有各自的圖示。
- 常見的資料夾有專屬圖示，展開和收合各一個：images、assets、docs、src、test、public、dist、scripts、attachments 等。
- 在 **設定 › 外觀 › 檔案圖示** 裡選 **Material** 後，側邊欄的檔案、搜尋結果和快速開啟都會用這套圖示。選 **預設** 換回 Textus 自己的圖示。

它帶了這套主題裡寫作和日常程式碼用得到的圖示；其他檔案和資料夾用一般的檔案、資料夾圖示。

## 權限

不需要任何權限。它只給 Textus 一套圖示，自己不讀取任何東西。
