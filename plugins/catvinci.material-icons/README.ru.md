# Material Icon Theme

Значки файлов и папок из Material Icon Theme для VS Code на боковой панели, в поиске и быстром открытии: цветной значок для каждого вида файлов - Markdown, PDF, картинки, Word, Excel, код - и для папок вроде images, docs и src. Выбирается в Настройки › Оформление › Значки файлов.

## Что он делает

- Даёт файлам цветной значок по расширению или имени: Markdown, обычный текст, PDF, картинки, Word, Excel и CSV, PowerPoint, JSON, YAML, LaTeX и BibTeX, EPUB, Excalidraw, аудио, видео, архивы, шрифты и распространённые языки программирования. У `README.md`, `LICENSE`, `CHANGELOG.md`, `package.json` и `.gitignore` свои значки.
- У привычных папок свой значок, в открытом и закрытом виде: images, assets, docs, src, test, public, dist, scripts, attachments и другие.
- Видны у файлов на боковой панели, в результатах поиска и в быстром открытии, когда в **Настройки › Оформление › Значки файлов** выбран **Material**. **Стандартные** возвращают значки Textus.

В нём значки темы для письма и повседневного кода; остальные файлы и папки получают простой значок файла или папки.

## Разрешения

Не нужны. Он только даёт Textus набор значков и сам ничего не читает.

## Источник

Значки взяты из [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme), лицензия MIT; см. `THIRD-PARTY-NOTICES.md`.
