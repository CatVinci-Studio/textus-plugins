# Material Icon Theme

Les icônes de fichiers et de dossiers du Material Icon Theme de VS Code dans la barre latérale, la recherche et l'ouverture rapide : une icône en couleur pour chaque type de fichier - Markdown, PDF, images, Word, Excel, code - et pour les dossiers comme images, docs et src. À choisir dans Réglages › Apparence › Icônes de fichier.

## Ce qu'il fait

- Donne à chaque fichier une icône en couleur selon son extension ou son nom : Markdown, texte brut, PDF, images, Word, Excel et CSV, PowerPoint, JSON, YAML, LaTeX et BibTeX, EPUB, Excalidraw, audio, vidéo, archives, polices et les langages de programmation courants. `README.md`, `LICENSE`, `CHANGELOG.md`, `package.json` et `.gitignore` ont leur propre icône.
- Les dossiers courants ont leur propre icône, ouverts et fermés : images, assets, docs, src, test, public, dist, scripts, attachments et d'autres.
- S'affiche dans les fichiers de la barre latérale, les résultats de recherche et l'ouverture rapide une fois **Material** choisi dans **Réglages › Apparence › Icônes de fichier**. **Par défaut** remet les icônes de Textus.

Il contient les icônes du thème pour l'écriture et le code de tous les jours ; tout autre fichier ou dossier prend l'icône simple de fichier ou de dossier.

## Autorisations

Aucune. Il donne seulement à Textus un jeu d'icônes ; il ne lit rien lui-même.
