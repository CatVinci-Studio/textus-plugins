# Material Icon Theme

Datei- und Ordnersymbole aus dem Material Icon Theme von VS Code in der Seitenleiste, der Suche und beim Schnellöffnen: ein farbiges Symbol für jede Dateiart - Markdown, PDF, Bilder, Word, Excel, Code - und für Ordner wie images, docs und src. Auszuwählen unter Einstellungen › Darstellung › Dateisymbole.

## Was es macht

- Gibt Dateien nach Endung oder Namen ein farbiges Symbol: Markdown, reiner Text, PDF, Bilder, Word, Excel und CSV, PowerPoint, JSON, YAML, LaTeX und BibTeX, EPUB, Excalidraw, Audio, Video, Archive, Schriften und die üblichen Programmiersprachen. `README.md`, `LICENSE`, `CHANGELOG.md`, `package.json` und `.gitignore` haben eigene Symbole.
- Gängige Ordner haben ein eigenes Symbol, offen und geschlossen: images, assets, docs, src, test, public, dist, scripts, attachments und mehr.
- Erscheint bei den Dateien in der Seitenleiste, in den Suchergebnissen und beim Schnellöffnen, sobald Sie **Material** unter **Einstellungen › Darstellung › Dateisymbole** wählen. **Standard** bringt die Symbole von Textus zurück.

Es enthält die Symbole des Themes fürs Schreiben und für alltäglichen Code; jede andere Datei und jeder andere Ordner bekommt das schlichte Datei- oder Ordnersymbol.

## Berechtigungen

Keine. Es gibt Textus nur einen Satz Symbole und liest selbst nichts.
