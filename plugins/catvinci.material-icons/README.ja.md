# Material Icon Theme

サイドバー・検索・クイックオープンのファイルとフォルダーのアイコンを、VS Code の Material Icon Theme のものにします。Markdown、PDF、画像、Word、Excel、コードなどファイルの種類ごとのカラーアイコンと、images・docs・src などのフォルダーのアイコン。設定 › 外観 › ファイルアイコン で選びます。

## できること

- 拡張子やファイル名でファイルにカラーアイコンを付けます。Markdown、テキスト、PDF、画像、Word、Excel と CSV、PowerPoint、JSON、YAML、LaTeX と BibTeX、EPUB、Excalidraw、音声、動画、圧縮ファイル、フォント、よく使うプログラミング言語。`README.md`、`LICENSE`、`CHANGELOG.md`、`package.json`、`.gitignore` には専用のアイコンがあります。
- よくあるフォルダーには、開いたときと閉じたときの専用アイコンがあります。images、assets、docs、src、test、public、dist、scripts、attachments など。
- **設定 › 外観 › ファイルアイコン** で **Material** を選ぶと、サイドバーのファイル、検索結果、クイックオープンに表示されます。**標準** で Textus のアイコンに戻ります。

このテーマのうち、文章とふだんのコードに使うアイコンを収めています。ほかのファイルやフォルダーには、ふつうのファイルやフォルダーのアイコンが付きます。

## 権限

必要ありません。Textus にアイコンを渡すだけで、自分では何も読みません。
