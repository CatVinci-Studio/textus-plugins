# Material 图标主题

侧边栏、搜索和快速打开里的文件与文件夹图标，来自 VS Code 的 Material Icon Theme：每种文件一个彩色图标——Markdown、PDF、图片、Word、Excel、代码——images、docs、src 等文件夹也有自己的图标。在 设置 › 外观 › 文件图标 中选用。

## 它做什么

- 按扩展名或文件名给文件一个彩色图标：Markdown、纯文本、PDF、图片、Word、Excel 和 CSV、PowerPoint、JSON、YAML、LaTeX 和 BibTeX、EPUB、Excalidraw、音频、视频、压缩包、字体，以及常见的编程语言。`README.md`、`LICENSE`、`CHANGELOG.md`、`package.json` 和 `.gitignore` 有各自的图标。
- 常见文件夹有自己的图标，展开和收起各一个：images、assets、docs、src、test、public、dist、scripts、attachments 等。
- 在 **设置 › 外观 › 文件图标** 里选 **Material** 后，侧边栏的文件、搜索结果和快速打开都用这套图标。选 **默认** 换回 Textus 自己的图标。

它带了这套主题 1,256 个图标里的 125 个，写作和日常代码用得到的那些；其余的文件和文件夹仍用普通图标。

## 权限

不需要任何权限。它只给 Textus 一套图标，自己不读取任何东西。
