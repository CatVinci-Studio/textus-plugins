# 文本整理

一键整理文字。每个命令都作用于选中的文字，没有选中就作用于整篇文档，都可以一步撤销。在「插件」菜单或命令面板里找到它们。

没有选中文字时，会先问一句再整理整篇文档。

- **删除空行**：删掉空段落；在选中的文字里，所有空行都删掉。
- **删除行尾空格**：删掉行尾的空格和制表符；用来换行的两个空格保留。
- **中文里改用中文标点**：「你好,世界?」变成「你好，世界？」。1.3.8 这样的小数和英文句子不变。
- **英文里改用英文标点**：「Hello，world！」变成「Hello, world!」；挨着中文的标点不变。
- **全角字母数字转半角**：「ＡＢＣ１２３」变成「ABC123」。
- **合并选中的行**（右键菜单里也有）：选中的几行合成一行，中文之间不加空格，英文单词之间加一个空格。

代码、公式、链接地址、HTML 和文档开头的属性都保持原样。
