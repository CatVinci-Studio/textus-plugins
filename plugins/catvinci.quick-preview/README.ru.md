# Быстрый просмотр

Узнайте, куда ведёт ссылка, не открывая её.

- Наведите указатель на ссылку на другой документ — ссылку Markdown или [[wikilink]].
- Рядом появится карточка с началом документа или с разделом, на который указывает ссылка; для ссылки на `#^id` — с этим блоком.
- **Открыть** переходит к этому документу; **Закрепить** оставляет карточку открытой, пока вы пишете.
