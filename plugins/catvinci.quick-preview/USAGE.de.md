# Schnellvorschau

Lies, wohin ein Link führt, ohne ihn zu öffnen.

- Halte den Zeiger über einen Link zu einem anderen Dokument – einen Markdown-Link oder einen [[wikilink]].
- Eine Karte daneben zeigt den Anfang des Dokuments oder den Abschnitt, den der Link nennt.
- **Anheften** lässt die Karte offen, während du schreibst; ein Klick auf den Titel öffnet das Dokument.
