# 快速預覽

不用開啟，就能看到連結指向的內容：把滑鼠停在指向其他文件的連結上，旁邊的卡片會顯示它的文字。

- 把滑鼠停在指向其他文件的連結上，Markdown 連結或 [[雙向連結]] 都可以。
- 旁邊會出現一張卡片，顯示那篇文件的開頭（不含開頭屬性）。連結指向某個標題（`#標題`）時，顯示那一節；指向某個區塊（`#^id`）時，顯示那一段。
- 卡片最多顯示約 1500 個字元，在段落結尾處截斷。**開啟** 跳到那篇文件；**釘住** 讓卡片在你寫作時一直開著。
- 只預覽目前開啟的資料夾裡的文件。

外掛要求讀取編輯器（知道你指著哪個連結）和讀取檔案（顯示被連結的文件）的權限，從不修改檔案。電腦、iPhone 和 iPad 上都能使用。

## 更新紀錄

- **0.2.3** - 商店簡介改為開頭一句就說明外掛做什麼。
- **0.2.2** - 指向巢狀標題的連結（`[[筆記#A#B]]`）顯示那個標題的段落，和點擊開啟的位置一致。需要 Textus 1.4.0。
- **0.2.1** - 介紹頁重寫：一句話說明它做什麼，再講它能做的事，並列出每個版本的更新。
- **0.2.0** - 指向某個區塊（`#^id`）的連結會顯示那一段。需要 Textus 1.3.9。
- **0.1.3** - 標明執行平台：電腦、iPhone 和 iPad。
- **0.1.2** - 卡片長度固定，不再需要設定。
- **0.1.0-0.1.1** - 最初的版本：指向文件的連結顯示卡片，內容是文件開頭或連結所指的那一節，附「開啟」和「釘住」。
