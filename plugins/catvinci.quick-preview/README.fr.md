# Aperçu rapide

Lisez où mène un lien sans l’ouvrir.

- Laissez le pointeur sur un lien vers un autre document, qu’il s’agisse d’un lien Markdown ou d’un [[wikilink]].
- Une carte à côté affiche le début du document, ou la section que nomme le lien.
- **Ouvrir** mène à ce document ; **Épingler** garde la carte ouverte pendant que vous écrivez.
