# Vista rápida

Lee a dónde lleva un enlace sin abrirlo.

- Deja el puntero sobre un enlace a otro documento, ya sea un enlace de Markdown o un [[wikilink]].
- Una tarjeta a su lado muestra el comienzo del documento, o la sección que nombra el enlace.
- **Fijar** mantiene la tarjeta abierta mientras escribes; haz clic en el título para abrir el documento.
