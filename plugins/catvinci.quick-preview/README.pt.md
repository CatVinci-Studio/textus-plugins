# Prévia rápida

Veja para onde um link leva sem abri-lo.

- Deixe o ponteiro sobre um link para outro documento, seja um link de Markdown ou um [[wikilink]].
- Um cartão ao lado mostra o início do documento, ou a seção que o link nomeia.
- **Abrir** vai para esse documento; **Fixar** mantém o cartão aberto enquanto você escreve.
