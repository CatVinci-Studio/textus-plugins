# Prévia rápida

Leia aonde um link leva sem abri-lo: deixe o ponteiro sobre um link para outro documento e um cartão mostra o texto dele.

- Deixe o ponteiro sobre um link para outro documento, um link Markdown ou um [[link wiki]].
- Um cartão ao lado mostra o início do documento, sem as propriedades. Para um link para um título (`#Título`) mostra essa seção, e para um link para um bloco (`#^id`), esse bloco.
- O cartão mostra até cerca de 1.500 caracteres, cortados no fim de um parágrafo. **Abrir** vai ao documento; **Fixar** mantém o cartão aberto enquanto você escreve.
- Só documentos da pasta aberta são mostrados.

O plugin pede para ler o editor (para saber em que link você aponta) e ler arquivos (para mostrar o documento ligado). Nunca muda um arquivo. Funciona no computador, no iPhone e no iPad.

## Alterações

- **0.2.0** - Um link para um bloco (`#^id`) mostra esse bloco. Requer Textus 1.3.9.
- **0.1.3** - Diz onde funciona: computador, iPhone e iPad.
- **0.1.2** - O tamanho do cartão é fixo em vez de uma configuração.
- **0.1.0-0.1.1** - Primeiras versões: um cartão para links para documentos, com o início do documento ou a seção que o link aponta, e Abrir e Fixar.
