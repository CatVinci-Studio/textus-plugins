# 網頁檢視

在筆記旁的分頁裡開啟網頁，不用離開 Textus 就能閱讀。

## 開啟網頁

- **外掛 › 開啟網頁…**：從最近開過的 20 個網頁裡選一個，或選 **新網頁…** 輸入網址或要搜尋的字詞。**清空這個列表** 會忘掉最近的網頁。
- 選取一個連結或一些文字，按右鍵選 **在分頁中開啟或搜尋選取內容**。如果是 Markdown 連結，會開啟它的網址。
- 在文件裡按住 **Ctrl** 點擊網頁連結（Mac 上是 **⌘**）。要先在外掛設定裡開啟 **按住 Ctrl/⌘ 點擊的網頁連結在分頁中開啟**；否則連結會用瀏覽器開啟，和沒裝這個外掛時一樣。
- 不是網址的文字，會用外掛設定中 **搜尋引擎** 選定的引擎搜尋：DuckDuckGo（預設）、Google、Bing 或百度。網址一律以 https 開啟。

## 在網頁上

- 網頁上方的列顯示目前的網址；點一下就能輸入新網址。
- **⌃** 把這一列收起來，再點小把手就會展開。
- **↗** 用瀏覽器開啟，**↻** 重新載入。

只支援桌面版。

## 權限

- 網路（任何位址）：載入你開啟的網頁。
- 讀取文件：讀取選取的連結或文字。
