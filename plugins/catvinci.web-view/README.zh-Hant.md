# 網頁檢視

在筆記旁邊的分頁中看網頁，不必離開 Textus。

## 開啟網頁

- 在文件裡 **按住 Ctrl 點擊** 網頁連結（Mac 上是 **⌘+點擊**）。
- **外掛程式 › 開啟網頁…**：選一個開過的網頁，或輸入網址；輸入的不是網址時，會拿去搜尋。
- 選取一個連結或一些文字，按右鍵 **在分頁中開啟或搜尋選取內容**。
- 搜尋引擎在外掛程式設定裡選：DuckDuckGo、Google、Bing 或百度。

## 在網頁上

- 網頁上方的列顯示目前的網址；點一下就能輸入新網址。
- **⌃** 把這一列收起來，再點小把手就會展開。
- **↗** 用瀏覽器開啟，**↻** 重新載入。
