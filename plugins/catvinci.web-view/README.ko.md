# 웹 보기

노트 옆 탭에서 웹 페이지를 열어, Textus를 떠나지 않고 읽을 수 있습니다.

## 페이지 열기

- **플러그인 › 웹 페이지 열기…**: 최근에 연 페이지 20개 중에서 고르거나, **새 페이지…**로 주소나 검색할 단어를 입력합니다. **목록 지우기**는 최근 페이지를 잊습니다.
- 링크나 단어를 선택하고 오른쪽 클릭해 **선택한 내용을 탭에서 열거나 검색**을 고르세요. Markdown 링크면 그 주소를 엽니다.
- 문서의 웹 링크를 **Ctrl+클릭**(Mac에서는 **⌘+클릭**)합니다. 먼저 플러그인 설정에서 **Ctrl/⌘ 클릭한 웹 링크를 탭에서 열기**를 켜야 합니다. 끄면 이 플러그인이 없을 때처럼 브라우저에서 열립니다.
- 주소가 아닌 단어는 플러그인 설정의 **검색 엔진**으로 검색합니다: DuckDuckGo(기본값), Google, Bing, Baidu. 주소는 https로 엽니다.

## 페이지에서

- 페이지 위 막대에 지금 주소가 보입니다. 누르면 다른 주소를 입력할 수 있습니다.
- **⌃**로 막대를 접고, 작은 손잡이로 다시 폅니다.
- **↗**는 브라우저에서 열기, **↻**는 새로 고침입니다.

데스크톱에서 동작합니다.

## 권한

- 네트워크(모든 주소): 여는 웹 페이지를 불러오기 위해.
- 문서 읽기: 선택한 링크나 단어를 읽기 위해.

## 변경 내역

- **0.2.2** - 설명과 빈 상태 문구를 짧게 줄였습니다.
- **0.2.1** - 소개 페이지를 새로 썼습니다. 무엇을 하는지 한 문장으로, 할 수 있는 일과 버전별 변경 내역을 담았습니다.
- **0.2.0** - Ctrl/⌘ 클릭한 웹 링크는 설정에서 켰을 때만 탭에서 열리고, 아니면 브라우저에서 열립니다.
- **0.1.2** - 데스크톱 전용이 되었습니다.
- **0.1.0-0.1.1** - 첫 버전들: 주소나 검색을 탭에서 열기, 최근 페이지, 선택한 내용 열기·검색, Ctrl/⌘ 클릭 링크, 검색 엔진 선택.
