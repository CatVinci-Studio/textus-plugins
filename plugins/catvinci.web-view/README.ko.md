# 웹 보기

Textus를 떠나지 않고 노트 옆 탭에서 웹 페이지를 봅니다.

## 페이지 열기

- 문서의 웹 링크를 **Ctrl+클릭**(Mac에서는 **⌘+클릭**)하세요.
- **플러그인 › 웹 페이지 열기…**: 전에 연 페이지를 고르거나 주소를 입력하세요. 주소가 아닌 단어를 입력하면 검색합니다.
- 링크나 단어를 선택하고 오른쪽 클릭, **선택한 내용을 탭에서 열거나 검색**.
- 검색 엔진은 플러그인 설정에서 고릅니다: DuckDuckGo, Google, Bing, Baidu.

## 페이지에서

- 페이지 위 막대에 지금 주소가 보입니다. 누르면 다른 주소를 입력할 수 있습니다.
- **⌃**로 막대를 접고, 작은 손잡이로 다시 폅니다.
- **↗**는 브라우저에서 열기, **↻**는 새로 고침입니다.
