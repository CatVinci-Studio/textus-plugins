# Web View

Opens web pages in a tab beside your notes, so you can read them without leaving Textus.

## Open a page

- **Plugins › Open a Web Page…**: pick one of the last 20 pages you opened, or **New page…** to type an address or words to search for. **Clear this list** forgets the recent pages.
- Select a link or some words, right-click, and choose **Open or search the selection in a tab**. For a Markdown link, its address opens.
- **Ctrl+click** a web link in a document (**⌘+click** on a Mac). Turn on **Open Ctrl/Cmd+clicked web links in a tab** in the plugin's settings first; otherwise they open in your browser, as without this plugin.
- Words that aren't an address are searched with the engine under **Search with** in the plugin's settings: DuckDuckGo (the default), Google, Bing or Baidu. Addresses open over https.

## On the page

- The bar above the page shows where you are; click it to type another address.
- **⌃** folds the bar away; the small handle brings it back.
- **↗** opens the page in your browser, **↻** reloads it.

Runs on the desktop.

## Permissions

- Network, any address: to load the web pages you open.
- Read the document: to read the selected link or words.
