# Web View

Read web pages in a tab beside your notes, without leaving Textus.

## Open a page

- **Ctrl+click** a web link in a document (**⌘+click** on a Mac). Turn on **Open Ctrl/Cmd+clicked web links in a tab** in its settings first; otherwise they open in your browser.
- **Plugins › Open a Web Page…**: pick a page you opened before, or type an address - or words, which are searched for.
- Select a link or some words, right-click, **Open or search the selection in a tab**.
- The search engine is in the plugin's settings: DuckDuckGo, Google, Bing or Baidu.

## On the page

- The bar above the page shows where you are; click it to type another address.
- **⌃** folds the bar away; the small handle brings it back.
- **↗** opens the page in your browser, **↻** reloads it.
