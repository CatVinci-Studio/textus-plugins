# Visão web

Abre páginas da web numa aba ao lado das suas notas, para lê-las sem sair do Textus.

## Abrir uma página

- **Plugins › Abrir uma página da web…**: escolha uma das últimas 20 páginas que você abriu, ou **Nova página…** para digitar um endereço ou palavras para pesquisar. **Limpar esta lista** esquece as páginas recentes.
- Selecione um link ou algumas palavras, clique com o botão direito e escolha **Abrir ou pesquisar a seleção numa aba**. Num link Markdown, abre o endereço dele.
- **Ctrl+clique** num link da web num documento (**⌘+clique** no Mac). Ligue antes **Abrir numa aba os links da web clicados com Ctrl/⌘** nos ajustes do plugin; senão eles abrem no navegador, como sem este plugin.
- Palavras que não são um endereço são pesquisadas com o buscador escolhido em **Pesquisar com**, nos ajustes do plugin: DuckDuckGo (padrão), Google, Bing ou Baidu. Os endereços abrem por https.

## Na página

- A barra acima da página mostra onde você está; clique nela para digitar outro endereço.
- **⌃** recolhe a barra; a pequena alça a traz de volta.
- **↗** abre a página no navegador, **↻** recarrega.

Funciona no desktop.

## Permissões

- Rede, qualquer endereço: para carregar as páginas da web que você abre.
- Ler o documento: para ler o link ou as palavras selecionadas.
