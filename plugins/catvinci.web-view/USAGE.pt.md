# Visão web

Leia páginas da web numa aba ao lado das suas notas, sem sair do Textus.

## Abrir uma página

- **Ctrl+clique** num link da web num documento (**⌘+clique** num Mac).
- **Plugins › Abrir uma página da web…** e digite um endereço.
- Selecione um link, clique com o botão direito, **Abrir o link selecionado numa aba**.

## Na página

- A barra acima da página mostra onde você está; clique nela para digitar outro endereço.
- **⌃** recolhe a barra; a pequena alça a traz de volta.
- **↗** abre a página no navegador, **↻** recarrega.
