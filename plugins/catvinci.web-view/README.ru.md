# Веб-страницы

Открывает веб-страницы во вкладке рядом с заметками, чтобы читать их, не выходя из Textus.

## Открыть страницу

- **Плагины › Открыть веб-страницу…**: выберите одну из 20 последних открытых страниц или **Новая страница…**, чтобы ввести адрес или слова для поиска. **Очистить список** забывает недавние страницы.
- Выделите ссылку или слова, щёлкните правой кнопкой и выберите **Открыть или найти выделенное во вкладке**. Для ссылки Markdown открывается её адрес.
- **Ctrl+щелчок** по веб-ссылке в документе (**⌘+щелчок** на Mac). Сначала включите **Открывать во вкладке веб-ссылки по Ctrl/⌘+щелчку** в настройках плагина; иначе они откроются в браузере, как без этого плагина.
- Слова, которые не являются адресом, ищутся через поисковик из пункта **Поиск через** в настройках плагина: DuckDuckGo (по умолчанию), Google, Bing или Baidu. Адреса открываются по https.

## На странице

- Панель над страницей показывает, где вы; щёлкните по ней, чтобы ввести другой адрес.
- **⌃** сворачивает панель; маленькая ручка возвращает её.
- **↗** открывает страницу в браузере, **↻** перезагружает.

Работает на компьютере.

## Разрешения

- Сеть, любой адрес: чтобы загружать открываемые вами страницы.
- Чтение документа: чтобы прочитать выделенную ссылку или слова.

- **0.1.2** - Только для компьютера.
