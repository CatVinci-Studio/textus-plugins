# 网页视图

在笔记旁边的标签页里看网页，不用离开 Textus。

## 打开网页

- 在文档里 **按住 Ctrl 点击** 网页链接（Mac 上是 **⌘+点击**）。
- **插件 › 打开网页…**：选一个打开过的网页，或输入网址；输入的不是网址时，会拿去搜索。
- 选中一个链接或一些文字，右键 **在标签页中打开或搜索选中内容**。
- 搜索引擎在插件设置里选：DuckDuckGo、Google、Bing 或百度。

## 在网页上

- 网页上方的栏显示当前地址；点它可以输入新网址。
- **⌃** 把这一栏收起来，再点小把手就展开。
- **↗** 用浏览器打开，**↻** 刷新。
