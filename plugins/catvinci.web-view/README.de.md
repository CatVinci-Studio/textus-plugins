# Webansicht

Öffnet Webseiten in einem Tab neben Ihren Notizen, damit Sie sie lesen können, ohne Textus zu verlassen.

## Eine Seite öffnen

- **Plugins › Webseite öffnen…**: Wählen Sie eine der letzten 20 geöffneten Seiten oder **Neue Seite…**, um eine Adresse oder Suchbegriffe einzugeben. **Liste leeren** vergisst die letzten Seiten.
- Markieren Sie einen Link oder ein paar Wörter, klicken Sie mit rechts und wählen Sie **Auswahl im Tab öffnen oder suchen**. Bei einem Markdown-Link öffnet sich seine Adresse.
- **Strg+Klick** auf einen Weblink in einem Dokument (**⌘+Klick** auf dem Mac). Schalten Sie vorher **Mit Strg/⌘ angeklickte Weblinks in einem Tab öffnen** in den Einstellungen des Plugins ein; sonst öffnen sie sich im Browser, wie ohne dieses Plugin.
- Wörter, die keine Adresse sind, werden mit der Suchmaschine unter **Suchen mit** in den Einstellungen des Plugins gesucht: DuckDuckGo (Standard), Google, Bing oder Baidu. Adressen öffnen sich über https.

## Auf der Seite

- Die Leiste über der Seite zeigt, wo Sie sind; ein Klick darauf nimmt eine andere Adresse an.
- **⌃** klappt die Leiste weg; der kleine Griff holt sie zurück.
- **↗** öffnet die Seite im Browser, **↻** lädt sie neu.

Läuft auf dem Desktop.

## Berechtigungen

- Netzwerk, jede Adresse: um die Webseiten zu laden, die Sie öffnen.
- Dokument lesen: um den markierten Link oder die markierten Wörter zu lesen.
