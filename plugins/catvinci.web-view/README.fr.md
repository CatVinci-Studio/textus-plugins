# Vue web

Ouvre des pages web dans un onglet à côté de vos notes, pour les lire sans quitter Textus.

## Ouvrir une page

- **Plugins › Ouvrir une page web…** : choisissez l’une des 20 dernières pages ouvertes, ou **Nouvelle page…** pour saisir une adresse ou des mots à rechercher. **Vider cette liste** oublie les pages récentes.
- Sélectionnez un lien ou quelques mots, faites un clic droit et choisissez **Ouvrir ou rechercher la sélection dans un onglet**. Pour un lien Markdown, c’est son adresse qui s’ouvre.
- **Ctrl+clic** sur un lien web dans un document (**⌘+clic** sur Mac). Activez d’abord **Ouvrir dans un onglet les liens web cliqués avec Ctrl/⌘** dans les réglages du plugin ; sinon ils s’ouvrent dans votre navigateur, comme sans ce plugin.
- Les mots qui ne sont pas une adresse sont recherchés avec le moteur choisi sous **Rechercher avec**, dans les réglages du plugin : DuckDuckGo (par défaut), Google, Bing ou Baidu. Les adresses s’ouvrent en https.

## Sur la page

- La barre au-dessus de la page montre où vous êtes ; cliquez dessus pour saisir une autre adresse.
- **⌃** replie la barre ; la petite poignée la ramène.
- **↗** ouvre la page dans votre navigateur, **↻** la recharge.

Fonctionne sur ordinateur.

## Autorisations

- Réseau, toute adresse : pour charger les pages web que vous ouvrez.
- Lire le document : pour lire le lien ou les mots sélectionnés.
