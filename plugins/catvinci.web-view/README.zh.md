# 网页视图

在笔记旁边的标签页里打开网页，不用离开 Textus 就能阅读。

## 打开网页

- **插件 › 打开网页…**：从最近打开过的 20 个网页里选一个，或选 **新网页…** 输入网址或要搜索的词。**清空这个列表** 会忘掉最近的网页。
- 选中一个链接或一些文字，右键选 **在标签页中打开或搜索选中内容**。如果是 Markdown 链接，会打开它的网址。
- 在文档里按住 **Ctrl** 点击网页链接（Mac 上是 **⌘**）。要先在插件设置里打开 **按住 Ctrl/⌘ 点击的网页链接在标签页中打开**；否则链接会用浏览器打开，和没装这个插件时一样。
- 不是网址的文字，会用插件设置里 **搜索引擎** 选定的引擎搜索：DuckDuckGo（默认）、Google、Bing 或百度。网址一律用 https 打开。

## 在网页上

- 网页上方的栏显示当前地址；点它可以输入新网址。
- **⌃** 把这一栏收起来，再点小把手就展开。
- **↗** 用浏览器打开，**↻** 刷新。

只支持桌面版。

## 权限

- 网络（任意地址）：加载你打开的网页。
- 读取文档：读取选中的链接或文字。
