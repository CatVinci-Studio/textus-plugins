# Веб-страницы

Читайте веб-страницы во вкладке рядом с заметками, не выходя из Textus.

## Открыть страницу

- **Ctrl+щелчок** по веб-ссылке в документе (**⌘+щелчок** на Mac).
- **Плагины › Открыть веб-страницу…** и введите адрес.
- Выделите ссылку, правый щелчок, **Открыть выделенную ссылку во вкладке**.

## На странице

- Панель над страницей показывает, где вы; щёлкните по ней, чтобы ввести другой адрес.
- **⌃** сворачивает панель; маленькая ручка возвращает её.
- **↗** открывает страницу в браузере, **↻** перезагружает.
