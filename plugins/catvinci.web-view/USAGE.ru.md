# Веб-страницы

Читайте веб-страницы во вкладке рядом с заметками, не выходя из Textus.

## Открыть страницу

- **Ctrl+щелчок** по веб-ссылке в документе (**⌘+щелчок** на Mac).
- **Плагины › Открыть веб-страницу…**: выберите страницу, открытую раньше, или введите адрес. Если ввести слова, по ним будет поиск.
- Выделите ссылку или несколько слов, правый щелчок, **Открыть или найти выделенное во вкладке**.
- Поисковик выбирается в настройках плагина: DuckDuckGo, Google, Bing или Baidu.

## На странице

- Панель над страницей показывает, где вы; щёлкните по ней, чтобы ввести другой адрес.
- **⌃** сворачивает панель; маленькая ручка возвращает её.
- **↗** открывает страницу в браузере, **↻** перезагружает.
