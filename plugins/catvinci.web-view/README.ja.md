# ウェブビュー

ノートの隣のタブでウェブページを開き、Textus から離れずに読めます。

## ページを開く

- **プラグイン › ウェブページを開く…**：最近開いた 20 ページから選ぶか、**新しいページ…** でアドレスや検索する語句を入力します。**このリストを消去** で最近のページを忘れます。
- リンクや語句を選択して右クリックし、**選択範囲をタブで開く・検索する** を選びます。Markdown のリンクなら、そのアドレスを開きます。
- 文書のウェブリンクを **Ctrl+クリック**（Mac では **⌘+クリック**）。先にプラグインの設定で **Ctrl/⌘ クリックしたウェブリンクをタブで開く** をオンにしてください。オフのときは、このプラグインがない場合と同じくブラウザで開きます。
- アドレスでない語句は、プラグインの設定の **検索エンジン** で検索します：DuckDuckGo（既定）、Google、Bing、Baidu。アドレスは https で開きます。

## ページの上で

- ページ上のバーに今のアドレスが出ます。クリックすると別のアドレスを入力できます。
- **⌃** でバーをたたみ、小さなつまみで戻します。
- **↗** でブラウザで開き、**↻** で再読み込み。

デスクトップ版で動きます。

## 権限

- ネットワーク（すべてのアドレス）：開いたウェブページを読み込むため。
- 文書の読み取り：選択したリンクや語句を読むため。
