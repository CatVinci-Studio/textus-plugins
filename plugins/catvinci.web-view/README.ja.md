# ウェブビュー

Textus を離れずに、ノートの隣のタブでウェブページを読めます。

## ページを開く

- 文書のウェブリンクを **Ctrl+クリック**（Mac では **⌘+クリック**）。
- **プラグイン › ウェブページを開く…**：以前開いたページを選ぶか、アドレスを入力します。アドレスでない言葉は検索されます。
- リンクや言葉を選択して右クリック、**選択範囲をタブで開く・検索する**。
- 検索エンジンはプラグインの設定で選べます：DuckDuckGo、Google、Bing、Baidu。

## ページの上で

- ページ上のバーに今のアドレスが出ます。クリックすると別のアドレスを入力できます。
- **⌃** でバーをたたみ、小さなつまみで戻します。
- **↗** でブラウザで開き、**↻** で再読み込み。
