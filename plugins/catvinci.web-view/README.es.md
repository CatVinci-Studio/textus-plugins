# Vista web

Abre páginas web en una pestaña junto a tus notas, para leerlas sin salir de Textus.

## Abrir una página

- **Plugins › Abrir una página web…**: elige una de las últimas 20 páginas que abriste, o **Página nueva…** para escribir una dirección o palabras que buscar. **Vaciar esta lista** olvida las páginas recientes.
- Selecciona un enlace o unas palabras, haz clic derecho y elige **Abrir o buscar la selección en una pestaña**. Si es un enlace Markdown, se abre su dirección.
- **Ctrl+clic** en un enlace web de un documento (**⌘+clic** en un Mac). Activa antes **Abrir en una pestaña los enlaces web con Ctrl/⌘+clic** en los ajustes del plugin; si no, se abren en tu navegador, como sin este plugin.
- Las palabras que no son una dirección se buscan con el motor elegido en **Buscar con**, en los ajustes del plugin: DuckDuckGo (por defecto), Google, Bing o Baidu. Las direcciones se abren por https.

## En la página

- La barra sobre la página muestra dónde estás; haz clic en ella para escribir otra dirección.
- **⌃** pliega la barra; el pequeño tirador la trae de vuelta.
- **↗** abre la página en tu navegador, **↻** la recarga.

Funciona en escritorio.

## Permisos

- Red, cualquier dirección: para cargar las páginas web que abres.
- Leer el documento: para leer el enlace o las palabras seleccionadas.

- **0.1.0-0.1.1** - Primeras versiones: una dirección o una búsqueda en una pestaña, páginas recientes, abrir o buscar la selección, enlaces con Ctrl/⌘+clic, elección de buscador.
