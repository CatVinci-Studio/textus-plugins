# Vue web

Lisez des pages web dans un onglet à côté de vos notes, sans quitter Textus.

## Ouvrir une page

- **Ctrl+clic** sur un lien web d’un document (**⌘+clic** sur Mac).
- **Extensions › Ouvrir une page web…** : choisissez une page déjà ouverte, ou saisissez une adresse – ou des mots, qui seront recherchés.
- Sélectionnez un lien ou quelques mots, clic droit, **Ouvrir ou rechercher la sélection dans un onglet**.
- Le moteur de recherche se choisit dans les réglages de l’extension : DuckDuckGo, Google, Bing ou Baidu.

## Sur la page

- La barre au-dessus de la page montre où vous êtes ; cliquez dessus pour saisir une autre adresse.
- **⌃** replie la barre ; la petite poignée la ramène.
- **↗** ouvre la page dans votre navigateur, **↻** la recharge.
