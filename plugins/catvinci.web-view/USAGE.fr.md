# Vue web

Lisez des pages web dans un onglet à côté de vos notes, sans quitter Textus.

## Ouvrir une page

- **Ctrl+clic** sur un lien web d’un document (**⌘+clic** sur Mac).
- **Extensions › Ouvrir une page web…** et saisissez une adresse.
- Sélectionnez un lien, clic droit, **Ouvrir le lien sélectionné dans un onglet**.

## Sur la page

- La barre au-dessus de la page montre où vous êtes ; cliquez dessus pour saisir une autre adresse.
- **⌃** replie la barre ; la petite poignée la ramène.
- **↗** ouvre la page dans votre navigateur, **↻** la recharge.
