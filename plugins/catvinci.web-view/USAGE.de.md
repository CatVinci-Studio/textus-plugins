# Webansicht

Lies Webseiten in einem Tab neben deinen Notizen, ohne Textus zu verlassen.

## Eine Seite öffnen

- **Strg+Klick** auf einen Weblink im Dokument (**⌘+Klick** auf dem Mac).
- **Plugins › Webseite öffnen…** und eine Adresse eingeben.
- Einen Link markieren, Rechtsklick, **Markierten Link in einem Tab öffnen**.

## Auf der Seite

- Die Leiste über der Seite zeigt, wo du bist; ein Klick darauf nimmt eine andere Adresse an.
- **⌃** klappt die Leiste weg; der kleine Griff holt sie zurück.
- **↗** öffnet die Seite im Browser, **↻** lädt sie neu.
