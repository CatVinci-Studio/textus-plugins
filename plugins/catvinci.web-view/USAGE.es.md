# Vista web

Lee páginas web en una pestaña junto a tus notas, sin salir de Textus.

## Abrir una página

- **Ctrl+clic** en un enlace web de un documento (**⌘+clic** en un Mac).
- **Complementos › Abrir una página web…** y escribe una dirección.
- Selecciona un enlace, clic derecho, **Abrir el enlace seleccionado en una pestaña**.

## En la página

- La barra sobre la página muestra dónde estás; haz clic en ella para escribir otra dirección.
- **⌃** pliega la barra; el pequeño tirador la trae de vuelta.
- **↗** abre la página en tu navegador, **↻** la recarga.
