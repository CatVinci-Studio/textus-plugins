# Imagens do Openverse

Deixa o Textus AI encontrar no [Openverse](https://openverse.org) imagens com licença aberta para os seus documentos.

## Como usar

- Peça ao Textus AI uma foto ou um desenho real de algo, como "uma imagem de um farol ao anoitecer". Ele pesquisa no Openverse (Flickr, museus e mais) e coloca a imagem com a linha de crédito embaixo.
- Cada crédito nomeia o autor, a licença e a fonte, com link para a página de onde a imagem veio.
- Só são usadas imagens CC BY, CC BY-SA, CC0 e de domínio público. O Openverse repassa o que cada fonte declara, então cada licença é verificada de novo antes de uma imagem ser oferecida.
- Pesquisas em inglês encontram mais.
- O plugin não tem menu nem ajustes próprios: ele acrescenta uma ferramenta ao Textus AI.

## Permissões

- **Rede, só api.openverse.org**: para pesquisar no Openverse. Não é preciso conta nem chave; o Openverse limita quantas pesquisas um endereço pode fazer por dia.
- **Ferramentas para o Textus AI**: para que o Textus AI possa pesquisar imagens.

## Ferramentas para o Textus AI

Com o plugin instalado, o Textus AI pode usá-las numa conversa:

- `find_open_pictures`: Encontra no Openverse imagens com licença aberta (CC BY, CC BY-SA, CC0, domínio público) para uma descrição, cada uma com o seu URL e a linha de crédito que a licença pede, para pôr sob a imagem. Use quando o utilizador quiser uma foto ou desenho real e não uma imagem gerada.
