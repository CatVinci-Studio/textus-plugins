# Imágenes de Openverse

Permite que Textus AI encuentre imágenes con licencia abierta en [Openverse](https://openverse.org) para tus documentos.

## Cómo usarlo

- Pide a Textus AI una foto o un dibujo real de algo, como «una foto de un faro al atardecer». Busca en Openverse (Flickr, museos y más) y coloca la imagen con su línea de crédito debajo.
- Cada crédito nombra al autor, la licencia y la fuente, con un enlace a la página de donde viene la imagen.
- Solo se usan imágenes CC BY, CC BY-SA, CC0 y de dominio público. Openverse transmite lo que declara cada fuente, así que cada licencia se vuelve a comprobar antes de ofrecer una imagen.
- Las búsquedas en inglés encuentran más.
- El plugin no tiene menú ni ajustes propios: añade una herramienta a Textus AI.

## Permisos

- **Red, solo api.openverse.org**: para buscar en Openverse. No hace falta cuenta ni clave; Openverse limita cuántas búsquedas puede hacer una dirección al día.
- **Herramientas para Textus AI**: para que Textus AI pueda buscar imágenes.

## Herramientas para Textus AI

Con el plugin instalado, Textus AI puede usarlas en una conversación:

- `find_open_pictures`: Busca en Openverse imágenes con licencia abierta (CC BY, CC BY-SA, CC0, dominio público) para una descripción, cada una con su URL y la línea de crédito que pide su licencia, para ponerla bajo la imagen. Úsala cuando el usuario quiera una foto o un dibujo real y no uno generado.
