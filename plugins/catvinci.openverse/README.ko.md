# Openverse 그림

Textus AI가 [Openverse](https://openverse.org)에서 자유 이용 허락 그림을 찾아 문서에 넣게 합니다.

## 쓰는 법

- Textus AI에게 실제 사진이나 그림을 부탁합니다. 예를 들어 "해 질 녘 등대 사진". Openverse(Flickr, 박물관 등)를 검색해 그림을 넣고 아래에 출처 표시를 붙입니다.
- 출처 표시에는 만든 사람, 라이선스, 출처가 나오며, 그림을 가져온 페이지로 링크됩니다.
- CC BY, CC BY-SA, CC0, 퍼블릭 도메인 그림만 씁니다. Openverse는 각 출처가 밝힌 내용을 그대로 전하므로, 그림을 제안하기 전에 라이선스를 모두 다시 확인합니다.
- 영어로 검색하면 가장 많이 찾습니다.
- 이 플러그인에는 자체 메뉴나 설정이 없습니다. Textus AI에 도구 하나를 더할 뿐입니다.

## 권한

- **네트워크, api.openverse.org만**: Openverse를 검색하기 위해. 계정이나 키는 필요 없으며, Openverse는 한 주소에서 하루에 할 수 있는 검색 횟수를 제한합니다.
- **Textus AI 도구**: Textus AI가 그림을 검색할 수 있도록.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `find_open_pictures`: 설명에 맞는 자유 이용 허락 그림(CC BY, CC BY-SA, CC0, 퍼블릭 도메인)을 Openverse에서 찾아 각각의 URL과 그림 아래에 둘 출처 표시를 돌려줍니다. 생성한 그림이 아니라 실제 사진이나 그림이 필요할 때 씁니다.
