# Закладки

Отметьте фрагмент и возвращайтесь к нему из боковой панели — в любом документе.

- Выделите слова и выберите **Добавить выделение в закладки** (правый щелчок или меню «Плагины»).
- Вкладка **Закладки** в боковой панели показывает их по документам; щелчок возвращает к этим словам.
- Правый щелчок по закладке — удалить. Закладки следуют за переименованным или перемещённым документом.
