# 북마크

글의 한 부분에 북마크를 걸고 사이드바에서 언제든 돌아갑니다. 문서를 넘나들어도 됩니다.

- 글자를 선택하고 **선택 영역 북마크**(오른쪽 클릭 또는 플러그인 메뉴)를 고르세요.
- 사이드바의 **북마크** 탭에 문서별로 나열되며, 누르면 그 글자로 돌아갑니다.
- 북마크를 오른쪽 클릭하면 지울 수 있습니다. 문서 이름을 바꾸거나 옮겨도 북마크가 따라갑니다.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `list_bookmarks`: 사용자의 북마크를 나열합니다. 각 문서에서 북마크한 글과, 열린 폴더에서 그 문서의 경로입니다.
