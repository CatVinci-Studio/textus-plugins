# Marcadores

Marca un pasaje y vuelve a él desde la barra lateral, entre documentos.

- Selecciona unas palabras y elige **Marcar la selección** (clic derecho o el menú Plugins).
- La pestaña **Marcadores** de la barra lateral los lista por documento; haz clic para volver a esas palabras.
- Clic derecho en un marcador para quitarlo. Los marcadores siguen al documento si se renombra o mueve.
