# Favoritos

Marque um trecho e volte a ele pela barra lateral, entre documentos.

- Selecione palavras e escolha **Marcar a seleção** (clique direito ou o menu Plugins).
- A aba **Favoritos** na barra lateral os lista por documento; clique para voltar a essas palavras.
- Clique direito num favorito para removê-lo. Os favoritos acompanham um documento renomeado ou movido.

<!-- ai-tools -->
## Ferramentas para o Textus AI

Com o plugin instalado, o Textus AI pode usá-las numa conversa:

- `list_bookmarks`: Lista os marcadores do utilizador: as palavras marcadas em cada documento, com o caminho do documento na pasta aberta.
