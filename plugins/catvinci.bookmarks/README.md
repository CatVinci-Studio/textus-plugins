# Bookmarks

Bookmark a passage and come back to it from the sidebar - across documents.

- Select some words and choose **Bookmark Selection** (right-click, or the Plugins menu).
- The **Bookmarks** tab in the sidebar lists them by document; click one to go back to those words.
- Right-click a bookmark to remove it. Bookmarks follow a document that is renamed or moved.

<!-- ai-tools -->
## Tools for Textus AI

Once it is installed, Textus AI can use these in a conversation:

- `list_bookmarks`: Lists the user's bookmarks: the words bookmarked in each document, with the document's path in the open folder.
