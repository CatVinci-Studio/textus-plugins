# Lesezeichen

Setzen Sie ein Lesezeichen auf eine Stelle und kehren Sie über die Seitenleiste dorthin zurück – dokumentübergreifend.

- Markieren Sie ein paar Wörter und wählen Sie **Auswahl als Lesezeichen** (Rechtsklick oder das Plugins-Menü).
- Der Reiter **Lesezeichen** in der Seitenleiste listet sie nach Dokument; ein Klick führt zu diesen Wörtern zurück.
- Rechtsklick auf ein Lesezeichen entfernt es. Lesezeichen folgen einem umbenannten oder verschobenen Dokument.

## Werkzeuge für Textus AI

Ist das Plugin installiert, kann Textus AI sie im Gespräch nutzen:

- `list_bookmarks`: Listet die Lesezeichen des Nutzers auf: die markierten Worte in jedem Dokument, mit dem Pfad des Dokuments im geöffneten Ordner.
