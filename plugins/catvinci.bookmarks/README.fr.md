# Signets

Mettez un signet sur un passage et revenez-y depuis la barre latérale, d’un document à l’autre.

- Sélectionnez des mots et choisissez **Signet sur la sélection** (clic droit ou le menu Plugins).
- L’onglet **Signets** de la barre latérale les liste par document ; cliquez pour revenir à ces mots.
- Clic droit sur un signet pour le supprimer. Les signets suivent un document renommé ou déplacé.

<!-- ai-tools -->
## Outils pour Textus AI

Une fois le plugin installé, Textus AI peut s’en servir dans une conversation :

- `list_bookmarks`: Liste les signets de l'utilisateur : les mots marqués dans chaque document, avec le chemin du document dans le dossier ouvert.
