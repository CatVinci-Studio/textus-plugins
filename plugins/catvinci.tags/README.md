# Tags

Every `#tag` in the open folder, in the sidebar, with how many notes use it.

- Open a tag to see its notes, and click one to open it.
- Right-click a tag and choose **Rename…** to rename it in every note. Rename it to a tag you already have, and the two become one.
- Tags in front matter (`tags: [a, b]`, or a list under `tags:`) are renamed too. Code, inline code and longer tags that start the same (`#drafts` when you rename `#draft`) are left alone.

## Tools for Textus AI

Once it is installed, Textus AI can use these in a conversation:

- `list_tags`: Lists every #tag in the open folder's documents with how many documents use it, the most used first.
- `notes_with_tag`: Lists the documents in the open folder that have a #tag, each with its title, path and tags.
