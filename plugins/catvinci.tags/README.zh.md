# 标签

在侧边栏列出所打开文件夹里的每个 `#标签`，以及使用它的笔记数量。

- 展开一个标签查看它的笔记，点击即可打开。
- 在标签上点右键选**重命名…**，会在所有笔记里一起改。改成一个已有的标签名，两个标签就合并成一个。
- front matter 里的标签（`tags: [a, b]`，或 `tags:` 下面的列表）也会一起改；代码块、行内代码，以及以它开头的更长标签（改 `#draft` 时的 `#drafts`）不会被改动。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `list_tags`：列出打开的文件夹中所有文档用到的 #标签，以及每个标签被多少篇文档使用，用得最多的排在前面。
- `notes_with_tag`：列出打开的文件夹中带有某个 #标签的文档，每篇带标题、路径和它的全部标签。
