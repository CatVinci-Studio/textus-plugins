# クイックノート

文書を離れずに、さっと書き留められます。

- **Ctrl+Alt+N**（Mac では **⌘⌥N**）か **プラグイン › 新しいクイックノート…** でノートを書きます。
- Textus をバックグラウンドで動かしていれば、メニューバーやトレイのアイコンからも同じことができます。ウインドウを開いていなくても大丈夫です。
- サイドバーの **クイックノート** タブに一覧が並びます。文書に挿入したり、文書として開いたり、削除したりできます。
- うっかり削除した？下に出る **元に戻す** を数秒のうちに押せば戻せます。新しく作って何も書かなかったノートは自動で消えます。
- ノートが増えると、上に検索欄が表示されます。
