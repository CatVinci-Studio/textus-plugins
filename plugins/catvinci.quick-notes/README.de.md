# Schnellnotizen

Schreib etwas auf, ohne das Dokument zu verlassen.

- **Ctrl+Alt+N** (**⌘⌥N** auf dem Mac) oder **Plugins › Neue Schnellnotiz…** nimmt eine Notiz auf.
- Läuft Textus im Hintergrund, findest du dasselbe in der Menüleiste oder im Tray-Symbol – auch ohne geöffnetes Fenster.
- Der Tab **Schnellnotizen** in der Seitenleiste listet sie auf: Füge eine ins Dokument ein, öffne sie als Dokument oder lösche sie.
- Aus Versehen gelöscht? **Rückgängig** unten holt sie ein paar Sekunden lang zurück. Eine neue Notiz, die leer bleibt, verschwindet von selbst.
- Bei vielen Notizen erscheint oben ein Suchfeld.

## Werkzeuge für Textus AI

Ist das Plugin installiert, kann Textus AI sie im Gespräch nutzen:

- `add_note`: Fügt oben in der Liste der Schnellnotizen in der Seitenleiste eine Notiz hinzu, die sich später in ein Dokument einfügen oder als Dokument öffnen lässt. Das heutige Journal ist append_to_daily_note; eine Aufgabe add_task.
