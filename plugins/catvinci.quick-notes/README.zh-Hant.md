# 快速筆記

不離開目前文件，隨手記一筆。

- 按 **Ctrl+Alt+N**（Mac 上為 **⌘⌥N**），或選擇 **外掛程式 › 新增快速筆記…**，記下一則。
- 開啟背景執行時，選單列或系統匣圖示中也有這個項目，即使沒有開啟視窗也能記。
- 側邊欄的 **快速筆記** 分頁會列出所有筆記：可以插入文件、以文件開啟，或刪除。
- 不小心刪掉了？底部會出現 **復原**，幾秒內點它就能找回。新增後什麼都沒寫的筆記會自動移除。
- 筆記一多，頂端就會出現搜尋欄。

## Textus AI 工具

裝上這個外掛後，Textus AI 在對話中可以使用：

- `add_note`：在側邊欄的快速筆記列表頂端新增一則筆記，之後可以插入文件，或單獨開成一份文件。
