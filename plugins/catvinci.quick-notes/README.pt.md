# Notas rápidas

Anote algo sem sair do documento.

- **Ctrl+Alt+N** (**⌘⌥N** no Mac), ou **Plugins › Nova nota rápida…**, cria uma nota.
- Com o Textus em segundo plano, o mesmo está na barra de menus ou no ícone da bandeja, mesmo sem nenhuma janela aberta.
- A aba **Notas rápidas** da barra lateral as lista: insira uma no documento, abra-a como documento ou exclua-a.
- Apagou sem querer? **Desfazer**, embaixo, a traz de volta por alguns segundos. Uma nota nova deixada em branco some sozinha.
- Com muitas notas, um campo de busca aparece no topo.

## Ferramentas para o Textus AI

Com o plugin instalado, o Textus AI pode usá-las numa conversa:

- `add_note`: Adiciona uma nota rápida no topo da lista de Notas rápidas da barra lateral, para inserir depois num documento ou abrir como um. O diário de hoje é append_to_daily_note; uma tarefa, add_task.
