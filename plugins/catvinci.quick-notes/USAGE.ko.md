# 빠른 메모

문서를 떠나지 않고 바로 적어 둡니다.

- **Ctrl+Alt+N**(Mac에서는 **⌘⌥N**)을 누르거나 **플러그인 › 새 빠른 메모…**를 선택해 메모합니다.
- Textus를 백그라운드에서 실행 중이면 메뉴 막대나 트레이 아이콘에서도 같은 일을 할 수 있습니다. 열린 창이 없어도 됩니다.
- 사이드바의 **빠른 메모** 탭에 목록이 나타납니다. 문서에 넣거나, 문서로 열거나, 삭제할 수 있습니다.
- 실수로 지웠나요? 아래에 나타나는 **실행 취소**를 몇 초 안에 누르면 되살아납니다. 새로 만들고 아무것도 쓰지 않은 메모는 저절로 사라집니다.
- 메모가 많아지면 맨 위에 검색란이 나타납니다.
