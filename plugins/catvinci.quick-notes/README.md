# Quick Notes

Jot something down without leaving the document.

- **Ctrl+Alt+N** (**⌘⌥N** on a Mac), or **Plugins › New Quick Note…**, takes a note.
- With Textus in the background, the same is in the menu bar or tray icon - even with no window open.
- The **Quick Notes** tab in the sidebar lists them: insert one into the document, open it as a document, or delete it.
- Deleted one by mistake? **Undo** at the bottom brings it back for a few seconds. A new note left empty goes by itself.
- With many notes, a search field shows at the top.

## Tools for Textus AI

Once it is installed, Textus AI can use these in a conversation:

- `add_note`: Adds a quick note to the top of the Quick Notes list in the sidebar, to be inserted into a document or opened as one later.
