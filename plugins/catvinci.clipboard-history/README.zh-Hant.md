# 剪貼簿紀錄

把你在文件裡拷貝或剪下的內容留在側欄，隨時可以再放回去。

在文件裡拷貝或剪下文字後，它會出現在側欄的 **剪貼簿紀錄** 分頁，最新的在最上面。保留最近 30 筆，重新啟動 Textus 後也還在。再拷貝一次相同的文字，它會回到最上面；特別長的內容（超過 50,000 個字元）不會記錄。

- 點一筆，就在游標處插入。
- 在某一筆上按右鍵，可以 **拷貝** 或 **移除**。
- **清除剪貼簿紀錄**（在任一筆上按右鍵，或 **外掛 › 清除剪貼簿紀錄**）會清空整個列表。

只記錄你在文件裡拷貝的內容，不會記錄在設定或其他 App 裡拷貝的東西。列表只存在 Textus 裡。

## 權限

- 剪貼簿：得知你在文件裡拷貝了什麼，並能再拷貝某一筆。
- 修改文件：在游標處插入一筆紀錄。
