# Historique du presse-papiers

Garde dans la barre latérale ce que vous copiez ou coupez dans vos documents, pour le remettre ensuite.

Copiez ou coupez du texte dans un document : il apparaît dans l’onglet **Historique du presse-papiers** de la barre latérale, le plus récent en haut. Les 30 derniers sont gardés, même après un redémarrage de Textus. Copier de nouveau le même texte le remet en haut ; les copies très longues (plus de 50 000 caractères) ne sont pas gardées.

- Cliquez sur une entrée pour l’insérer au curseur.
- Clic droit sur une entrée pour la **Copier** de nouveau ou la **Retirer**.
- **Vider l’historique du presse-papiers** (clic droit sur une entrée, ou **Plugins › Vider l’historique du presse-papiers**) vide la liste.

Seul ce que vous copiez dans vos documents est gardé, jamais ce que vous copiez dans les Réglages ou dans d’autres apps. La liste reste dans Textus.

## Autorisations

- Presse-papiers : pour voir ce que vous copiez dans un document, et copier de nouveau une entrée.
- Modifier le document : pour insérer une entrée au curseur.
