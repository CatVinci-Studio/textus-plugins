# 클립보드 기록

문서에서 복사하거나 잘라낸 내용을 사이드바에 남겨 두고 다시 넣을 수 있습니다.

문서에서 글을 복사하거나 잘라내면 사이드바의 **클립보드 기록** 탭에 최신순으로 나타납니다. 최근 30개를 보관하며, Textus를 다시 시작해도 남아 있습니다. 같은 글을 다시 복사하면 맨 위로 올라가고, 아주 긴 내용(50,000자 초과)은 기록하지 않습니다.

- 항목을 누르면 커서 위치에 넣습니다.
- 항목을 오른쪽 클릭하면 다시 **복사**하거나 **제거**할 수 있습니다.
- **클립보드 기록 지우기**(항목 오른쪽 클릭, 또는 **플러그인 › 클립보드 기록 지우기**)로 목록을 비웁니다.

문서에서 복사한 것만 기록하며, 설정이나 다른 앱에서 복사한 것은 기록하지 않습니다. 목록은 Textus 안에만 저장됩니다.

## 권한

- 클립보드: 문서에서 무엇을 복사했는지 알고, 항목을 다시 복사하기 위해.
- 문서 편집: 커서 위치에 항목을 넣기 위해.

## 변경 내역

- **0.1.1** - 소개 페이지를 새로 썼습니다. 무엇을 하는지 한 문장으로, 할 수 있는 일과 버전별 변경 내역을 담았습니다.
- **0.1.0** - 첫 버전: 최근 30개의 복사 내용을 사이드바에 보여 주고, 누르면 넣고, 오른쪽 클릭으로 다시 복사하거나 제거합니다. Textus 1.3.10이 필요합니다.
