# 剪贴板历史

把你在文档里复制或剪切过的内容留在侧栏，随时可以再放回去。

在文档里复制或剪切文字后，它会出现在侧栏的 **剪贴板历史** 标签页里，最新的在最上面。保留最近 30 条，重启 Textus 后也还在。再次复制同样的文字，它会回到最上面；特别长的内容（超过 50,000 个字符）不会记录。

- 点一条，就在光标处插入它。
- 右键一条，可以 **复制** 或 **移除**。
- **清空剪贴板历史**（右键任意一条，或 **插件 › 清空剪贴板历史**）会清空整个列表。

只记录你在文档里复制的内容，不会记录在设置或其他应用里复制的东西。列表只保存在 Textus 里。

## 权限

- 剪贴板：知道你在文档里复制了什么，并能再次复制某一条。
- 修改文档：在光标处插入一条记录。
