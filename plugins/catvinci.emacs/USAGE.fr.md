# Emacs

Les touches d’Emacs dans l’éditeur.

- **Extensions › Activer ou désactiver les touches Emacs** les active ou les désactive.
- Déplacement : **C-f C-b C-n C-p**, **C-a C-e**, **M-f M-b**, **M-< M->**.
- **C-SPC** place la marque ; **C-w** coupe la région et **C-k** le reste de la ligne, vers le kill ring ; **C-y** colle, **M-y** parcourt l’anneau ; **C-/** annule.
- **M-u**, **M-l** et **M-c** mettent le mot suivant en majuscules, en minuscules ou avec une majuscule initiale.
- Les touches Ctrl que Textus utilise déjà restent à Textus, sauf si vous laissez Emacs les prendre dans les réglages de l’extension.
