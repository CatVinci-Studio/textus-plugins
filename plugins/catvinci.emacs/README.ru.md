# Emacs

Клавиши Emacs в редакторе.

- **Плагины › Включить или выключить клавиши Emacs** переключает их.
- Перемещение: **C-f C-b C-n C-p**, **C-a C-e**, **M-f M-b**, **M-< M->**.
- **C-SPC** ставит метку; **C-w** вырезает область, а **C-k** — остаток строки, оба в kill ring; **C-y** вставляет, **M-y** перебирает кольцо, **C-/** отменяет.
- **M-u**, **M-l** и **M-c** делают следующее слово прописным, строчным или с заглавной буквы.
- Сочетания с Ctrl, которые уже использует Textus, остаются за Textus, пока вы не разрешите Emacs забрать их в настройках плагина.
