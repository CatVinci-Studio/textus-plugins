# Emacs

讓你在編輯器裡用 Emacs 的按鍵移動、設定標記、剪下（kill）和貼上（yank）。

安裝外掛後按鍵立即生效。**外掛程式 › 開啟或關閉 Emacs 按鍵** 可以切換，點狀態列裡的 **Emacs** 也可以；設定標記時狀態列還會顯示 **標記**，按下 C-x 等待第二個鍵時顯示 **C-x-**。外掛只接管下列按鍵，打字仍由編輯器處理。在 Markdown 文件裡，「一行」指一個段落、一個標題、一個清單項目，或程式碼區塊裡的一行。

- **移動**：**C-f C-b C-n C-p**、**C-a C-e**、**M-f M-b**、**M-< M->**，**M-{ M-}** 以段落移動，**C-v M-v** 一次移動二十行。
- **標記與選取範圍**：**C-SPC** 設定標記，之後的移動（包括方向鍵）都會擴大選取範圍；**C-g** 取消標記；**C-x h** 選取整份文件。
- **kill ring**：**C-k** 剪到行尾（在行尾時與下一行合併），**C-w** 剪下選取範圍，**M-w** 複製選取範圍，**M-d** 和 **M-DEL** 向前或向後剪掉一個字詞。連續剪下會合成一筆。**C-y** 貼上最近剪下的內容，緊接著按 **M-y** 換成更早的。**C-d** 刪除一個字元，不進 kill ring。
- **大小寫**：**M-u**、**M-l** 和 **M-c** 把下一個字詞改成大寫、小寫或首字大寫。
- **復原與儲存**：**C-/**、**C-_** 或 **C-x u** 復原；**C-x C-s** 儲存。

在 Mac 上，Textus 的快捷鍵使用 ⌘，所以所有 Ctrl 鍵都歸 Emacs。在 Windows 和 Linux 上，Ctrl 鍵屬於 Textus 和系統（複製、貼上、剪下、全選、粗體、尋找），所以只有 M- 鍵、C-SPC 和 C-g 歸 Emacs；在外掛設定中開啟 **接管 Textus 用到的 Ctrl 鍵** 後，Ctrl 鍵也歸 Emacs。

支援桌面版與 iPhone。外掛只要求一項權限：編輯器按鍵，用來在編輯器裡接管這些鍵。

## 更新紀錄

- **0.1.5** - 說明和空狀態文字更簡短。
- **0.1.4** - 介紹頁重寫：一句話說明它做什麼，再講它能做的事，並列出每個版本的更新。
- **0.1.3** - 標明可執行的平台：桌面版與 iPhone。
- **0.1.2** - C-x 不再卡住；C-d 和 C-y 不再更動剪貼簿與選取範圍。
- **0.1.0-0.1.1** - 最初的版本：移動、標記與選取範圍、含 C-y 和 M-y 的 kill ring、M-u M-l M-c、復原與 C-x 組合鍵；商店頁面與圖示。
