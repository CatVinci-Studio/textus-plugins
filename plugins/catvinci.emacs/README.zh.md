# Emacs

让你在编辑器里用 Emacs 的按键移动、设标记、剪切（kill）和粘贴（yank）。

装好插件后按键立即生效。**插件 › 打开或关闭 Emacs 按键** 可以开关它们，点状态栏里的 **Emacs** 也可以；设了标记时状态栏还会显示 **标记**，按下 C-x 等第二个键时显示 **C-x-**。插件只接管下面这些键，打字仍由编辑器处理。在 Markdown 文档里，“一行”指一个段落、一个标题、一个列表项，或代码块里的一行。

- **移动**：**C-f C-b C-n C-p**、**C-a C-e**、**M-f M-b**、**M-< M->**，**M-{ M-}** 按段落移动，**C-v M-v** 一次移动二十行。
- **标记和选区**：**C-SPC** 设标记，之后的移动（包括方向键）都会扩大选区；**C-g** 取消标记；**C-x h** 选中整篇文档。
- **kill ring**：**C-k** 剪到行尾（在行尾时与下一行合并），**C-w** 剪切选区，**M-w** 复制选区，**M-d** 和 **M-DEL** 向前或向后剪掉一个词。连续剪切会合成一条。**C-y** 粘贴最近剪下的内容，紧接着按 **M-y** 换成更早的。**C-d** 删除一个字符，不进 kill ring。
- **大小写**：**M-u**、**M-l** 和 **M-c** 把下一个词改成大写、小写或首字母大写。
- **撤销和保存**：**C-/**、**C-_** 或 **C-x u** 撤销；**C-x C-s** 保存。

在 Mac 上，Textus 的快捷键用 ⌘，所以所有 Ctrl 键都归 Emacs。在 Windows 和 Linux 上，Ctrl 键属于 Textus 和系统（复制、粘贴、剪切、全选、加粗、查找），所以只有 M- 键、C-SPC 和 C-g 归 Emacs；在插件设置里打开 **接管 Textus 用到的 Ctrl 键** 后，Ctrl 键也归 Emacs。

支持桌面版和 iPhone。插件只申请一项权限：编辑器按键，用来在编辑器里接管这些键。

## 更新日志

- **0.1.5** - 说明和空状态文字更简短。

- **0.1.2** - C-x 不再卡住；C-d 和 C-y 不再改动剪贴板和选区。
- **0.1.0-0.1.1** - 最早的版本：移动、标记和选区、带 C-y 和 M-y 的 kill ring、M-u M-l M-c、撤销和 C-x 组合键；商店页面和图标。
