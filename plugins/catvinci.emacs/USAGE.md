# Emacs Keys

Emacs's keys in the editor.

- **Plugins › Turn Emacs Keys On or Off** switches them.
- Moving: **C-f C-b C-n C-p**, **C-a C-e**, **M-f M-b**, **M-< M->**.
- **C-SPC** sets the mark; **C-w** cuts the region and **C-k** the rest of the line into the kill ring; **C-y** yanks, **M-y** cycles; **C-/** undoes.
- Ctrl keys Textus already uses stay Textus's, unless you let Emacs take them in the plugin's settings.
