# Emacs

As teclas do Emacs no editor.

- **Plugins › Ligar ou desligar as teclas do Emacs** alterna entre elas.
- Mover: **C-f C-b C-n C-p**, **C-a C-e**, **M-f M-b**, **M-< M->**.
- **C-SPC** define a marca; **C-w** recorta a região e **C-k** o resto da linha, ambos para o kill ring; **C-y** cola, **M-y** percorre o anel e **C-/** desfaz.
- As teclas Ctrl que o Textus já usa continuam sendo do Textus, a menos que você deixe o Emacs assumi-las nos ajustes do plugin.
