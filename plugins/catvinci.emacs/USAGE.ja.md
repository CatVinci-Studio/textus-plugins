# Emacs

エディタで Emacs のキーを使えます。

- **プラグイン › Emacs キーのオン・オフ** で切り替えます。
- 移動：**C-f C-b C-n C-p**、**C-a C-e**、**M-f M-b**、**M-< M->**。
- **C-SPC** でマークを設定。**C-w** で選択範囲を、**C-k** で行の残りを切り取ってキルリングに入れます。**C-y** でヤンク、**M-y** で切り替え、**C-/** で元に戻します。
- **M-u**、**M-l**、**M-c** で、次の単語を大文字、小文字、先頭だけ大文字にします。
- Textus がすでに使っている Ctrl キーは Textus のままです。Emacs に使わせるには、プラグインの設定で許可してください。
