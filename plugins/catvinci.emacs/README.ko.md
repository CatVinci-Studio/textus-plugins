# Emacs

편집기에서 Emacs 키로 이동하고, 마크를 두고, kill과 yank를 할 수 있습니다.

플러그인을 설치하면 바로 키가 작동합니다. **플러그인 › Emacs 키 켜기/끄기**나 상태 표시줄의 **Emacs**를 클릭하면 켜고 끕니다. 상태 표시줄에는 마크가 있는 동안 **마크**, C-x가 다음 키를 기다리는 동안 **C-x-**가 보입니다. 아래 키만 가져가고 글자 입력은 편집기가 그대로 처리합니다. Markdown 문서에서 "줄"은 문단, 제목, 목록 항목, 또는 코드 블록의 한 줄입니다.

- **이동**: **C-f C-b C-n C-p**, **C-a C-e**, **M-f M-b**, **M-< M->**, 문단 단위 **M-{ M-}**, 스무 줄 단위 **C-v M-v**.
- **마크와 영역**: **C-SPC**로 마크를 두면 이후 이동(화살표 키 포함)이 영역을 넓힙니다. **C-g**로 해제하고 **C-x h**로 문서 전체를 선택합니다.
- **kill ring**: **C-k**는 줄 끝까지 kill하고(줄 끝에서는 다음 줄과 합칩니다), **C-w**는 영역을 kill, **M-w**는 영역을 복사, **M-d**와 **M-DEL**은 앞뒤 단어를 kill합니다. 연달아 kill하면 하나로 합쳐집니다. **C-y**는 가장 최근 kill을 yank하고, 바로 이어서 **M-y**를 누르면 더 오래된 것으로 바꿉니다. **C-d**는 한 글자를 지울 뿐 kill ring에 넣지 않습니다.
- **대소문자**: **M-u**, **M-l**, **M-c**는 다음 단어를 대문자, 소문자, 첫 글자만 대문자로 바꿉니다.
- **실행 취소와 저장**: **C-/**, **C-_**, **C-x u**로 실행 취소, **C-x C-s**로 저장합니다.

Mac에서는 Textus 단축키가 ⌘에 있으므로 모든 Ctrl 키가 Emacs 것입니다. Windows와 Linux에서는 Ctrl 키가 Textus와 시스템 것(복사, 붙여넣기, 잘라내기, 모두 선택, 굵게, 찾기)이므로, 플러그인 설정에서 **Textus가 쓰는 Ctrl 키도 가져오기**를 켜기 전까지는 M- 키와 C-SPC, C-g만 Emacs 것입니다.

데스크톱과 iPhone에서 쓸 수 있습니다. 요청하는 권한은 편집기 키 하나뿐이며, 편집기에서 이 키들을 받는 데 씁니다.
