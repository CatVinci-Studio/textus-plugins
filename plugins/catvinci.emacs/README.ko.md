# Emacs

편집기에서 Emacs 키를 쓸 수 있습니다.

- **플러그인 › Emacs 키 켜기/끄기**로 전환합니다.
- 이동: **C-f C-b C-n C-p**, **C-a C-e**, **M-f M-b**, **M-< M->**.
- **C-SPC**로 마크를 지정합니다. **C-w**는 선택 영역을, **C-k**는 줄의 나머지를 잘라 킬 링에 넣습니다. **C-y**로 붙여넣고, **M-y**로 바꿔 가며 붙이고, **C-/**로 실행을 취소합니다.
- **M-u**, **M-l**, **M-c**는 다음 단어를 대문자로, 소문자로, 첫 글자만 대문자로 바꿉니다.
- Textus가 이미 쓰는 Ctrl 키는 Textus가 계속 씁니다. Emacs가 가져가게 하려면 플러그인 설정에서 허용하세요.
