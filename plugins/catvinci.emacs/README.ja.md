# Emacs

エディタで、Emacs のキーを使って移動・マーク・kill・yank ができます。

プラグインを入れるとすぐキーが使えます。**プラグイン › Emacs キーのオン・オフ** か、ステータスバーの **Emacs** をクリックすると切り替わります。ステータスバーには、マークがある間は **マーク**、C-x が次のキーを待つ間は **C-x-** と出ます。使うのは下のキーだけで、文字入力はエディタのままです。Markdown 文書での「行」は、段落・見出し・リスト項目、またはコードブロックの一行です。

- **移動**：**C-f C-b C-n C-p**、**C-a C-e**、**M-f M-b**、**M-< M->**、段落単位の **M-{ M-}**、20 行単位の **C-v M-v**。
- **マークとリージョン**：**C-SPC** でマークを置くと、その後の移動（矢印キーも）でリージョンが広がります。**C-g** で解除、**C-x h** で文書全体を選択します。
- **kill ring**：**C-k** で行末まで kill（行末では次の行とつなげます）、**C-w** でリージョンを kill、**M-w** でコピー、**M-d** と **M-DEL** で前後の単語を kill します。続けて kill すると一つにまとまります。**C-y** で最新の kill を yank し、直後の **M-y** で古いものに入れ替えます。**C-d** は一文字消すだけで kill ring には入りません。
- **大文字・小文字**：**M-u**、**M-l**、**M-c** で次の単語を大文字、小文字、先頭だけ大文字にします。
- **取り消しと保存**：**C-/**、**C-_**、**C-x u** で取り消し、**C-x C-s** で保存。

Mac では Textus のショートカットが ⌘ なので、Ctrl キーはすべて Emacs のものです。Windows と Linux では Ctrl キーは Textus とシステムのもの（コピー、貼り付け、切り取り、すべて選択、太字、検索）なので、プラグインの設定で **Textus が使う Ctrl キーも使う** をオンにするまでは、M- キーと C-SPC、C-g だけが Emacs のものです。

デスクトップと iPhone で使えます。求める権限は「エディタのキー」の一つだけで、エディタでこれらのキーを受け取るためのものです。
