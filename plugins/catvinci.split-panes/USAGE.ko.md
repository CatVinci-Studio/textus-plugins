# 화면 분할

문서 두 개를 동시에 엽니다.

- **Ctrl+Alt+S**(Mac에서는 **⌘⌥S**)를 누르면 나란히 분할되고, 한 번 더 누르면 문서 하나로 돌아갑니다.
- **플러그인 › 오른쪽으로 분할**이나 **아래로 분할**을 선택하면 다음 문서가 이 문서 옆이나 아래에 놓입니다.
- 둘 사이의 선을 끌어 공간을 나누고, 작업할 쪽을 클릭합니다.
- **좌우 ⇄ 상하**는 분할 방향을 바꾸고, **양쪽 바꾸기**는 자리를 맞바꾸며, **양쪽 같은 크기로**는 선을 가운데로 돌려놓습니다.
- **플러그인 › 분할 닫기**로 하나로 돌아갑니다.
