# Painéis divididos

Dois documentos ao mesmo tempo.

- **Ctrl+Alt+S** (**⌘⌥S** no Mac), ou **Plugins › Dividir à direita**, coloca o próximo documento ao lado deste; **Dividir para baixo** o coloca embaixo.
- Arraste a linha entre eles para repartir o espaço; clique num deles para trabalhar ali.
- **Plugins › Fechar a divisão** volta a um só.
