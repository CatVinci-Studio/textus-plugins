# Painéis divididos

Dois documentos ao mesmo tempo.

- **Ctrl+Alt+S** (**⌘⌥S** no Mac) divide lado a lado; de novo, volta a um só documento.
- **Plugins › Dividir à direita** ou **Dividir para baixo** coloca o próximo documento ao lado deste ou embaixo.
- Arraste a linha entre eles para repartir o espaço; clique num deles para trabalhar ali.
- **Lado a lado ⇄ um acima do outro** gira a divisão, **Trocar os lados** troca os dois de lugar e **Igualar os dois lados** põe a linha de volta no meio.
- **Plugins › Fechar a divisão** volta a um só.
