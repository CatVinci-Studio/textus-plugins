# Разделение окна

Два документа одновременно.

- **Ctrl+Alt+S** (**⌘⌥S** на Mac) или **Плагины › Разделить вправо** помещает следующий документ рядом с этим; **Разделить вниз** — под ним.
- Перетащите линию между ними, чтобы распределить место; нажмите в одной из частей, чтобы работать в ней.
- **Плагины › Закрыть разделение** возвращает один документ.
