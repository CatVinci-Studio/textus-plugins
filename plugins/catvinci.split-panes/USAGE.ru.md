# Разделение окна

Два документа одновременно.

- **Ctrl+Alt+S** (**⌘⌥S** на Mac) разделяет окно на две части рядом; повторное нажатие возвращает один документ.
- **Плагины › Разделить вправо** или **Разделить вниз** помещает следующий документ рядом с этим или под ним.
- Перетащите линию между ними, чтобы распределить место; нажмите в одной из частей, чтобы работать в ней.
- **Рядом ⇄ друг над другом** поворачивает разделение, **Поменять стороны местами** меняет части местами, **Сделать стороны равными** возвращает линию в середину.
- **Плагины › Закрыть разделение** возвращает один документ.
