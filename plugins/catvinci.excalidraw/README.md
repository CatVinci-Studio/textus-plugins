# Excalidraw

Draw hand-drawn style diagrams with [Excalidraw](https://excalidraw.com) in a Textus tab.

Open a `.excalidraw` file from the sidebar, or choose **New Drawing** in the Plugins menu, and the drawing fills a tab with Excalidraw's own tools: shapes, arrows, text, pictures and the library. What you draw is saved to the file as you go.

- Drawings made with Obsidian's Excalidraw plugin (`.excalidraw.md`) open and save too. The note keeps its front matter and other sections, its drawing stays compressed if it was, and its list of the drawing's words is written again so a search still finds them. Pictures the note links are shown.
- The page follows Textus's language and its light or dark mode.
- If the file is changed somewhere else while it is open, the tab shows the new drawing; a save never writes over it.
- Excalidraw's handwriting fonts come with the plugin, except its Chinese one, so Chinese and Japanese text uses your system's font.

The plugin asks to read and write files: it reads the drawing and the pictures it links, and writes only the drawing you edit. It works on the desktop and on iPhone and iPad.
