# Excalidraw

Рисуйте схемы в стиле «от руки» с [Excalidraw](https://excalidraw.com) во вкладке Textus.

Откройте файл `.excalidraw` на боковой панели или выберите **Новый рисунок** в меню «Плагины» — рисунок займёт вкладку вместе с инструментами самого Excalidraw: фигурами, стрелками, текстом, картинками и библиотекой. Нарисованное сохраняется в файл по ходу работы.

- Рисунки из плагина Excalidraw для Obsidian (`.excalidraw.md`) тоже открываются и сохраняются. Заметка сохраняет front matter и другие разделы, рисунок остаётся сжатым, если был сжат, а список слов рисунка записывается заново, чтобы поиск по-прежнему их находил. Картинки, на которые ссылается заметка, показываются.
- Страница следует языку Textus и его светлому или тёмному режиму.
- Если файл изменили где-то ещё, пока он открыт, вкладка покажет новый рисунок; сохранение никогда его не перезапишет.
- Рукописные шрифты Excalidraw входят в плагин, кроме китайского, поэтому китайский и японский текст показывается системным шрифтом.

Плагин просит чтение и запись файлов: он читает рисунок и картинки, на которые тот ссылается, а записывает только рисунок, который вы правите.
