# Excalidraw

在 Textus 的分頁裡用 [Excalidraw](https://excalidraw.com) 畫手繪風格的圖。

從側邊欄開啟 `.excalidraw` 檔案，或在「外掛程式」選單裡選 **新增繪圖**，繪圖就會佔滿一個分頁，並附上 Excalidraw 自己的工具：圖形、箭頭、文字、圖片和素材庫。你畫的內容會隨時儲存到檔案裡。

- 用 Obsidian 的 Excalidraw 外掛畫的繪圖（`.excalidraw.md`）也能開啟和儲存。筆記會保留它的 front matter 和其他段落，原本壓縮過的繪圖仍然保持壓縮，繪圖裡的文字清單也會重新寫入，搜尋時照樣找得到。筆記連結的圖片也會顯示出來。
- 頁面會跟隨 Textus 的語言和淺色或深色模式。
- 檔案開著的時候如果在別處被修改了，分頁會顯示新的繪圖；儲存時絕不會蓋掉它。
- Excalidraw 的手寫字型隨外掛一起安裝，但不包括中文字型，所以中文和日文會使用系統字型。

外掛要求讀寫檔案的權限：讀取繪圖和它連結的圖片，只寫入你編輯的那個繪圖。
