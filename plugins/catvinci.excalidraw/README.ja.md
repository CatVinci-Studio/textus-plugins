# Excalidraw

[Excalidraw](https://excalidraw.com) を使い、Textus のタブで手描き風の図を描けます。

サイドバーから `.excalidraw` ファイルを開くか、「プラグイン」メニューで **新しい図** を選ぶと、図がタブいっぱいに開き、Excalidraw 自身の道具が使えます：図形、矢印、テキスト、画像、ライブラリ。描いたものはその都度ファイルに保存されます。

- Obsidian の Excalidraw プラグインで描いた図（`.excalidraw.md`）も開いて保存できます。ノートの front matter とほかの節はそのまま残り、図が圧縮されていれば圧縮されたまま保存されます。図の中の言葉の一覧も書き直すので、検索で見つかり続けます。ノートがリンクしている画像も表示されます。
- 画面は Textus の言語と、ライトモード・ダークモードに従います。
- 開いているあいだにファイルが別の場所で変更されると、タブに新しい図が表示されます。保存でそれを上書きすることはありません。
- Excalidraw の手書きフォントはプラグインに含まれています。ただし中国語のフォントは含まれないので、中国語と日本語の文字はシステムのフォントで表示されます。

このプラグインはファイルの読み書きを求めます。図とそれがリンクしている画像を読み、書くのは編集している図だけです。
