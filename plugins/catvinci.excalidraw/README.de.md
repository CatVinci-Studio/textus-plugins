# Excalidraw

Zeichnen Sie Diagramme im Handzeichnungsstil mit [Excalidraw](https://excalidraw.com) in einem Tab von Textus.

Öffnen Sie eine `.excalidraw`-Datei aus der Seitenleiste oder wählen Sie **Neue Zeichnung** im Plugins-Menü, und die Zeichnung füllt einen Tab mit den Werkzeugen von Excalidraw: Formen, Pfeile, Text, Bilder und die Bibliothek. Was Sie zeichnen, wird laufend in der Datei gespeichert.

- Zeichnungen aus dem Excalidraw-Plugin von Obsidian (`.excalidraw.md`) öffnen und speichern sich ebenso. Die Notiz behält ihr Front Matter und ihre anderen Abschnitte, ihre Zeichnung bleibt komprimiert, wenn sie es war, und ihre Liste der Wörter in der Zeichnung wird neu geschrieben, damit eine Suche sie weiter findet. Bilder, auf die die Notiz verlinkt, werden angezeigt.
- Die Seite folgt der Sprache von Textus und seinem hellen oder dunklen Modus.
- Wird die Datei anderswo geändert, während sie offen ist, zeigt der Tab die neue Zeichnung; ein Speichern überschreibt sie nie.
- Die Handschrift-Schriften von Excalidraw kommen mit dem Plugin, außer der chinesischen, daher nutzt chinesischer und japanischer Text die Schrift Ihres Systems.

Das Plugin fragt nach Lese- und Schreibzugriff auf Dateien: Es liest die Zeichnung und die Bilder, auf die sie verlinkt, und schreibt nur die Zeichnung, die Sie bearbeiten.
