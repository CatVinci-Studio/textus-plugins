# SSH フォルダー

自分の ssh でサーバー上のフォルダーを開き、このコンピューターのフォルダーと同じように書けます。文書はタブに、ファイルはサイドバーに並びます。

## できること

- **プラグイン › リモートフォルダーを開く…** で `~/.ssh/config` にあるサーバーが並び（`me@server` のように入力することもできます）、次に開くフォルダーを、そのサーバーのホームから選びます。
- フォルダーはサイドバーに開きます。文書を開く、保存する、名前を変える、移動する、検索するのは、ほかのフォルダーと同じです。新しい文書やフォルダーはサーバー上に作られます。
- 接続には自分の `ssh` を、その設定、鍵、エージェント、known hosts ごと使います。求めるのはファイル転送（SFTP）だけで、シェルやコマンドは使いません。
- 接続が切れても、次にファイルを読むか保存するときにつなぎ直します。

## できないこと

- サインインは鍵かエージェントだけです。パスワードを求めるサーバーには接続しません。先にそのサーバー用の鍵を追加してください。
- ssh がまだ知らないサーバーには接続せず、代わりに受け入れることもしません。一度ターミナルで `ssh` を使って接続し、そこで鍵を受け入れてください。
- サーバー上の文書にはまだ画像を貼り付けられません。また、削除したファイルは元に戻せません。サーバーにはゴミ箱がないためです。

## 権限

**ssh** を求めます。プラグインがサーバーに接続する前に、Textus がサーバーごとに一度確認します。
