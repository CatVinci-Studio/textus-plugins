# Папки SSH

Открывайте папку на сервере через ваш собственный ssh и пишите там как в папке на этом компьютере: документы во вкладках, файлы на боковой панели.

## Что он делает

- **Плагины › Открыть удалённую папку…** показывает серверы из вашего `~/.ssh/config` (или принимает введённый вами, например `me@server`), а затем папку, которую нужно открыть, начиная с вашей домашней папки на сервере.
- Папка открывается на боковой панели. Документы открываются, сохраняются, переименовываются, перемещаются и ищутся как в любой папке; новый документ или папка создаются на сервере.
- Соединение устанавливает ваш собственный `ssh`, с вашей конфигурацией, ключами, агентом и известными хостами. Запрашивается только передача файлов (SFTP): никакой оболочки и никаких команд.
- Оборвавшееся соединение восстанавливается, когда в следующий раз читается или сохраняется файл.

## Ограничения

- Вход только по ключу или через агент. Сервер, который просит пароль, отклоняется; сначала добавьте для него ключ.
- Сервер, который ssh ещё не знает, отклоняется и никогда не принимается за вас: подключитесь к нему один раз через `ssh` в терминале и примите там его ключ.
- Вставлять картинки в документ на сервере пока нельзя, а удалённый файл пропадает навсегда: на сервере нет корзины.

## Разрешения

Плагин просит **ssh**: Textus один раз спрашивает вас о каждом сервере, прежде чем плагин сможет к нему подключиться.
