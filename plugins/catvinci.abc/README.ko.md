# 악보(ABC)

ABC 표기법으로 악보를 그립니다.

- `abc` 코드 블록을 쓰면 그 아래에 그려집니다. 블록을 클릭하면 소스가 다시 보이고 고칠 수 있습니다.
- 언어 이름 뒤에 `height=400`을 쓰면 높이를 정할 수 있습니다.
- HTML, PDF, Word로 내보내면 그림이 이미지로 들어갑니다.

## 예시

```abc
X:1
T:Scale
M:4/4
L:1/4
K:C
C D E F | G A B c |
```
