# 악보(ABC)

코드 블록에 쓴 ABC 표기법을 악보로 그립니다.

언어가 `abc`인 코드 블록을 쓰면 바로 아래에 악보가 그려집니다. 블록을 클릭하면 소스가 다시 보여 고칠 수 있습니다.

- 마디가 열 너비에 맞춰 줄바꿈되어 좁은 패널에서도 음표가 잘 보입니다.
- 음표는 테마의 글자 색으로 그려지고, 라이트와 다크를 바꾸면 다시 그려집니다.
- HTML, PDF, Word로 내보내면 악보가 그림으로 들어갑니다.

데스크톱과 iPhone에서 쓸 수 있고 Textus 1.3.2 이상이 필요합니다. 요청하는 권한은 Textus AI 도구 하나뿐이며, Textus AI가 `abc` 블록을 문서에 쓰기 전에 검사하는 데 씁니다.

## 예시

```abc
X:1
T:Scale
M:4/4
L:1/4
K:C
C D E F | G A B c |
```

## 변경 내역

- **0.3.2** - 악보 전체를 줄이지 않고 마디를 열 너비에 맞춰 줄바꿈합니다. 음표를 클릭해도 빨갛게 변하지 않습니다. `check_abc`가 전체 선법 이름, 모든 음표 길이, `+:` 줄, `` ` ``와 `$`를 받아들입니다. `height=`는 없어졌습니다.
- **0.3.1** - 소개 페이지를 새로 썼습니다. 무엇을 하는지 한 문장으로, 할 수 있는 일과 버전별 변경 내역을 담았습니다.
- **0.3.0** - Textus AI가 `abc` 블록을 쓰기 전에 검사할 수 있습니다(`check_abc`).
- **0.2.0** - 음표가 테마의 글자 색을 따릅니다. Textus 1.3.2 필요.
- **0.1.3** - Textus에서 이름이 바뀐 문서 색을 씁니다.
- **0.1.2** - 내보낸 그림이 악보의 너비와 높이를 유지합니다.
- **0.1.0-0.1.1** - 첫 버전: 소스 아래에 그려지는 `abc` 블록, `height=`, 내보내기 시 그림. 스토어 페이지와 아이콘.
