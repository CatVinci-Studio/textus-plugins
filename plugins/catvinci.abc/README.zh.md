# 乐谱（ABC）

用 ABC 记谱法写乐谱。

- 写一个 `abc` 代码块，下方就会画出来；点进代码块可以再看到并修改源码。
- 在语言后面写 `height=400` 可以设置图的高度。
- 导出 HTML、PDF、Word 时，图会作为图片放进去。

## 示例

```abc
X:1
T:Scale
M:4/4
L:1/4
K:C
C D E F | G A B c |
```

装上这个插件后，Textus AI 在对话中可以使用：

- `check_abc`：在把 ```abc 块写进文档之前检查它的源码（ABC 乐谱记法：以 K: 结尾的字段头部，然后是音符），不实际绘制。返回 ok，或需要先修正的问题。传入时不带代码围栏。
