# 楽譜（ABC）

コードブロックに書いた ABC 記譜法を楽譜として描きます。

言語を `abc` にしたコードブロックを書くと、そのすぐ下に楽譜が描かれます。ブロックをクリックするとソースがもう一度表示され、編集できます。

- 最初の行の `abc` の後に `height=400` と書くと、図の高さをピクセルで指定できます。
- 音符はテーマの文字色で描かれ、ライトとダークを切り替えると描き直されます。
- HTML・PDF・Word に書き出すと、楽譜は画像として入ります。

デスクトップと iPhone で使え、Textus 1.3.2 以降が必要です。求める権限は「Textus AI ツール」の一つだけで、Textus AI が `abc` ブロックを文書に書く前に検査するためのものです。

## 例

```abc
X:1
T:Scale
M:4/4
L:1/4
K:C
C D E F | G A B c |
```

## 更新履歴

- **0.3.0** - Textus AI が `abc` ブロックを書く前に検査できるように（`check_abc`）。
- **0.2.0** - 音符がテーマの文字色に合わせて描かれるように。Textus 1.3.2 が必要。
- **0.1.3** - Textus で名前が変わった文書の色を使うように。
- **0.1.2** - 書き出した画像が楽譜の幅と高さを保つように。
- **0.1.0-0.1.1** - 最初の版：`abc` ブロックをソースの下に描画、`height=`、書き出しでは画像に。ストアページとアイコン。
