# 樂譜（ABC）

用 ABC 記譜法寫樂譜。

- 寫一個 `abc` 程式碼區塊，下方就會畫出來；點進區塊可以再看到並修改原始碼。
- 在語言後面寫 `height=400` 可以設定圖的高度。
- 匯出 HTML、PDF、Word 時，圖會以圖片放進去。

## 範例

```abc
X:1
T:Scale
M:4/4
L:1/4
K:C
C D E F | G A B c |
```
