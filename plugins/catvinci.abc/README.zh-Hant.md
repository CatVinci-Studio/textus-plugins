# 樂譜（ABC）

把程式碼區塊裡的 ABC 記譜法畫成樂譜。

寫一個語言為 `abc` 的程式碼區塊，樂譜會直接畫在它下方；點進區塊就能再看到原始碼並修改。

- 在開頭那一行的 `abc` 後面寫 `height=400`，可以設定圖的高度（像素）。
- 音符採用佈景主題的文字顏色，切換淺色與深色時會重新繪製。
- 匯出 HTML、PDF、Word 時，樂譜會以圖片放入。

支援桌面版與 iPhone，需要 Textus 1.3.2 以上版本。外掛只要求一項權限：Textus AI 工具，讓 Textus AI 在把 `abc` 區塊寫進文件前先檢查。

## 範例

```abc
X:1
T:Scale
M:4/4
L:1/4
K:C
C D E F | G A B c |
```

## 更新紀錄

- **0.3.0** - Textus AI 可以在寫入 `abc` 區塊前先檢查它（`check_abc`）。
- **0.2.0** - 音符跟隨佈景主題的文字顏色；需要 Textus 1.3.2。
- **0.1.3** - 改用 Textus 重新命名後的文件顏色。
- **0.1.2** - 匯出的圖片保留樂譜的寬度與高度。
- **0.1.0-0.1.1** - 最初的版本：`abc` 區塊畫在原始碼下方、支援 `height=`、匯出時轉為圖片；商店頁面與圖示。
