# Noten (ABC)

Noten aus ABC-Notation.

- Schreiben Sie einen Codeblock in `abc`: Er wird darunter gezeichnet, und seine Quelle erscheint wieder, wenn Sie hineinklicken.
- `height=400` nach der Sprache legt die Höhe der Zeichnung fest.
- Beim Export nach HTML, PDF oder Word kommt die Zeichnung als Bild mit.

## Beispiel

```abc
X:1
T:Scale
M:4/4
L:1/4
K:C
C D E F | G A B c |
```
