# Ноты (ABC)

Ноты по записи ABC.

- Напишите блок кода на `abc`: под ним появится рисунок, а исходник снова видно, если щёлкнуть в блок.
- `height=400` после имени языка задаёт высоту рисунка.
- При экспорте в HTML, PDF или Word рисунок попадает картинкой.

## Пример

```abc
X:1
T:Scale
M:4/4
L:1/4
K:C
C D E F | G A B c |
```
