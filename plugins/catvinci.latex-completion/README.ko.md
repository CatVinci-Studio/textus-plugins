# LaTeX 자동 완성

수식을 쓰는 동안 LaTeX 명령을 제안합니다.

- 수식 안(`$ … $` 사이나 수식 블록)에서 백슬래시와 명령의 앞부분을 입력합니다. 예: `\fr`, `\alp`. 백슬래시만 입력하면 자주 쓰는 명령이 나옵니다.
- 목록에는 맞는 명령이 각각 그려지는 모양과 함께 나옵니다. `\frac`부터 `\begin{pmatrix}`까지 200개가 넘습니다. 입력한 글자로 시작하는 명령이 먼저, 그 글자를 포함하는 명령이 그다음이며 대소문자는 가리지 않습니다.
- 글자를 순서대로 골라 써도 찾습니다: `\rarr`는 `\rightarrow`, `\lra`는 `\leftrightarrow`입니다.
- **Enter**나 **Tab**을 누르면 고른 명령을 쓰고 커서를 중괄호 안에 둡니다. **Esc**는 목록을 닫습니다. `\left(`, `\left[`, `\left\{`는 짝이 되는 `\right`와 함께 들어갑니다.

데스크톱과 iPhone에서 쓸 수 있고 Textus 1.3.0 이상이 필요합니다. 요청하는 권한은 편집기 읽기 하나뿐이며, 수식에 입력한 내용을 보는 데 씁니다.
