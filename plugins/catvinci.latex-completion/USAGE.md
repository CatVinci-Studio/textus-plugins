# LaTeX Completion

LaTeX commands suggested as you type a formula.

- In a formula - between $ … $ or in a math block - type a backslash and the start of a command: \fr, \alp.
- A list shows the commands that begin so, each with what it draws - over 200 of them, from \frac to \begin{pmatrix}.
- Letters in order find a command too: \rarr is \rightarrow, \lra \leftrightarrow.
- **Enter** or **Tab** writes the one picked, with the caret inside its braces; **Esc** closes the list.
