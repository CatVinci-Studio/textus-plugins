# Complétion LaTeX

Des commandes LaTeX proposées pendant que vous saisissez une formule.

- Dans une formule — entre $ … $ ou dans un bloc mathématique — tapez une barre oblique inverse et le début d’une commande : \fr, \alp.
- Une liste affiche les commandes qui commencent ainsi, chacune avec ce qu’elle dessine ; il y en a plus de 200, de \frac à \begin{pmatrix}.
- Des lettres dans l’ordre trouvent aussi une commande : \rarr donne \rightarrow, \lra \leftrightarrow.
- **Enter** ou **Tab** écrit la commande choisie, avec le curseur entre ses accolades ; **Esc** ferme la liste.
