# Complétion LaTeX

Des commandes LaTeX proposées pendant que vous saisissez une formule.

- Dans une formule — entre $ … $ ou dans un bloc mathématique — tapez une barre oblique inverse et le début d’une commande : \fr, \alp.
- Une liste affiche les commandes qui commencent ainsi, chacune avec ce qu’elle dessine.
- **Entrée** ou **Tab** écrit la commande choisie, avec le curseur entre ses accolades ; **Échap** ferme la liste.
