# Autocompletado de LaTeX

Sugerencias de comandos LaTeX mientras escribes una fórmula.

- Dentro de una fórmula —entre $ … $ o en un bloque matemático— escribe una barra invertida y el comienzo de un comando: \fr, \alp.
- Una lista muestra los comandos que empiezan así, cada uno con lo que dibuja; son más de 200, de \frac a \begin{pmatrix}.
- También encuentras un comando con sus letras en orden: \rarr es \rightarrow y \lra es \leftrightarrow.
- **Enter** o **Tab** escribe el elegido, con el cursor dentro de sus llaves; **Esc** cierra la lista.
