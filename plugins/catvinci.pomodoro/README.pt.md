# Pomodoro

Um temporizador de foco que flutua sobre a janela do Textus ou sobre a área de trabalho: um período de foco, depois uma pausa, com uma notificação ao fim de cada um.

- **Plugins › Mostrar ou ocultar o pomodoro** mostra o temporizador. Arraste-o para onde quiser, ou para fora da janela, até a área de trabalho.
- Clique no temporizador, ou escolha **Plugins › Iniciar ou pausar o temporizador**, para iniciá-lo ou pausá-lo. Um anel se enche conforme o tempo passa, de outra cor durante a pausa.
- Clique com o botão direito no temporizador para **Ir para o próximo período** e **Recomeçar**.
- Quando um período acaba, o seguinte começa sozinho e uma notificação avisa.
- O temporizador continua contando mesmo se você reiniciar o Textus.

**Ajustes**: **Foco (minutos)** e **Pausa (minutos)**, 25 e 5 por padrão, até 180.

Precisa do Textus 1.3.12 ou mais recente. Pede uma única permissão: notificações, para o fim de cada período.

- **0.1.3** - Quick clicks no longer lose one; a new focus or break length shows on a timer not yet started; the clock grows and shrinks with the timer.
- **0.1.2** - A click on the timer starts and pauses it again (it did nothing in 0.1.0 and 0.1.1).
- **0.1.1** - Follows every theme and grows with the interface; needs Textus 1.3.12.
- **0.1.0** - First version: a floating focus timer with breaks, notifications, a right-click menu, and its own focus and break lengths.
