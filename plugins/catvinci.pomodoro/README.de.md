# Pomodoro

Ein Fokus-Timer, der über dem Fenster von Textus oder dem Schreibtisch schwebt: eine Phase der Konzentration, dann eine Pause, mit einer Benachrichtigung am Ende jeder Phase.

- **Plugins › Pomodoro-Timer ein- oder ausblenden** zeigt den Timer. Ziehen Sie ihn, wohin Sie möchten, auch aus dem Fenster auf den Schreibtisch.
- Klicken Sie auf den Timer oder wählen Sie **Plugins › Timer starten oder pausieren**, um ihn zu starten oder anzuhalten. Ein Ring füllt sich mit der Zeit, in einer anderen Farbe während einer Pause.
- Ein Rechtsklick auf den Timer bietet **Zur nächsten Phase** und **Neu beginnen**.
- Endet eine Phase, beginnt die nächste von selbst, und eine Benachrichtigung sagt es.
- Der Timer läuft über einen Neustart von Textus hinweg weiter.

**Einstellungen**: **Fokus (Minuten)** und **Pause (Minuten)**, standardmäßig 25 und 5, bis zu 180.

Es braucht Textus 1.3.12 oder neuer. Es fragt nach einer einzigen Berechtigung: Benachrichtigungen, für das Ende jeder Phase.

## Änderungen

- **0.1.3** - Quick clicks no longer lose one; a new focus or break length shows on a timer not yet started; the clock grows and shrinks with the timer.
- **0.1.2** - A click on the timer starts and pauses it again (it did nothing in 0.1.0 and 0.1.1).
- **0.1.1** - Follows every theme and grows with the interface; needs Textus 1.3.12.
- **0.1.0** - First version: a floating focus timer with breaks, notifications, a right-click menu, and its own focus and break lengths.
