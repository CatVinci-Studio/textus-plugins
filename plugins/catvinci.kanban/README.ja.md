# カンバン

リストに並べたカードのボードを、ふつうの Markdown ファイルとして保存します。

- **プラグイン › 新しいカンバンボード…** で作ります。ファイル名は _名前_.kanban.md です。
- 各リストはファイルの中の見出し、各カードはその下のタスクなので、どこで開いてもボードを読めます。
- リストの下にカードを追加します。カードはリスト間で、リストは並べ替えのためにドラッグできます。チェックしたカードは完了です。
- カードに [[リンク]] を書くと、クリックでそのノートが開きます。
- **Markdown として編集** でファイルをテキストとして開けます。変更はボードに反映されます。

```markdown
## やること

- [ ] 構成を書く

## 完了

- [x] タイトルを決める
```

## Textus AI のツール

このプラグインを入れると、Textus AI が会話の中で使えます：

- `list_boards`：開いているフォルダにあるカンバンボード（name.kanban.md ファイル）を、それぞれのリストと各リストのカード数とともに一覧にします。
- `read_board`：カンバンボードを読みます。リストを順に、各カードの本文と完了かどうかとともに返します。 普通の文書に書かれたタスクは list_tasks です。
- `add_card`：カンバンボードのリストの末尾にカードを追加します。 ボード（name.kanban.md）専用です。文書の ToDo は add_task です。
- `move_card`：カンバンボードのカードを別のリストへ、または同じリストの別の位置へ移します。
