# 칸반

목록에 담긴 카드로 이루어진 보드를 일반 Markdown 파일로 보관합니다.

- **플러그인 › 새 칸반 보드…**로 만들고, 파일 이름은 _이름_.kanban.md가 됩니다.
- 각 목록은 파일 속의 제목이고 각 카드는 그 아래의 할 일이라서, 어디에서 열어도 보드를 읽을 수 있습니다.
- 목록 맨 아래에 카드를 추가합니다. 카드는 목록 사이로, 목록은 순서를 바꾸도록 끌 수 있습니다. 체크한 카드는 완료된 것입니다.
- 카드에 [[링크]]를 쓰고 클릭하면 그 노트가 열립니다.
- **Markdown으로 편집**을 누르면 파일을 텍스트로 열고, 고친 내용은 보드에 바로 반영됩니다.

```markdown
## 할 일

- [ ] 개요 쓰기

## 완료

- [x] 제목 정하기
```

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `list_boards`: 열린 폴더에 있는 칸반 보드(name.kanban.md 파일)를 각 보드의 목록과 목록마다의 카드 수와 함께 나열합니다.
- `read_board`: 칸반 보드를 읽습니다. 목록을 순서대로, 각 카드의 내용과 완료 여부와 함께 돌려줍니다.
- `add_card`: 칸반 보드의 목록 끝에 카드를 추가합니다.
- `move_card`: 칸반 보드의 카드를 다른 목록으로, 또는 같은 목록의 다른 위치로 옮깁니다.
