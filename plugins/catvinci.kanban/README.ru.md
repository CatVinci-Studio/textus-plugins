# Канбан

Доски из карточек в списках, хранящиеся в обычном файле Markdown.

- **Плагины › Новая канбан-доска…** создаёт доску с именем _имя_.kanban.md.
- Каждый список — заголовок в файле, каждая карточка — задача под ним, поэтому доску можно прочитать где угодно.
- Добавьте карточку внизу списка; перетаскивайте карточки между списками, а списки — чтобы изменить порядок. Отмеченная карточка выполнена.
- Напишите в карточке [[ссылку]] и нажмите на неё, чтобы открыть эту заметку.
- Перетащите список за заголовок, чтобы переместить его.
