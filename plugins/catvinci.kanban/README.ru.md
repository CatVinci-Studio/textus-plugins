# Канбан

Доски из карточек в списках, хранящиеся в обычном файле Markdown.

- **Плагины › Новая канбан-доска…** создаёт доску с именем _имя_.kanban.md.
- Каждый список — заголовок в файле, каждая карточка — задача под ним, поэтому доску можно прочитать где угодно.
- Добавьте карточку внизу списка; перетаскивайте карточки между списками, а списки — чтобы изменить порядок. Отмеченная карточка выполнена.
- Напишите в карточке [[ссылку]] и нажмите на неё, чтобы открыть эту заметку.
- **Редактировать как Markdown** открывает файл как текст; доска подхватывает изменения.

```markdown
## Сделать

- [ ] Написать план

## Готово

- [x] Выбрать название
```

## Инструменты для Textus AI

Когда плагин установлен, Textus AI может пользоваться ими в разговоре:

- `list_boards`: Перечисляет канбан-доски (файлы name.kanban.md) в открытой папке, каждую с её списками и числом карточек в них.
- `read_board`: Читает канбан-доску: её списки по порядку, в каждом текст карточек и отметку, выполнены ли они. Задачи в обычных документах — list_tasks.
- `add_card`: Добавляет карточку в конец списка на канбан-доске. Только для доски (name.kanban.md); задача в документе — add_task.
- `move_card`: Перемещает карточку на канбан-доске в другой список или на другое место в её собственном.
