# 看板

一列列卡片组成的看板，保存成普通的 Markdown 文件。

- **插件 › 新建看板…** 新建一个，文件名是 _名字_.kanban.md。
- 每一列是文件里的一个标题，每张卡片是它下面的一条任务，所以在别处打开也照样能读。
- 在列底部添加卡片；拖动卡片换列，拖动列调整顺序。勾上的卡片就是完成了。
- 卡片里可以写 [[链接]]，点一下就打开那篇笔记。
- **作为 Markdown 编辑** 以文本打开文件，改完后看板会跟着更新。

```markdown
## 待办

- [ ] 写大纲

## 已完成

- [x] 定标题
```

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `list_boards`：列出打开的文件夹中的看板（name.kanban.md 文件），以及每个看板的各个列表和其中的卡片数。
- `read_board`：读取一个看板：按顺序给出各个列表，以及每个列表里卡片的文字和是否已完成。 普通文档里的任务用 list_tasks。
- `add_card`：在看板某个列表的末尾添加一张卡片。 只用于看板（name.kanban.md）；文档里的待办用 add_task。
- `move_card`：把看板上的一张卡片移到另一个列表，或移到所在列表的另一个位置。
