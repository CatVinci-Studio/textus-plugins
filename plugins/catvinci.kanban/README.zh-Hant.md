# 看板

由一列列卡片組成的看板，儲存成一般的 Markdown 檔案。

- 選擇 **外掛程式 › 新增看板…** 建立一個，檔名為 _名稱_.kanban.md。
- 每一列是檔案中的一個標題，每張卡片是它底下的一項任務，所以在其他地方開啟也一樣能閱讀。
- 在清單底部新增卡片；拖曳卡片可換清單，拖曳清單可調整順序。已勾選的卡片就是完成了。
- 在卡片裡寫 [[連結]]，點一下就會開啟那篇筆記。
- **以 Markdown 編輯** 以文字開啟檔案，改完後看板會跟著更新。

```markdown
## 待辦

- [ ] 寫大綱

## 已完成

- [x] 定標題
```

## Textus AI 工具

裝上這個外掛後，Textus AI 在對話中可以使用：

- `list_boards`：列出開啟的資料夾中的看板（name.kanban.md 檔案），以及每個看板的各個列表和其中的卡片數。
- `read_board`：讀取一個看板：依順序給出各個列表，以及每個列表裡卡片的文字和是否已完成。
- `add_card`：在看板某個列表的末尾新增一張卡片。
- `move_card`：把看板上的一張卡片移到另一個列表，或移到所在列表的另一個位置。
