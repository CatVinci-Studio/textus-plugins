# Visão de grafo

Suas notas e os links entre elas, em forma de grafo.

- **Ctrl+Alt+G** (**⌘⌥G** no Mac), ou **Plugins › Abrir a visão de grafo**, mostra a pasta inteira numa aba.
- A aba **Grafo** da barra lateral mostra as notas ao redor do documento em primeiro plano.
- Contam tanto os [[wiki links]] quanto os links para outros documentos. Clique numa nota para abri-la; arraste para se mover e role para dar zoom.
- Até onde vai o grafo da barra lateral e se as notas sem links aparecem está nos ajustes do plugin.
