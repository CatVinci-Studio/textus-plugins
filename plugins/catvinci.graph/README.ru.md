# Граф заметок

Ваши заметки и ссылки между ними в виде графа.

- **Ctrl+Alt+G** (**⌘⌥G** на Mac) или **Плагины › Открыть граф заметок** показывает всю папку во вкладке.
- Вкладка **Граф** на боковой панели показывает заметки вокруг открытого документа.
- Учитываются [[вики-ссылки]] и ссылки на другие документы. Щёлкните заметку, чтобы открыть её (с Ctrl или ⌘ — в новой вкладке); перетаскивайте, чтобы двигать, колёсиком меняйте масштаб.
- Кнопка с ползунками вверху открывает настройки графа:
  - **Фильтры**: поиск (`path:идеи`, `file:черновик`, `tag:#todo`, `-` впереди исключает), теги как узлы, ещё не созданные заметки, заметки без ссылок. Граф на боковой панели также задаёт, насколько далеко он охватывает.
  - **Группы**: раскрасьте заметки, найденные поиском.
