# Граф заметок

Ваши заметки и связи между ними в виде графа.

- **Ctrl+Alt+G** (**⌘⌥G** на Mac) или **Плагины › Открыть граф заметок** показывает всю папку во вкладке.
- Вкладка **Граф** на боковой панели показывает заметки вокруг текущего документа.
- Учитываются и [[wiki links]], и ссылки на другие документы. Нажмите на заметку, чтобы открыть её; перетаскивайте, чтобы двигаться, прокручивайте, чтобы масштабировать.
- Насколько далеко простирается граф на боковой панели и показывать ли заметки без ссылок — настраивается в параметрах плагина.
