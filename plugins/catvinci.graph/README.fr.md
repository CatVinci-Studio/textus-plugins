# Vue en graphe

Vos notes et les liens entre elles, sous forme de graphe.

- **Ctrl+Alt+G** (**⌘⌥G** sur Mac), ou **Extensions › Ouvrir la vue en graphe**, affiche tout le dossier dans un onglet.
- L’onglet **Graphe** de la barre latérale montre les notes autour du document au premier plan.
- Les [[wiki links]] comme les liens vers d’autres documents comptent. Cliquez sur une note pour l’ouvrir ; faites glisser pour vous déplacer, faites défiler pour zoomer.
- La portée du graphe de la barre latérale et l’affichage des notes sans lien se règlent dans les réglages de l’extension.
