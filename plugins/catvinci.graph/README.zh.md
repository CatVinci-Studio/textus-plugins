# 关系图谱

把你的笔记和它们之间的链接画成一张图。

- 按 **Ctrl+Alt+G**（Mac 上 **⌘⌥G**），或 **插件 › 打开知识图谱**，在标签页里看整个文件夹。
- 侧边栏的 **图谱** 标签显示当前文档周围的笔记。
- [[维基链接]] 和指向其他文档的链接都算。点一个笔记就打开它（按住 Ctrl 或 ⌘ 在新标签页打开）；拖动可以移动画面，滚轮缩放。
- 顶部的滑杆按钮打开图谱设置：
  - **筛选**：搜索（`path:想法`、`file:草稿`、`tag:#待办`，前面加 `-` 表示排除）、把标签画成节点、尚未创建的笔记、没有链接的笔记。侧边栏图谱还能设置显示几层。
  - **分组**：给搜索到的笔记上色。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `list_neighbours`：给出一篇文档（默认当前文档）在笔记关系图中的周边：几步链接之内（不论方向）的笔记、各自相隔几步，以及它们之间的链接。指向不存在笔记的 [[链接]] 记为 missing。
