# 그래프 보기

노트와 그 사이의 링크를 그래프로 보여 줍니다.

- **Ctrl+Alt+G**(Mac에서는 **⌘⌥G**) 또는 **플러그인 › 그래프 보기 열기**로 폴더 전체를 탭에서 봅니다.
- 사이드바의 **그래프** 탭은 지금 문서 주변의 노트를 보여 줍니다.
- [[위키 링크]]와 다른 문서로 가는 링크 모두 포함됩니다. 노트를 클릭하면 열립니다(Ctrl 또는 ⌘를 누르면 새 탭). 드래그로 이동하고 스크롤로 확대·축소합니다.
- 위쪽의 슬라이더 버튼으로 그래프 설정을 엽니다:
  - **필터**: 검색(`path:아이디어`, `file:초안`, `tag:#할일`, 앞에 `-`를 붙이면 제외), 태그를 노드로 표시, 아직 없는 노트, 링크 없는 노트. 사이드바 그래프는 깊이와 따라갈 링크도 정합니다.
  - **그룹**: 검색에 맞는 노트에 색을 입힙니다.
  - **표시**: 화살표, 라벨이 보이는 시점, 노드 크기, 링크 두께.
  - **힘**: 중심으로 모이는 힘, 서로 밀어내는 힘, 링크로 당기는 힘, 링크 길이.
