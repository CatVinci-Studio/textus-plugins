# 그래프 보기

노트와 그 사이의 링크를 그래프로 보여 줍니다.

- **Ctrl+Alt+G**(Mac에서는 **⌘⌥G**) 또는 **플러그인 › 그래프 보기 열기**로 폴더 전체를 탭에서 봅니다.
- 사이드바의 **그래프** 탭은 지금 문서 주변의 노트를 보여 줍니다.
- [[위키 링크]]와 다른 문서로 가는 링크 모두 포함됩니다. 노트를 클릭하면 열립니다(Ctrl 또는 ⌘를 누르면 새 탭). 드래그로 이동하고 스크롤로 확대·축소합니다.
- 위쪽의 슬라이더 버튼으로 그래프 설정을 엽니다:
  - **필터**: 검색(`path:아이디어`, `file:초안`, `tag:#할일`, 앞에 `-`를 붙이면 제외), 태그를 노드로 표시, 아직 없는 노트, 링크 없는 노트. 사이드바 그래프는 몇 단계까지 보일지도 정합니다.
  - **그룹**: 검색에 맞는 노트에 색을 입힙니다.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `list_neighbours`: 어떤 문서(경로가 없으면 앞에 열린 문서)의 노트 그래프 속 이웃을 돌려줍니다. 방향과 관계없이 몇 링크 안의 노트, 각각 몇 링크 떨어졌는지, 그 사이의 링크입니다. 없는 노트로 가는 [[링크]]는 kind가 missing입니다.
