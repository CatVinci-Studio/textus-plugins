# 知識圖譜

把你的筆記和它們之間的連結畫成一張圖。

- 按 **Ctrl+Alt+G**（Mac 上 **⌘⌥G**），或 **外掛程式 › 開啟知識圖譜**，在分頁裡看整個資料夾。
- 側邊欄的 **圖譜** 分頁顯示目前文件周圍的筆記。
- [[維基連結]] 和指向其他文件的連結都算。點一個筆記就開啟它（按住 Ctrl 或 ⌘ 在新分頁開啟）；拖曳可以移動畫面，滾輪縮放。
- 頂部的滑桿按鈕開啟圖譜設定：
  - **篩選**：搜尋（`path:想法`、`file:草稿`、`tag:#待辦`，前面加 `-` 表示排除）、把標籤畫成節點、尚未建立的筆記、沒有連結的筆記。側邊欄圖譜還能設定顯示幾層。
  - **分組**：替搜尋到的筆記上色。
