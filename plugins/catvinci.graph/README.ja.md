# グラフビュー

ノートとその間のリンクをグラフで表示します。

- **Ctrl+Alt+G**（Mac では **⌘⌥G**）、または **プラグイン › グラフビューを開く** で、フォルダ全体をタブに表示します。
- サイドバーの **グラフ** タブには、開いている文書の周りのノートが表示されます。
- [[ウィキリンク]] も他の文書へのリンクも対象です。ノートをクリックすると開きます（Ctrl または ⌘ を押しながらで新しいタブ）。ドラッグで移動、スクロールで拡大縮小。
- 上部のスライダーボタンでグラフの設定を開きます：
  - **フィルター**：検索（`path:アイデア`、`file:下書き`、`tag:#todo`、先頭の `-` で除外）、タグをノードとして表示、未作成のノート、リンクのないノート。サイドバーのグラフでは何段先まで表示するかも設定できます。
  - **グループ**：検索に合うノートに色を付けます。

## Textus AI のツール

このプラグインを入れると、Textus AI が会話の中で使えます：

- `list_neighbours`：ある文書（パスがなければ前面の文書）のノートのグラフでの近傍を返します。向きを問わず数リンク以内のノートと、それぞれ何リンク離れているか、その間のリンクです。存在しないノートへの [[リンク]] は kind が missing になります。
