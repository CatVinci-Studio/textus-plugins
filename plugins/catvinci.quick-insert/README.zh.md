# 快速插入

输入 `/` 插入标题、列表、表格等块，输入 `:` 插入表情，输入 `@` 插入日期。

## / 菜单

在行首或空格后输入 `/`，选择要插入的内容：

- **标题 1–3、正文**，以及**无序、有序和待办列表**
- **引用、代码块、公式、表格、分隔线**和**提示框**（`> [!NOTE]`）

接着输入可以缩小范围：`/表格`、`/table`，中文名也能用拼音找（`/biaoge`）。

**转换为…**（在 `/` 菜单和命令面板里）把光标所在的段落改成标题、列表、引用或代码，也能改回正文。

## 表情

输入 `:` 加一个词插入表情：`:tada` 是 🎉，`:+1` 是 👍，`:笑` 是 😄。

## 日期

输入 `@` 加上一个日子，选中后就写入它对应的日期：

- 中文：`@今天`、`@明天`、`@后天`、`@周五`、`@下周五`、`@星期三`、`@3天后`、`@下周`（繁体的 `@後天`、`@下週五`、`@禮拜三`、`@3天後` 也认得）
- English: `@today`、`@tomorrow`、`@yesterday`、`@friday`、`@next friday`、`@in 3 days`、`@next week`
- 日本語：`@今日`、`@明日`、`@明後日`、`@金曜日`、`@来週金曜日`、`@3日後`

每周从周一开始；只说星期几时，指下一个。

默认写成 `2026-11-06` 这样的日期。在插件设置里把 **插入为** 改成 **那天每日笔记的链接**，就会按文件夹的链接写法写成那天每日笔记的链接：默认是标准链接，比如 `[2026-11-06](Daily/2026-11-06.md)`；在 Obsidian 库或已经用 wiki 链接的文件夹里写成 `[[2026-11-06]]`，并按库的每日笔记设置的名称和文件夹，比如 `[[November 6th, 2026]]` 或 `[[Journal/2026/11/2026-11-06]]`。没有这类设置的文件夹，每日笔记默认在 `Daily/` 里。

只有在空格后、行首或括号后输入 `@` 才会弹出，`me@example.com` 这样的邮箱、`[@key]` 这样的引用不会。在 `(` 后面会保留 `@`，所以 `(@明天` 会写成提醒的格式 `(@2026-11-06`。

插入的都是普通的 Markdown。

## 权限

- **读取和编辑文档**：插入块、表情和日期。
- **读取文件**：读取库的每日笔记设置，用来写日期链接。
- **Textus AI 工具**：让 Textus AI 能把文字说的日子换算成日期。

桌面版和 iOS 都能用。

## 更新日志

- **0.4.3** - 支持繁体日期写法，如 後天、3天後、下週五。只输入 @ 时先列出界面语言的日期，日期链接按当前笔记的位置写对。
- **0.4.2** - 同步双向链接里判断笔记链接写法的修复。
- **0.4.1** - 日期链接写成标准链接 [2026-11-08](Journal/2026-11-08.md)，文件夹或笔记本来用双链时仍写双链
- **0.4.0** - 日期链接按文件夹的链接写法写入，使用 Textus 1.3.10 的日期功能；需要 Textus 1.3.10
- **0.3.1** - 带上更新后的共用日期代码
- **0.3.0** - 合并了「自然语言日期」：`@` 日期支持中文、英文和日文，可写成每日笔记链接，并为 Textus AI 提供 `parse_date` 工具
- **0.2.0** - `/` 菜单里的 **今天的日期** 改由 `@今天` 代替
- **0.1.0-0.1.1** - 最初版本：`/` 菜单、**转换为…**、`:` 后插入表情

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `parse_date`：把用文字说的日子（英文、中文或日文，与插件的 @ 补全认得的一样：tomorrow、next wednesday、in 3 days、下周五、明後日）换算成日期 YYYY-MM-DD，从今天算起。每周从周一开始；只说星期几指下一个。
