# Vim

Textus 편집기에서 Vim의 모드와 키를 씁니다.

- **플러그인 › Vim 키 켜기/끄기**로 전환합니다. 켜져 있는 동안 상태 표시줄에 모드(NORMAL, INSERT, VISUAL, V-LINE)가 보이고, 클릭하면 Vim을 끕니다.
- 노멀·삽입·비주얼·비주얼 줄 모드. 이동(**h j k l**, **w b e**, **0 ^ $**, **gg G**, **f t F T**와 **;**·**,**, **Ctrl+D**와 **Ctrl+U**), 연산자(**d c y**, **dd**, **x**, **p P**, **r**, **iw**/**aw**), 횟수, 레지스터, **u**와 **Ctrl+R**로 실행 취소·다시 실행, **.**으로 반복.
- 한 줄은 문단, 제목, 목록 항목, 또는 코드 블록의 한 줄입니다. **j**와 **k**는 이 모두를 지나가고, **}**와 **{**는 블록 단위로 움직입니다. **zz**, **zt**, **zb**는 커서가 있는 줄을 창의 가운데, 위, 아래로 옮깁니다.
- **~**는 커서 위치 글자의 대소문자를 바꿉니다. 비주얼 모드에서 **~**, **U**, **u**는 선택 영역을 각각 뒤집기, 대문자, 소문자로 바꿉니다.
- **s**와 한 글자, 이어서 라벨을 누르면 화면 어디로든 이동합니다(flash). 가까운 곳일수록 먼저 라벨을 받습니다. **s** 앞에 **d**, **c**, **y**를 누르면 거기까지 지우기, 바꾸기, 복사합니다.
- **:**는 Vim 명령이 맨 앞에 오는 명령 팔레트를 엽니다. **:w** 저장, **:q** 탭 닫기, **:wq** 둘 다, **:12** 12번째 줄로, **:u**와 **:redo** 실행 취소와 다시 실행. Textus의 다른 명령도 여기서 찾을 수 있습니다.
- Mac에서는 노멀 모드 동안 영문 입력이 되어, 한글 같은 입력기가 키를 가로채지 않습니다. 삽입 모드로 돌아가면 원래 입력기가 돌아옵니다.

설정은 **설정 › 확장 › 플러그인 › Vim**에 있습니다:

- **s로 이동(flash)**: 기본값 켬. 끄면 **s**는 Vim 본래의 동작(한 글자 지우고 삽입)이 됩니다.
- **삽입 모드를 나가는 키**: 삽입 모드에서 빠르게 이어 치면 Escape처럼 동작하는 두 글자(예: `jk`). 비워 두면 Escape와 **Ctrl+[**만 됩니다.
- **키 매핑**: vimrc처럼 한 줄에 하나씩(`map`, `noremap`, `nnoremap`, `inoremap`, `vnoremap`, `let mapleader`). 예: `inoremap jj <Esc>`, `nnoremap <leader>w :w<CR>`.

Obsidian: Obsidian 보관소에서는 그 보관소의 `.obsidian.vimrc`(Vimrc Support 플러그인의 파일)도 내 설정 다음에 읽고, 파일이 바뀌면 다시 읽습니다.

이 플러그인은 편집기에서 키를 받는 권한(Vim 키를 실행하려고)과 파일 읽기 권한(`.obsidian.vimrc`를 읽을 때만)을 요청합니다. 데스크톱과 iPhone, iPad에서 쓸 수 있습니다.

## 변경 내역

- **0.2.5** - 코드를 역할별로 작은 파일로 나눴습니다. 사용법은 바뀌지 않습니다.
- **0.2.4** - 소개 페이지를 새로 썼습니다. 무엇을 하는지 한 문장으로, 할 수 있는 일과 버전별 변경 내역을 담았습니다.
- **0.2.3** - Obsidian 보관소의 `.obsidian.vimrc`를 읽습니다. 같은 키를 다시 매핑하면 이전 매핑을 바꿉니다.
- **0.2.2** - **zz**, **zt**, **zb**로 커서 줄을 창의 가운데, 위, 아래로.
- **0.2.1** - 실행되는 곳을 밝힘: 데스크톱, iPhone, iPad.
- **0.2.0** - **:**로 Vim 명령이 맨 앞에 오는 명령 팔레트를 엽니다. flash는 한 글자 뒤에 라벨을 보여 줍니다. Mac에서 노멀 모드는 영문 입력.
- **0.1.0-0.1.1** - 첫 버전들: 모드, 이동, 연산자, 횟수, 점 반복, flash와 **ds**·**cs**·**ys**, 명령줄(**:w**, **:q**, **:wq**, **:12**), vimrc식 키 매핑, 대소문자 키.
