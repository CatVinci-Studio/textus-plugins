# Vim

在 Textus 編輯器裡使用 Vim 的模式和按鍵。

- **外掛程式 › 開啟或關閉 Vim 按鍵** 切換開關。開啟時，狀態列會顯示目前模式（NORMAL、INSERT、VISUAL、V-LINE），點它就能關閉 Vim。
- 一般、插入、可視、可視行四種模式，支援移動（**h j k l**、**w b e**、**0 ^ $**、**gg G**、**f t F T** 及 **;** 和 **,**、**Ctrl+D** 和 **Ctrl+U**）、運算子（**d c y**、**dd**、**x**、**p P**、**r**，以及 **iw**／**aw**）、計數、暫存器、**u** 和 **Ctrl+R** 復原與重做，以及 **.** 重複。
- 一「行」是一個段落、標題、清單項目，或程式碼區塊裡的一行：**j** 和 **k** 能走遍它們，**}** 和 **{** 依區塊跳。**zz**、**zt**、**zb** 把游標所在行移到視窗中間、頂端或底部。
- **~** 切換游標處字母的大小寫；在可視模式下，**~**、**U** 和 **u** 分別把選取內容切換大小寫、改成大寫、改成小寫。
- 按 **s** 加一個字母，再按標籤，就能跳到螢幕上任何位置（flash），離游標近的位置先拿到標籤。先按 **d**、**c** 或 **y** 再按 **s**，就是刪除、修改或複製到那裡。
- 按 **:** 開啟命令面板，Vim 的命令排在最前面：**:w** 儲存，**:q** 關閉分頁，**:wq** 儲存並關閉，**:12** 跳到第 12 行，**:u** 和 **:redo** 復原與重做；Textus 的其他命令也能在這裡搜尋到。
- 在 Mac 上，一般模式下會暫時切到英文輸入，注音、拼音等輸入法不會攔住按鍵；回到插入模式，原本的輸入法會自動回來。

設定在 **設定 › 擴充功能 › 外掛程式 › Vim** 裡：

- **用 s 跳轉（flash）**：預設開啟。關掉後，**s** 恢復 Vim 原本的作用（刪除一個字元並進入插入）。
- **退出插入模式的按鍵**：在插入模式下快速連按、作用等同 Escape 的兩個字母，例如 `jk`。留空則只有 Escape 和 **Ctrl+[**。
- **按鍵對應**：像 vimrc 一樣一行一條（`map`、`noremap`、`nnoremap`、`inoremap`、`vnoremap` 和 `let mapleader`），例如 `inoremap jj <Esc>` 或 `nnoremap <leader>w :w<CR>`。

Obsidian：在 Obsidian 庫裡，也會讀取庫裡的 `.obsidian.vimrc`（Vimrc Support 外掛使用的檔案），排在你自己的設定之後；檔案改了會重新讀取。

外掛要求在編輯器裡接管按鍵的權限（用來執行 Vim 按鍵）和讀取檔案的權限（只用來讀 `.obsidian.vimrc`）。電腦、iPhone 和 iPad 上都能使用。
