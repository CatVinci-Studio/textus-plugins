# Pasta de imagens por documento

Guarda as imagens de cada documento ao lado dele, numa pasta com o nome dele, como o Typora e o VS Code: as de `Note.md` vão para `Note.assets/`.

- Cole ou solte uma imagem num documento salvo: o Textus a salva e este plugin a move para a pasta do documento e muda o link para `Note.assets/imagem.png`. Um nome já usado ganha um número; nada é sobrescrito.
- Renomeie um documento na pasta dele e a pasta de imagens é renomeada junto, com os links — a não ser que outro documento também aponte para essa pasta; aí os dois ficam como estão.
- As imagens que seus documentos já têm ficam onde estão.
