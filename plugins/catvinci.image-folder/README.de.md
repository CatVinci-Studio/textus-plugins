# Bilderordner pro Dokument

Legt die Bilder jedes Dokuments daneben in einen Ordner mit seinem Namen, wie Typora und VS Code: die von `Note.md` kommen nach `Note.assets/`.

- Fügen Sie ein Bild in ein gespeichertes Dokument ein oder ziehen Sie es hinein: Textus speichert es, dann verschiebt dieses Plugin es in den Ordner des Dokuments und ändert den Link zu `Note.assets/bild.png`. Ein vergebener Name bekommt eine Nummer; nichts wird überschrieben.
- Benennen Sie ein Dokument in seinem Ordner um, wird sein Bilderordner mit umbenannt, Links eingeschlossen – außer ein anderes Dokument verlinkt ebenfalls in diesen Ordner; dann bleibt beides, wie es ist.
- Bilder, die Ihre Dokumente schon haben, bleiben, wo sie sind.
