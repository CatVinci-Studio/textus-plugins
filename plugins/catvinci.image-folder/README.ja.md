# 文書ごとの画像フォルダ

Typora や VS Code と同じく、文書の画像をその横の、文書名のフォルダに置きます。`Note.md` の画像は `Note.assets/` に入ります。

- 保存済みの文書に画像を貼り付けるかドロップすると、Textus が画像を保存したあと、このプラグインが文書の画像フォルダへ移し、リンクを `Note.assets/画像.png` に変えます。同じ名前があれば番号を付け、何も上書きしません。
- 同じフォルダ内で文書の名前を変えると、画像フォルダもリンクごと名前が変わります。ほかの文書もそのフォルダにリンクしている場合は、どちらもそのままです。
- すでに文書にある画像はそのままです。
