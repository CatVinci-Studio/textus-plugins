# Images avec le document

Range les images de chaque document à côté de lui, dans un dossier à son nom, comme Typora et VS Code : celles de `Note.md` vont dans `Note.assets/`.

- Collez ou déposez une image dans un document enregistré : Textus l’enregistre, puis cette extension la déplace dans le dossier du document et change le lien en `Note.assets/image.png`. Un nom déjà pris reçoit un numéro ; rien n’est écrasé.
- Renommez un document dans son dossier, et son dossier d’images est renommé avec lui, liens compris – sauf si un autre document pointe aussi vers ce dossier : alors les deux restent tels quels.
- Les images déjà présentes dans vos documents restent où elles sont.
