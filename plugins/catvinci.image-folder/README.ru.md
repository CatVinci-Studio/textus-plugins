# Картинки рядом с документом

Хранит картинки каждого документа рядом с ним, в папке с его именем, как Typora и VS Code: картинки `Note.md` попадают в `Note.assets/`.

- Вставьте или перетащите картинку в сохранённый документ: Textus сохранит её, а этот плагин переместит её в папку документа и поменяет ссылку на `Note.assets/картинка.png`. Занятое имя получает номер; ничего не перезаписывается.
- Переименуйте документ в его папке — папка с картинками переименуется вместе с ним, со ссылками, если только на эту папку не ссылается другой документ: тогда всё остаётся как есть.
- Картинки, которые уже есть в документах, остаются на месте.
