# Carpeta de imágenes por documento

Guarda las imágenes de cada documento a su lado, en una carpeta con su nombre, como Typora y VS Code: las de `Note.md` van en `Note.assets/`.

- Pega o suelta una imagen en un documento guardado: Textus la guarda y este complemento la mueve a la carpeta del documento y cambia el enlace a `Note.assets/imagen.png`. Un nombre ya usado recibe un número; nada se sobrescribe.
- Si cambias el nombre de un documento dentro de su carpeta, su carpeta de imágenes cambia con él, enlaces incluidos, salvo que otro documento también enlace a esa carpeta: entonces ambos se quedan como están.
- Las imágenes que ya tienen tus documentos se quedan donde están.
