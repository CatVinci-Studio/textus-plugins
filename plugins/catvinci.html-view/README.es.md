# Visor HTML

Lee los archivos .html en una pestaña como las páginas que son: un informe, una página de diapositivas o una nota guardada como HTML.

- Abre un archivo .html o .htm desde la barra lateral, o arrástralo a la ventana.
- Se muestra en solo lectura, con sus propios estilos; sus scripts solo se ejecutan dentro de la pestaña y no salen a la red.
- **Editar código** abre el archivo como texto en Textus, para cambiarlo.

El plugin no pide permisos: solo lee el archivo que abres con él.

## Cambios

- **0.1.3** - Its page is in every language Textus speaks. Its page receives Textus's messages by the API's current name.
- **0.1.2** - The page follows Textus's language by itself. Needs Textus 1.4.3.
- **0.1.1** - The page listens only to Textus: scripts in the HTML file it shows can't change what it displays.
- **0.1.0** - First version: .html files in a tab as pages, and Edit source.
