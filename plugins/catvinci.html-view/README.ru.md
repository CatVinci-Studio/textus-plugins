# Просмотр HTML

Читайте файлы .html во вкладке такими, какими они выглядят как страницы: отчёт, слайд или заметку, сохранённую в HTML.

- Откройте файл .html или .htm на боковой панели или перетащите его в окно.
- Он показывается только для чтения, со своим оформлением; его скрипты работают только внутри вкладки и не выходят в сеть.
- **Изменить код** открывает файл как текст в Textus, чтобы его править.

Плагин не просит никаких разрешений: он только читает файл, который вы им открываете.
