# HTML 檢視器

在分頁中把 .html 檔案顯示成原本的網頁：報告、投影片頁面，或存成 HTML 的筆記。

- 從側邊欄開啟 .html 或 .htm 檔案，或把檔案拖進視窗。
- 網頁以唯讀方式顯示，保留它自己的樣式；它的程式碼只在分頁內執行，也不會連上網路。
- **編輯原始碼** 會在 Textus 裡以文字開啟檔案，方便修改。

外掛不要求任何權限，只讀取你用它開啟的檔案。

## 更新紀錄
