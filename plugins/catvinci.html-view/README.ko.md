# HTML 뷰어

.html 파일을 웹 페이지 그대로 탭에서 읽습니다. HTML로 저장한 보고서, 슬라이드 페이지, 노트 등.

- 사이드바에서 .html이나 .htm 파일을 열거나 창으로 끌어다 놓습니다.
- 페이지 자체의 스타일로 읽기 전용으로 보입니다. 스크립트는 탭 안에서만 돌고, 네트워크에는 접속하지 않습니다.
- **소스 편집**을 누르면 Textus에서 텍스트로 열어 고칠 수 있습니다.

이 플러그인은 권한을 요청하지 않습니다. 열어 둔 파일만 읽습니다.

## 변경 내역

- **0.1.3** - Its page is in every language Textus speaks. Its page receives Textus's messages by the API's current name.
- **0.1.2** - The page follows Textus's language by itself. Needs Textus 1.4.3.
- **0.1.1** - The page listens only to Textus: scripts in the HTML file it shows can't change what it displays.
- **0.1.0** - First version: .html files in a tab as pages, and Edit source.
