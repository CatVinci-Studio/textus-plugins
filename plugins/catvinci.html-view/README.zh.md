# HTML 查看器

在标签页里把 .html 文件按网页的样子阅读：报告、幻灯片页面或存成 HTML 的笔记。

- 从侧栏打开 .html 或 .htm 文件，或把它拖进窗口。
- 只读显示，保留它自己的样式；它的脚本只在这个标签页里运行，不能联网。
- **编辑源码** 会在 Textus 里以文本打开这个文件，方便修改。

这个插件不需要任何权限：只读取你在其中打开的文件。
