# Visionneuse HTML

Lisez les fichiers .html dans un onglet comme les pages qu’ils sont : un rapport, une page de diapositives ou une note enregistrée en HTML.

- Ouvrez un fichier .html ou .htm depuis la barre latérale, ou faites-en glisser un dans la fenêtre.
- Il s’affiche en lecture seule, avec ses propres styles ; ses scripts ne s’exécutent que dans l’onglet, et il n’accède pas au réseau.
- **Modifier la source** ouvre le fichier en texte dans Textus, pour le changer.

Le plugin ne demande aucune permission : il lit seulement le fichier que vous ouvrez avec lui.

## Changements

- **0.1.3** - Its page is in every language Textus speaks. Its page receives Textus's messages by the API's current name.
- **0.1.2** - The page follows Textus's language by itself. Needs Textus 1.4.3.
- **0.1.1** - The page listens only to Textus: scripts in the HTML file it shows can't change what it displays.
- **0.1.0** - First version: .html files in a tab as pages, and Edit source.
