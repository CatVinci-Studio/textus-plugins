# HTML-Ansicht

Lesen Sie .html-Dateien in einem Tab als die Seiten, die sie sind: ein Bericht, eine Folienseite oder eine als HTML gespeicherte Notiz.

- Öffnen Sie eine .html- oder .htm-Datei aus der Seitenleiste, oder ziehen Sie eine ins Fenster.
- Sie wird schreibgeschützt mit ihren eigenen Stilen angezeigt; ihre Skripte laufen nur im Tab, und sie erreicht kein Netzwerk.
- **Quelltext bearbeiten** öffnet die Datei als Text in Textus, um sie zu ändern.

Das Plugin fragt nach keinen Berechtigungen: Es liest nur die Datei, die Sie damit öffnen.

## Änderungen

- **0.1.3** - Its page is in every language Textus speaks. Its page receives Textus's messages by the API's current name.
- **0.1.2** - The page follows Textus's language by itself. Needs Textus 1.4.3.
- **0.1.1** - The page listens only to Textus: scripts in the HTML file it shows can't change what it displays.
- **0.1.0** - First version: .html files in a tab as pages, and Edit source.
