# HTML ビューア

.html ファイルを、本来のページの姿のままタブで読めます。HTML で保存したレポート、スライドのページ、ノートなどです。

- サイドバーから .html か .htm ファイルを開くか、ウインドウにドラッグします。
- 読み取り専用で、ページ自身のスタイルで表示します。スクリプトはタブの中でだけ動き、ネットワークにはつながりません。
- **ソースを編集** で、ファイルを Textus でテキストとして開いて変更できます。

このプラグインは権限を求めません。開いたファイルを読むだけです。
