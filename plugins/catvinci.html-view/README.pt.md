# Visualizador HTML

Leia arquivos .html numa aba como as páginas que são: um relatório, uma página de slides ou uma nota salva como HTML.

- Abra um arquivo .html ou .htm pela barra lateral, ou arraste um para a janela.
- Ele aparece somente leitura, com os próprios estilos; os scripts dele rodam só dentro da aba e não acessam a rede.
- **Editar código** abre o arquivo como texto no Textus, para alterá-lo.

O plugin não pede permissões: só lê o arquivo que você abre com ele.

## Alterações

- **0.1.3** - Its page is in every language Textus speaks. Its page receives Textus's messages by the API's current name.
- **0.1.2** - The page follows Textus's language by itself. Needs Textus 1.4.3.
- **0.1.1** - The page listens only to Textus: scripts in the HTML file it shows can't change what it displays.
- **0.1.0** - First version: .html files in a tab as pages, and Edit source.
