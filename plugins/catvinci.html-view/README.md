# HTML View

Read .html files in a tab as the pages they are: a report, a slide page or a note saved as HTML.

- Open a .html or .htm file from the sidebar, or drag one into the window.
- It shows read-only, with its own styles; its scripts run inside the tab only, and it reaches no network.
- **Edit source** opens the file as text in Textus, to change it.

The plugin asks for no permissions: it only reads the file you open in it.

## Changes

- **0.1.1** - The page listens only to Textus: scripts in the HTML file it shows can't change what it displays.
- **0.1.0** - First version: .html files in a tab as pages, and Edit source.
