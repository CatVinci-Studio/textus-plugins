# ECharts

在代码块里写一段 ECharts 配置，文档里就会画出对应的图表。

写一个语言为 `echarts` 的代码块，在里面放 ECharts 的 option 配置，代码块下方就会画出图表；点进代码块可以再次查看和修改源码。

- 配置用 JSON 写，也可以写得随意些：键名不加引号、用单引号、末尾多逗号、写注释都可以。函数（比如 `formatter` 函数）不行，因为代码块里的内容不会被执行。
- 柱状图、折线图、饼图、散点图、雷达图、仪表盘、漏斗图、树图、矩形树图、旭日图、桑基图、热力图、K 线图等 ECharts 系列都能画。地图系列不行：它需要地图数据，代码块无法加载。
- 在语言后面写 `height=400` 可以设置图表高度（单位像素，默认 320）。
- 图表颜色跟随主题，切换主题时会重新绘制。
- 配置画不出来时，代码块里会说明哪里出了问题。
- 导出 HTML、PDF、Word 时，图表会作为图片放进去。

插件只申请一项权限：为 Textus AI 提供下面列出的 `check_echarts` 工具，让它在把代码块写进文档前先检查一遍。电脑、iPhone 和 iPad 上都能用。

## 示例

```echarts
{
  xAxis: { type: "category", data: ["Mon", "Tue", "Wed"] },
  yAxis: { type: "value" },
  series: [{ type: "bar", data: [120, 200, 150] }]
}
```

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `check_echarts`：在把 ```echarts 块写进文档之前检查它的源码（JSON 格式的 ECharts option：带类型的 series，以及它们所在的坐标轴或组件），不实际绘制。返回 ok，或需要先修正的问题。传入时不带代码围栏。
