# ECharts

코드 블록에 적은 ECharts 옵션으로 문서 안에 차트를 그립니다.

언어를 `echarts`로 한 코드 블록에 ECharts 옵션을 쓰면 블록 아래에 차트가 그려집니다. 블록을 클릭하면 소스를 다시 보고 고칠 수 있습니다.

- 옵션은 JSON으로 쓰며, 느슨하게 써도 됩니다. 따옴표 없는 키, 작은따옴표, 끝의 쉼표, 주석 모두 괜찮습니다. 함수(예: `formatter` 함수)는 쓸 수 없습니다. 블록 안의 내용은 실행되지 않기 때문입니다.
- 막대, 선, 원형, 산점도, 레이더, 게이지, 깔때기, 트리, 트리맵, 선버스트, 생키, 히트맵, 캔들스틱 등 ECharts 시리즈를 그립니다. 지도 시리즈는 그리지 못합니다. 블록에서 지도 데이터를 불러올 수 없기 때문입니다.
- 언어 뒤에 `height=400`처럼 쓰면 차트 높이를 픽셀로 정합니다(기본값 320).
- 차트 색은 테마를 따르고, 테마를 바꾸면 다시 그려집니다.
- 옵션을 그릴 수 없으면 무엇이 문제인지 블록에 표시합니다.
- HTML, PDF, Word로 내보내면 차트가 그림으로 들어갑니다.

이 플러그인이 요청하는 권한은 하나입니다. 아래에 있는 `check_echarts` 도구를 Textus AI에 주어, 문서에 블록을 쓰기 전에 확인하게 하기 위해서입니다. 데스크톱과 iPhone, iPad에서 쓸 수 있습니다.

## 예시

```echarts
{
  xAxis: { type: "category", data: ["Mon", "Tue", "Wed"] },
  yAxis: { type: "value" },
  series: [{ type: "bar", data: [120, 200, 150] }]
}
```

## 변경 내역

- **0.3.1** - 설명에서 지도를 뺐습니다. 블록은 지도 데이터를 불러올 수 없습니다.
- **0.3.0** - Textus AI가 `echarts` 블록을 쓰기 전에 확인할 수 있습니다.
- **0.2.0** - 시리즈 색을 테마의 색조에서 가져옵니다. Textus 1.3.2가 필요합니다.
- **0.1.3** - 테마의 본문 글자색과 각주 크기를 Textus 1.3의 새 이름으로 읽습니다.
- **0.1.0-0.1.2** - 첫 버전들: 문서 안에서 `echarts` 코드 블록 그리기, `height=`, 내보낼 때 그림으로.

- `check_echarts`: ```echarts 블록의 소스(JSON으로 쓴 ECharts option: 유형이 있는 series와 그것이 그려지는 축이나 컴포넌트)를 문서에 넣기 전에 그리지 않고 검사합니다. ok나 먼저 고칠 문제를 돌려줍니다. 펜스 없이 소스만 넘기세요.
