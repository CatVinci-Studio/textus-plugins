# ECharts

Диаграммы по настройкам ECharts: столбцы, линии, круговые и другие.

- Напишите блок кода на `echarts`: под ним появится рисунок, а исходник снова видно, если щёлкнуть в блок.
- `height=400` после имени языка задаёт высоту рисунка.
- При экспорте в HTML, PDF или Word рисунок попадает картинкой.

## Пример

```echarts
{
  xAxis: { type: "category", data: ["Mon", "Tue", "Wed"] },
  yAxis: { type: "value" },
  series: [{ type: "bar", data: [120, 200, 150] }]
}
```
