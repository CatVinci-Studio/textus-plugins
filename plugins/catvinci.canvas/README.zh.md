# 白板

在标签页里打开 Obsidian 的白板：上面的笔记、图片、链接、分组，以及它们之间的箭头。目前只能查看，编辑白板仍在 Obsidian 里进行。

- 从侧边栏打开 `.canvas` 文件，打开时整个白板正好放进标签页。
- 拖动可以移动画布；用 **Ctrl+滚轮**（Mac 上 **⌘+滚轮**）、双指捏合或 **-**、**+** 按钮缩放。点百分比让整个白板回到窗口里。
- 白板上的笔记显示标题和开头几行，图片直接显示；点一下就会打开。链接在浏览器里打开。
- 颜色跟随主题：Obsidian 的六种预设颜色用主题的红、橙、黄、绿、青、紫。
- 快捷键：**+** 和 **-** 缩放，**0** 或 **F** 适应窗口，方向键移动。

Excalidraw 绘图（`.excalidraw.md`、`.excalidraw`）也能打开。Textus 不绘制它们，而是显示 Excalidraw 导出的图片：笔记里嵌入的图片，或自动导出写在旁边的 `.svg`、`.png`。没有导出图时，点 **以文本打开** 查看文件本身。

插件只读取文件，从不修改。
