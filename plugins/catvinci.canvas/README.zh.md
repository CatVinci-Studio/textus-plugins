# 白板

在标签页里打开 Obsidian 的白板（`.canvas`），查看上面的笔记、图片、链接和分组。

从侧边栏打开 `.canvas` 文件，它会占满一个标签页，整个白板正好放进窗口。白板只用来查看：可以在上面移动、打开上面的内容，但编辑白板目前仍要在 Obsidian 里进行。

- 拖动或滚动可以移动画布。用 **Ctrl+滚轮**（Mac 上是 **⌘+滚轮**）、双指捏合，或缩小、放大按钮来缩放。点百分比，整个白板会重新放进窗口。
- 白板上的笔记显示标题和开头几行，图片直接显示。点一下就会打开；指向某个标题或块的卡片会打开笔记并直接跳到那里。网页链接在浏览器里打开。
- 箭头、箭头上的文字和分组都按 Obsidian 的样子画出。颜色跟随主题：Obsidian 的六种预设颜色对应主题的红、橙、黄、绿、青、紫。
- 快捷键：**+** 和 **-** 缩放，**0** 或 **F** 适应窗口，方向键移动。

Excalidraw 绘图（`.excalidraw.md`、`.excalidraw`）也能打开。Textus 不绘制它们，而是显示 Excalidraw 导出的图片：笔记里嵌入的那张，或者 Excalidraw 自动导出时写在旁边的 `.svg`、`.png`。没有导出图时，点 **以文本打开** 查看文件本身。

插件只申请读取文件的权限（用来显示白板上的笔记和图片），从不修改文件。电脑、iPhone 和 iPad 上都能用。
