# Canevas

Ouvrez les canevas d’Obsidian (`.canvas`) dans un onglet pour parcourir les notes, images, liens et groupes qu’ils contiennent.

Ouvrez un fichier `.canvas` depuis la barre latérale : il remplit un onglet, ajusté à la fenêtre. Le canevas est en lecture : vous pouvez vous y déplacer et ouvrir ce qu’il contient, mais sa modification reste dans Obsidian pour l’instant.

- Faites glisser, ou faites défiler, pour vous déplacer. Zoomez avec **Ctrl+défilement** (**⌘+défilement** sur Mac), en pinçant, ou avec les boutons de zoom arrière et de zoom avant. Cliquez sur le pourcentage pour afficher de nouveau tout le canevas.
- Une note du canevas montre son titre et ses premières lignes, et une image s’affiche elle-même. Cliquez sur l’une d’elles pour l’ouvrir ; une carte qui pointe vers un titre ou un bloc ouvre la note à cet endroit. Un lien web s’ouvre dans votre navigateur.
- Les flèches, leurs étiquettes et les groupes sont dessinés comme dans Obsidian. Les couleurs viennent de votre thème : les six couleurs prédéfinies d’Obsidian prennent le rouge, l’orange, le jaune, le vert, le bleu-vert et le violet du thème.
- Touches : **+** et **-** zooment, **0** ou **F** affiche tout, les flèches déplacent.

Les dessins Excalidraw s’ouvrent avec le plugin **Excalidraw**, où vous pouvez aussi les modifier.

Le plugin demande seulement à lire les fichiers (pour afficher les notes et les images d’un canevas). Il ne les modifie jamais.

## Changements

- **0.1.7** - A pinch zooms the canvas through Textus, as PDFs and pictures do, instead of through the canvas's own two-finger code; a second finger no longer moves it. Its page is in every language Textus speaks. Its description says it is for viewing; editing stays in Obsidian. Its page receives Textus's messages by the API's current name.
- **0.1.6** - Excalidraw drawings now open with the new Excalidraw plugin, which edits them; Canvas no longer shows their exported picture.
- **0.1.5** - The page follows Textus's language by itself. Needs Textus 1.4.3.
- **0.1.4** - An empty or unreadable canvas now shows one clear message across the page. Card labels stay readable in every theme, and dragging no longer stops when the pointer leaves the canvas.
- **0.1.3** - Shorter help and empty-state text. Its bar keeps Textus's one order: what it shows, then find and zoom.
- **0.1.2** - Its bars, lists and controls are Textus's own, grow with the interface and follow every theme; needs Textus 1.3.12.
- **0.1.1** - Its page now says in one sentence what it does, what it can do, and what changed in each version.
- **0.1.0** - first version: Obsidian canvases in a tab to drag and zoom, notes and pictures shown on the board, and Excalidraw drawings by their exported picture.
