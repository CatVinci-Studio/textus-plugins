# WakaTime

把你在 Textus 里写作的时间发到你的 [WakaTime](https://wakatime.com) 账号，和写代码的时间一起显示在统计面板上。

1. 在 [wakatime.com/settings/api-key](https://wakatime.com/settings/api-key) 复制你的 API 密钥。
2. 在命令面板里运行「WakaTime：设置 API 密钥…」，粘贴进去。

写作时，它会告诉 WakaTime 你在写哪个文档（文件路径）、打开的文件夹名（作为项目）以及什么时候保存。同一个文档最多每两分钟发送一次，和 WakaTime 官方插件的做法一样。设置密钥之前不会发送任何内容，没保存过的文档也不会发送。想停止时，把密钥设为空即可。
