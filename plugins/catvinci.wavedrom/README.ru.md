# WaveDrom

Цифровые временные диаграммы по WaveJSON.

- Напишите блок кода на `wavedrom`: под ним появится рисунок, а исходник снова видно, если щёлкнуть в блок.
- `height=400` после имени языка задаёт высоту рисунка.
- При экспорте в HTML, PDF или Word рисунок попадает картинкой.

## Пример

```wavedrom
{ signal: [
  { name: "clk",  wave: "p....." },
  { name: "data", wave: "x.345x", data: ["a", "b", "c"] }
]}
```
