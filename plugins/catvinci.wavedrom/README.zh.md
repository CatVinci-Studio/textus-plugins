# WaveDrom

用 WaveJSON 画数字时序图和寄存器字段图。

## 画一张图

- 写一个 `wavedrom` 代码块，里面写 WaveJSON。图会画在代码块下方；点进代码块可以再看到并修改源码。
- `signal` 里是各条信号：每条有 `name`、`wave` 波形字符串（`p n h l 0 1 x z . |`，以及表示数值的 `= 2-9`）和数值标签 `data`。以标签开头的列表把几条信号分成一组；`{}` 留一行空白。
- 写 `reg` 则画寄存器的字段：`{ reg: [{ bits: 8, name: "data" }] }`。
- 手写的 JSON 也能读：键不加引号、单引号、末尾多余的逗号和 `//` 注释都可以。
- 源码有错时，代码块下方会说明问题。
- 在语言后面写 `height=400` 可以设置图的高度。
- 深色主题下使用 WaveDrom 的深色外观。导出 HTML、PDF、Word 时，图会按导出的配色重画，作为图片放进去。

## 示例

```wavedrom
{ signal: [
  { name: "clk",  wave: "p....." },
  { name: "data", wave: "x.345x", data: ["a", "b", "c"] }
]}
```

## 权限

只需要 **Textus AI 工具** 权限，让 Textus AI 在写入代码块前先检查一遍。WaveDrom 随插件一起安装：它不读取任何文件，全部在本机绘制，桌面版和 iOS 都能用。
