# Numeración de títulos

Numera los títulos mientras escribes (1, 1.1, 1.2) sin cambiar el texto; las exportaciones pueden llevar los números.

- Los títulos reciben su número mientras escribes: 1, 1.1, 1.2, 2… El texto no cambia.
- La numeración empieza en el nivel de encabezado más alto del documento, o en el siguiente si ese nivel solo tiene el título.
- **Números en las exportaciones**: las exportaciones HTML y PDF muestran los mismos números.

## Herramientas para Textus AI

Con el plugin instalado, Textus AI puede usarlas en una conversación:

- `number_headings`: Escribe números en los encabezados de un Markdown - 1, 1.1, 1.2 -, contados como los muestra el editor (un título único no se numera), y sustituye los que ya hubiera; con remove, los quita. Devuelve el texto; no escribe nada.
