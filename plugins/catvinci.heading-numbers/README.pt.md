# Numeração de títulos

Numera os títulos enquanto você escreve (1, 1.1, 1.2) sem mudar o texto; as exportações podem levar os números.

- Os títulos recebem números enquanto você escreve: 1, 1.1, 1.2, 2… O texto não muda.
- A numeração começa no nível de título mais alto do documento, ou no seguinte quando esse nível só tem o título.
- **Números nas exportações**: as exportações HTML e PDF mostram os mesmos números.
