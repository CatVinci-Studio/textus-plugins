# 標題編號

寫作時為標題自動編號（1、1.1、1.2），不改動原文；匯出時也可以帶上編號。

- 寫作時標題會自動顯示編號：1、1.1、1.2、2……原文本身不會改動。
- 編號從文件最高一級的標題開始；如果那一級只有一個標題（文件的題目），就從下一級開始。
- **匯出時帶編號**：匯出 HTML 和 PDF 時顯示同樣的編號。

## Textus AI 工具

裝上這個外掛後，Textus AI 在對話中可以使用：

- `number_headings`：把編號寫進一段 Markdown 的標題裡（1、1.1、1.2），編號方式與編輯器中顯示的一致（單獨的總標題不編號），已有的編號會被取代；設 remove 時則移除編號。回傳處理後的文字，不寫入任何檔案。
