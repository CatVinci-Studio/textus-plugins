# 标题编号

写作时给标题自动编号（1、1.1、1.2），不改动原文；导出时也可以带上编号。

- 写作时标题会自动显示编号：1、1.1、1.2、2……原文本身不会改动。
- 编号从文档最高一级的标题开始；如果那一级只有一个标题（文档的题目），就从下一级开始。
- **导出时带编号**：导出 HTML 和 PDF 时显示同样的编号。

## Textus AI 工具

装上这个插件后，Textus AI 在对话中可以使用：

- `number_headings`：把编号写进一段 Markdown 的标题里（1、1.1、1.2），编号方式与编辑器中显示的一致（单独的总标题不编号），已有的编号会被替换；设 remove 时则去掉编号。返回处理后的文本，不写入任何文件。
