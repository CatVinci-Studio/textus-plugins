# 제목 번호

쓰는 동안 제목에 번호(1, 1.1, 1.2)를 붙입니다. 원문은 바꾸지 않으며 내보낼 때도 번호를 넣을 수 있습니다.

- 쓰는 동안 제목에 번호가 표시됩니다: 1, 1.1, 1.2, 2… 원문은 바뀌지 않습니다.
- 번호는 문서의 가장 높은 제목 수준부터 매깁니다. 그 수준에 문서 제목 하나만 있으면 한 단계 아래부터입니다.
- **내보낼 때 번호 넣기**: HTML과 PDF로 내보낼 때 같은 번호가 들어갑니다.

## Textus AI 도구

이 플러그인을 설치하면 Textus AI가 대화 중에 사용할 수 있습니다:

- `number_headings`: Markdown의 제목에 번호(1, 1.1, 1.2)를 써 넣습니다. 번호는 편집기에 보이는 것과 같이 매기며(하나뿐인 표제는 제외), 이미 있는 번호는 바꿉니다. remove를 주면 번호를 뺍니다. 글을 돌려주고 아무것도 쓰지 않습니다.
