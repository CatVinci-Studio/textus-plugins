# Numérotation des titres

Numérote les titres pendant l’écriture (1, 1.1, 1.2) sans changer le texte ; les exports peuvent garder les numéros.

- Les titres reçoivent leur numéro pendant l’écriture : 1, 1.1, 1.2, 2… Le texte ne change pas.
- La numérotation part du niveau de titre le plus haut du document, ou du suivant quand ce niveau ne contient que le titre.
- **Numéros dans les exports** : les exports HTML et PDF affichent les mêmes numéros.

<!-- ai-tools -->
## Outils pour Textus AI

Une fois le plugin installé, Textus AI peut s’en servir dans une conversation :

- `number_headings`: Écrit des numéros dans les titres d'un Markdown - 1, 1.1, 1.2 -, comptés comme l'éditeur les montre (un titre unique n'est pas numéroté), en remplaçant ceux déjà là ; avec remove, les retire. Renvoie le texte ; n'écrit rien.
