# Нумерация заголовков

Нумерует заголовки по ходу письма (1, 1.1, 1.2), не меняя текст; при экспорте номера тоже можно сохранить.

- Заголовки получают номера по ходу письма: 1, 1.1, 1.2, 2… Сам текст не меняется.
- **Нумеровать начиная с**: по умолчанию `##`, ведь `#` обычно — название документа.
- **Номера при экспорте**: в HTML и PDF те же номера.
