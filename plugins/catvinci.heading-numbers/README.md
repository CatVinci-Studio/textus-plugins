# Heading Numbers

Numbers headings as you write - 1, 1.1, 1.2 - without changing the text; exports can carry the numbers too.

- Headings get their numbers as you write: 1, 1.1, 1.2, 2… The text itself is not changed.
- Numbering starts at the document's top heading level - or one below, when that level holds only the title.
- **Numbers in exports**: HTML and PDF exports show the same numbers.

## Tools for Textus AI

Once it is installed, Textus AI can use these in a conversation:

- `number_headings`: Writes numbers into the headings of some Markdown - 1, 1.1, 1.2 - counted as the editor shows them (a lone title heading isn't numbered), replacing numbers already there; or, with remove, takes them out. Returns the text; writes nothing.
