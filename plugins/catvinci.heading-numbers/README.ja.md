# 見出し番号

書きながら見出しに番号（1、1.1、1.2）を振ります。本文は変えません。書き出しにも番号を付けられます。

- 書きながら見出しに番号が表示されます：1、1.1、1.2、2… 本文は変わりません。
- 番号は文書でいちばん上のレベルの見出しから振ります。そのレベルが表題ひとつだけなら、ひとつ下のレベルからです。
- **書き出しにも番号を付ける**：HTML と PDF の書き出しに同じ番号が入ります。

## Textus AI のツール

このプラグインを入れると、Textus AI が会話の中で使えます：

- `number_headings`：Markdown の見出しに番号（1、1.1、1.2）を書き込みます。番号の付け方はエディタの表示と同じで（一つだけの表題には付けません）、既にある番号は置き換えます。remove を指定すると番号を取り除きます。文章を返し、何も書き込みません。
