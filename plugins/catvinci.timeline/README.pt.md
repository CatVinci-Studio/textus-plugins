# Linha do tempo

Eventos em ordem, um por linha: quando | o quê | mais.

- Escreva um bloco de código em `timeline`: ele é desenhado abaixo, e o código volta a aparecer ao clicar nele.
- `height=400` depois da linguagem define a altura do desenho.
- Ao exportar para HTML, PDF ou Word, o desenho vai como imagem.

## Exemplo

```timeline
2024-03 | First draft | The outline and two chapters
2024-09 | Review | Notes from three readers
2025-01 | Published
```
